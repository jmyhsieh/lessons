課目表

正式課程保留 Phase 1、3、4、5、6、9，從安全操作 Claude Code 一路做到需求交付、畫面、簡報、知識庫與工作技能。Phase 2、7、8、10、11、12 改為工具庫，不列入正式課程；遇到真實需求時先查一頁式卡片，再選擇是否進入實作。

常用速查：Claude Code 工具庫、產品選用、第一個小畫面、視覺交付選路、三頁簡報、Phase 7 open-slide、Phase 8 Playwright、Phase 9 工作技能、Phase 10 文件轉 Markdown、Phase 11 用量與查找工具、Phase 12 介面動態 Skills、Claude Code 操作、模型與推理程度、Wayfinder 地圖、迷你 LLM Wiki、課程詞彙表
完成原則：勾完清單代表操作完成；能交出指定產出、說明判斷並通過回饋，才達到這課的完成標準。
