請 Claude Code 整理四句 design brief

今天只做一件事：把真實需求交給 Claude Code，整理成 Design MCP 能執行、你能檢查的四句 brief。

四句就夠：做什麼、給誰用、畫面要放什麼、最重要的是什麼。

填入你的內容

請只整理 brief，不要先生成設計：
我要做＿＿，使用者是＿＿，現有資料是＿＿。
我要做：
使用者是：
畫面必須包含：
最重要的是：

必要內容使用真實標題、按鈕名稱或欄位，不要只寫「現代、簡潔」。

確認沒有發明使用者、資料或功能；最重要判準必須可觀察，例如「第一次使用的人能找到報名按鈕」。

完成：你已有一段經人工核對、可由 Claude Code 交給 Design MCP 的四句 brief。

觀念檢查

哪一種 prompt 最容易檢查成果？

能觀察的使用結果，比抽象風格形容詞更容易讓你與 Claude 對齊。

帶走這個就好

Claude Code 可以幫你壓縮需求，但人要確認四句沒有偏離真實任務，再交給視覺工具。
