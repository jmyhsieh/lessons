用任務需求選模型，用不確定性選推理強度

任務：替目前路線寫一張模型／推理強度選擇卡，用一個低風險提示驗證選擇是否達到事先定義的回饋評分規準。

先分清楚兩個旋鈕

選項主要影響何時才調整
模型可用能力、行為特性、速度與成本邊界目前能力與任務複雜度、風險或脈絡需求不匹配。
推理強度代理嘗試投入多少推理與工作範圍已清楚，但不確定性或取捨需要更多分析。

可用模型、別名與推理強度層級會依模型、帳號、供應者、組織設定及版本改變。先看目前工作階段的選擇器或 CLI 說明，只選介面實際提供的值；若需要的選項沒有出現，記錄缺口並返回目前路線，不要自行猜測名稱。

執行一次有界限的快速驗證測試

  1. 從選擇器或 claude --help 記錄目前環境實際提供的模型／推理強度控制；不要從課程硬猜可用名稱。
  2. 選一個不修改檔案、不呼叫外部服務的小型提示，它必須保留目前路線的主要推理形狀。
  3. 先寫三個可觀察評分規準項目，例如「列出兩個風險」「指出未知資訊」「給出合法停止點」。
  4. 用選擇卡指定的設定執行一次，記錄顯示的模型／推理強度、輸出、延遲或成本訊號，以及評分規準結果。
  5. 若評分規準通過就停止；若未通過，只依事先寫好的升級訊號調整一次。重複失敗時修範圍、脈絡 或回饋 迴路，不用更高推理強度硬跑。
具體成果：一張選擇卡，加上一筆有界限的模型／推理強度快速驗證測試紀錄。
可觀察回饋：介面顯示的設定與卡一致；三個評分規準項目有逐項結果；你能說明保留、升級、降級或停止的理由。

高推理強度的快速驗證測試仍無法指出關鍵未知資訊，下一步應該是什麼？

模型 與推理強度是工作設定，不會補回缺少的 脈絡、模糊範圍或失效的驗證方式。

返回邊界：把選擇卡、評分規準結果與 learner judgment 寫回 Return notebook，狀態只記為 Lesson practiced，然後回到原本的 Targeted-remediation return point。本課不產生目前路線成果，也不授權更高權限。
