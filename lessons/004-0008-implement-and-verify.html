Phase 4 · 第 08 課 · 約 15–20 分鐘

完成一個小畫面並親自打開

今天只做一件事：讓 Claude Code 完成一個小切片，然後在瀏覽器親自走一次。

入門完成線：一個畫面、一條主要操作、桌面與手機各看一次。不要一次實作整個產品。

完成 Phase 4

確認它只碰本次畫面，沿用 repo 已有元件與樣式，再允許修改；完成後先審查 diff。

使用專案已有的 test、lint 或 build，回報完整命令與結果；不能執行就誠實記錄原因。

桌面與手機各開一次，完成主要操作，對照第 07 課交接卡確認保留項。

完成：你已把一個設計方向變成可打開、可操作、知道驗證結果的小畫面。

觀念檢查

程式 build 成功後，還要做什麼？

Build 只能證明程式能產出；真實畫面與操作仍要在瀏覽器確認。
