Phase 6 · 第 01 課 · 約 10 分鐘

把 LLM Wiki idea file 交給 Claude Code

本課成果：一個由原始想法檔建立、可以立即瀏覽的最小 LLM Wiki。

先記這句：這份 idea file 是給 AI agent 閱讀的設計說明，不是要你先學會安裝或架構。Claude Code 會依你的主題，和你一起決定最小版本。

直接開始

可以是新資料夾，也可以是現有專案中的知識區。第一版不用先安裝任何額外工具。

請讀這份 LLM Wiki idea file：
https://gist.githubusercontent.com/karpathy/442a6bf555914893e9891c11519de94f/raw/ac46de1ad27f92b28ac95459c782c07f6b8c964a/llm-wiki.md

請在目前資料夾幫我建立最小可用版本。
先問我這個 Wiki 要整理的主題，再建立需要的最少檔案。
不要先安裝額外工具，也不要一次加入大量來源。

確認它只建立最少檔案、沒有修改無關內容，再同意開始。如果它無法讀取連結，就開啟 raw 檔並把全文貼進對話。

完成：Claude Code 已根據 idea file 與你的主題，建立或提出一個最小可用的 Wiki。

觀念檢查

開始 LLM Wiki 的最小動作是什麼？

idea file 本來就是要交給 AI agent 閱讀；你只要補上主題與邊界，就能開始。

關鍵判斷

一個 raw 連結加一句需求，就足以開始。具體檔案結構由你和 Claude Code 在實際資料夾中一起決定，不是開始前的考試。
