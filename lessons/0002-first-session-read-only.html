Lesson 0002 · 約 20 分鐘 · 實作課

安裝 Claude Code，跑第一個唯讀任務

任務目標：在你的工作 repo 裡開出第一個 Claude Code session，讓它解釋專案架構 — 全程不修改任何檔案。完成後你就跨過了「從沒用過」到「真的用過」的門檻。

正式專案安全規則（本課唯一要背的東西）：
Claude Code 預設在修改檔案或執行指令前都會逐項徵求你的同意。在正式 repo，保持這個預設模式。本課的任務是純閱讀，它最多只會請求「讀檔案」的權限 — 不會出現任何修改。 （出處：官方 Quickstart：「Claude Code always asks for permission before modifying files.」）

實作步驟（做完打勾）

建議路徑：從 claude.com/download 下載 Claude 桌面 App（Windows），安裝後登入，點上方的 Code 分頁 — 這就是 Claude Code 的圖形介面，有視覺化 diff 檢視，權限同樣逐項詢問。裝好就可跳到步驟 2。

替代路徑：CLI 安裝（之後想在終端機用再回來看）

Windows PowerShell（提示字元開頭是 PS C:\）：

irm https://claude.ai/install.ps1 | iex

Windows CMD（開頭只有 C:\）：

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

macOS / Linux / WSL：

curl -fsSL https://claude.ai/install.sh | bash

Windows 原生環境建議另裝 Git for Windows，Claude Code 才能使用 Bash 工具（WSL 不需要）。也可用 winget install Anthropic.ClaudeCode 或 macOS 的 brew install --cask claude-code，但這兩種不會自動更新；原生安裝會自動更新，官方建議優先使用。

桌面 App：啟動 Claude，登入你的帳號（需 Pro/Max/Team 訂閱或 Console 帳號），點 Code 分頁，新增 session 時選擇你的工作 repo 資料夾。

CLI：cd 到 repo 目錄後執行 claude，第一次會引導你到瀏覽器登入。登入一次後憑證會保存，之後不用重登。

桌面 App：在輸入框附近找到權限模式選單（如 Ask before edits）。CLI：按 Shift+Tab 循環切換。兩邊都一樣 — 現在切換看看認識各模式，最後停在預設（逐項詢問）模式。

直接用自然語言輸入（中英文皆可）：

what does this project do? explain the folder structure
and where the main entry point is.

它會自己讀需要的檔案 — 你不用手動貼程式碼。觀察：它讀了哪些檔案？總結準確嗎？

挑一段你一直沒搞懂的程式碼，問它。例如：

explain how authentication works in this codebase

桌面 App：直接關閉或切換 session 即可，歷史會保留，隨時可回來續聊。CLI：輸入 /exit（或 Ctrl+D），之後用 claude -c 接續同目錄最近一次對話。
