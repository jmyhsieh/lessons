Phase 5 · 第 02 課 · 約 10–15 分鐘

收集三份可信資料

今天只做一件事：把三份可信資料交給 Claude Code，讓它整理用途與待確認內容。

少就是多：只把三份你看得懂、知道來源的資料放進 scope；不要讓 Claude Code 掃整個資料夾再替你猜哪些可信。

建立迷你資料包

可以是文件、試算表、會議筆記或官方網頁。確認 Claude Code 有權讀取；至少一份直接支持主要主張。

資料 A：用來說明……
資料 B：用來證明……
資料 C：用來決定……

打開原始資料抽查用途；不知道出處的圖片、數字或引言移到「待確認」，不讓 Claude Code 補猜。

完成：你已有三份可信資料，也知道每一份在簡報中要做什麼。

觀念檢查

某個重要數字找不到原始出處，該怎麼做？

先把不確定內容隔離，能避免初稿把猜測包裝成事實。

帶走這個就好
