第 2 階段 · 裝備 · 002-0006 · Conditional toolbox lesson

先使用既有 Skill，不跨過 Workflow authoring boundary

任務：選一個已安裝、來源可信且 description 直接符合 active-route gap 的 Skill，讀完 instruction package，再用 bounded task 做一次 smoke test。

先做 trust 與 fit 檢查

檢查可以繼續的證據停止訊號
來源與 scope知道它來自 personal、project 或 approved plugin，且名稱／description 對應目前 gap。來源不明，或只能靠猜測用途。
完整 instructions已讀完整 SKILL.md 及本次需要的直接 references。只看 description 就執行。
權限／副作用Read、write、network、external actions 與 stop condition 都在 selection card 內。Skill 需要超出 active route 核准範圍的權限。
Workflow 編寫邊界不修改 Skill，只使用既有 package。需要新建、重寫或發布 shared Skill。

建立 Skill use card

Active route / return point:

Why its description matches the gap:

Expected artifact or observation:
Stop condition:
  1. 從目前介面實際列出的 Skills 中選一個；沒有適合項目就記錄 gap 並停止。
  2. 開啟該 Skill 的 SKILL.md，完整讀取 instructions；只讀本次被直接引用且必要的 resources。
  3. 若介面支援 explicit invocation，就用顯示的 /skill-name；不要自行猜測不存在的 command。
  4. 用 safe fixture 或 read-only task 執行一次，保存 invocation、Skill 要求的步驟、實際結果與任何 permission prompt。
  5. 逐項比對 use card；若 Skill 要求擴權、修改自身或產生未核准 external side effect，立即停止。
具體成果：一張 Skill use card 與一次 bounded invocation record。
可觀察回饋：Skill 按已讀 instructions 完成指定小任務，結果符合預期，且沒有超出 card 的 authority／side effects。
