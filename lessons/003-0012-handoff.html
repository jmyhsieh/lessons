用 /handoff 做跨工作階段交接

本課成果：一份讓全新 Claude Code 工作階段可以直接接手的交接文件。

本課只做：把下一個人或工作階段需要的脈絡打包。
先不要做：把交接當成完整報告或長期文件庫。

它解決的問題

Phase 1 第 12 課教過：對話脈絡塞滿就砍掉重練、乾淨工作階段贏過污染的長對話。但「重練」也有成本：原本的脈絡會一起消失。交接就是在按下重練之前，先把值錢的脈絡壓縮成文件帶走：

長對話（脈絡漸亂）→ /handoff 今天到此，明天繼續做 X
                              ↓
                  交接文件（存到作業系統暫存目錄）
                              ↓
新工作階段開場：「讀這份交接文件，繼續」 → 乾淨脈絡＋完整交接

四個設計細節（SKILL.md 原文）

設計為什麼
存到作業系統暫存目錄，不放程式庫交接文件是消耗品，不該污染程式庫（同 Phase 3 第 11 課報告的做法）
不重複既有產出 — 規格、ADR、工作項目、提交紀錄用路徑引用單一事實來源：脈絡的正本在文件制度裡，交接只記「正本沒有的東西」（當下的決策過程、卡住的點、下一步）
內建 建議工作技能 區塊告訴下一個代理該用哪些工作技能繼續（例：「接下來跑 /implement 實作工作項目 3」）
產出時遮蔽敏感資訊（API key、密碼、個資）這是工作技能的必要指令，不是零漏網保證；交接前仍要自己掃一眼
參數很重要：使用 /handoff 下一個工作階段要做 X，它會針對 X 裁剪內容。「為了繼續除錯」和「為了寫文件」需要的脈絡完全不同。

什麼時候用（四個真實程式庫情境）

  • 中途分支：主線把一個問題交給全新的原型工作階段，完成後再用另一份交接把答案帶回主線。
  • 收工交接：下班前 /handoff 明天繼續實作 ticket 5，明早新工作階段直接接力。
  • 糾正兩次還不對（Phase 1 第 12 課的砍掉重練訊號）：先交接再重開，把「學到的教訓」帶進新工作階段的第一句提示。
  • 跨人交接：需求追問到一半要請假，改由同事接手。先透過經授權的安全管道，把交接文件送到對方能讀取的路徑，再由他的 Claude Code 冷啟動。

與相鄰機制的分工：/compact 是同一個工作階段內壓縮歷史；claude -c 是接續同一個對話；交接則產生一份本機暫存文件，供新的工作階段讀取。跨人或跨機器時，本機暫存路徑不會自動同步，必須先經授權管道安全傳送。

跨機器邊界：不要把 /tmp/... 或 $TMPDIR/... 路徑直接貼給另一台機器。先重新檢查敏感資訊是否已遮蔽（redaction），再用組織核准的安全管道傳送；確認接手方可讀後，依資料保留政策清理兩端暫存副本。

實作步驟（做完打勾）

最好是已有一些歷史的工作，例如需求追問或除錯做到一半。

/handoff 下一個工作階段要 [具體說明接下來做什麼]

打開暫存目錄的文件檢查：(a) 有沒有重複貼規格或工作項目內容（應引用路徑）？(b) 建議的下一個工作技能是否正確？(c) 有沒有漏網的敏感資訊？

先在同一台機器開全新工作階段：「讀 [文件路徑]，繼續這個工作」。觀察它需不需要再問你本該寫在文件裡的事；如果需要，表示交接文件還有漏洞，回頭補上。跨機器實測時，必須改用安全傳送後的目的端路徑。

給自己立一條規則：長工作階段收工或工作流程中途換工作階段，先交接。一週後回顧：接力的啟動時間少了多少？

完成條件：全新 Claude Code 工作階段已用交接文件成功接手，缺少的資訊也已補回文件。

Phase 3 驗收標準

不要用「12 課都看過」當結業證據。選一條真實路線，交出能讓新工作階段冷啟動的成果鏈：

  • 新需求：對齊結論 → 規格／工作項目（若需要）→ 實作證據 → 程式碼審查 → 交接。
  • 外部回報：議題 → 分類狀態 → 診斷證據 → 回歸驗證 → 交接。
  • 維護改善：架構發現 → 被選定的接縫 → 規格／實作證據 → 交接。
  • 巨大模糊工作：決策地圖 → 關聯決策 → 規格 → 工作項目 → 實作證據 → 交接。

新的 Claude Code 工作階段只靠這些產出，就能說出「做了什麼、怎麼驗證、還剩什麼」，這才算留下可用的學習紀錄。

觀念檢查（憑記憶作答）

1. 交接文件裡發現它把整份規格內容貼了進來，該怎麼處理？

工作技能原文：不重複既有產出，用路徑引用。複製會製造兩份會分岔的事實；交接文件的價值在「正本沒有的脈絡」（決策過程、卡點、下一步）。

2. /compact 和 /handoff 的本質差異是？

/compact 服務「這個對話繼續」；交接服務「新對話從文件冷啟動」。交接產生的是本機暫存檔，不會自動傳到另一台機器。

3.（複習 Phase 1 第 12 課）糾正它兩次同一問題仍失敗，加上本課工具後的最佳流程是？

（間隔複習）Phase 1 第 12 課說砍掉重練；本課補上「怎麼帶走學到的東西」。交接把失敗嘗試中值錢的部分（什麼不行、為什麼）變成新工作階段的起點。compact 留在原對話，污染還在。
