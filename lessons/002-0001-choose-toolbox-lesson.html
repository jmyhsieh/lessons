Phase 2 · Equip · 002-0001 · Toolbox entry

只補目前任務缺少的一個能力

任務：從 active route 的具體 blocker 選一個 Just-in-time toolbox lesson，先寫好 smoke test 與返回點，再進入練習。

先帶著 route contract 進來

  1. 從 Return notebook 複製 mission、current anchor 與下一個 tangible win。
  2. 把阻止下一個 win 的缺口寫成可觀察句，例如「我不知道這次允許哪些 write 與 external side effects」。
  3. 先填 Targeted-remediation return point；它必須是 active route 的確切 lesson 或工作步驟。
  4. 只選一課，並定義一個不碰真實交付物的最小 smoke test。

Tangible win：一張 Toolbox selection card，包含 gap、selected lesson、safe fixture、smoke-test evidence 與 return point。
Observable feedback：另一個人可以從 card 判斷這一課是否直接移除 active route 的 blocker，且不需要完成整個 Phase 2。

完成後如何返回

  1. 把 bounded setup、smoke-test command／steps、結果與 permission／side-effect boundary 寫回 Return notebook。
  2. 狀態只記為 Lesson practiced；Toolbox 沒有 Phase completion。
  3. 回到事先記錄的 Targeted-remediation return point，重新嘗試 active route 的 tangible win。

你在 Presentation route 遇到模型推理不足，完成 model／effort smoke test 後，下一步是什麼？

Toolbox 是插入 active route 的 targeted remediation；完成一個 bounded lesson 後就回到 caller-provided return point。

Legal stop：若目前缺口沒有對應的已 authored lesson，記錄 gap 與 return point 後停止。不要把 feature tour、未驗證安裝或整個 Phase 2 當成替代路線。
