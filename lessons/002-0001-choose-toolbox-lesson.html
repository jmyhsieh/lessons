第 2 階段 · 裝備 · 002-0001 · 工具箱 入口

只補目前任務缺少的一個能力

任務：從目前路線的具體阻塞選一個即時工具箱課程，先寫好快速驗證測試與返回點，再進入練習。

先帶著路線契約進來

  1. 從 續作筆記本 複製 任務使命、目前錨點與下一個具體成果。
  2. 把阻止下一個 成果 的缺口寫成可觀察句，例如「我不知道這次允許哪些寫入與外部副作用」。
  3. 先填 Targeted-remediation return point；它必須是目前路線的確切課程或工作步驟。
  4. 只選一課，並定義一個不碰真實交付物的最小快速驗證測試。

已驗證的單次執行可能進入遠端 CI界定 CI 自動化邊界以桌上演練驗證不受信任輸入、權限、機密資料、失敗與核准停止點，不建立真實工作流程。
具體成果：一張工具箱選擇卡，包含缺口、已選課程、安全練習環境、快速驗證證據與返回點。
可觀察回饋：另一個人可以從卡判斷這一課是否直接移除目前路線的阻塞，且不需要完成整個第 2 階段。

完成後如何返回

  1. 把有界限的設定、快速驗證測試命令／步驟、結果與權限／副作用邊界寫回 Return notebook。
  2. 狀態只記為 Lesson practiced；工具箱沒有 Phase 完成證明。
  3. 回到事先記錄的 Targeted-remediation return point，重新嘗試目前路線的具體成果。

你在簡報路線遇到模型推理不足，完成模型／推理強度快速驗證測試後，下一步是什麼？

工具箱是插入目前路線的定向補強；完成一個有界限的課程後就回到呼叫端提供的返回點。

合法停止點：若目前缺口沒有對應的已編寫的課程，記錄缺口與返回點後停止。不要把功能導覽、未驗證安裝或整個第 2 階段當成替代路線。
