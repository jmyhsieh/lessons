關閉一則視覺回饋

本課成果：一則從瀏覽器留言到程式差異審查都已關閉的回饋。

留言只是需求：/apply-comments 會把檢查器標記轉成程式碼修改；你仍要審查程式差異與新畫面。

關閉一次視覺回饋迴圈

在檢查器選一個元素，描述可觀察問題與期望，例如「標題在投影時太小，請提高到簡報標題尺寸」。

使用 /apply-comments；你要檢查標記、實際程式差異與是否意外改到其他頁。

刷新開發伺服器，確認留言已清除且問題改善；再讓 Claude Code 執行建置，留下前後證據。

完成：你已把一則視覺回饋轉成受控的程式差異，並用新畫面與建置結果關閉迴圈。

觀念檢查

檢查器留言之後，完整流程是什麼？

留言只有轉成可審查的程式差異，並由新畫面與建置再次驗證後才算關閉。

關鍵判斷

好的回饋迴圈讓留言、程式差異與瀏覽器證據能一一對應。
