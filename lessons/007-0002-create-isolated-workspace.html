Phase 7 · 入門第 02 課 · 約 15 分鐘

請 Claude Code 建立隔離 workspace

本課成果：一個在新資料夾建立、已親自看過範例的 open-slide 工作區（workspace）。

不要裝進現有 repo：第一次先用獨立 workspace，讓產生的檔案、Git 歷史與 dependencies 都有清楚邊界。

把 starter 跑起來

node --version
npm --version

要求它顯示實際版本；任何命令不存在就停止，不讓模型猜安裝狀態。

npx @open-slide/cli init phase7-open-slide --use-npm --locale zh-TW

確認目標是新的明確資料夾、預計安裝官方 package，才允許 Claude Code 執行。

cd phase7-open-slide
npm run dev

從終端輸出的本機網址開啟瀏覽器，確認畫面與上一／下一頁操作正常。

完成：你已在隔離 workspace 跑起 open-slide starter，並留下可見的 browser evidence。

觀念檢查

初始化後，哪一項才是第一個完成證據？

只有實際啟動 dev server 並打開範例，才能確認 dependencies、設定與瀏覽器路徑都能運作。

關鍵判斷

今天只證明環境可用；不要在還沒看懂 starter 前開始整份簡報。

主要閱讀：open-slide — Getting Started。
