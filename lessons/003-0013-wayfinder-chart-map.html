Phase 2 選修 · 第 13 課 · 約 45 分鐘 · Wayfinder

用 /wayfinder 建立共享決策地圖

本課成果：一張共享決策地圖（shared map），標出目標、目前可處理的問題與仍待釐清的區域。

本課只做：建立一張共享決策地圖，讓下一個 Claude Code 工作階段知道目標、目前能處理的問題，以及還看不清的地方。
先不要做：順手實作功能或解第一張工作項目。

先確認真的需要 /wayfinder

你現在的情況建議路線
需求已經能寫成完整規格直接用 /to-spec，不用建立地圖。
一個工作階段就能問清楚使用 /grill-with-docs。
工作跨多個階段，連「該先決定什麼」都不清楚使用 /wayfinder，先把未知範圍畫出來。
使用條件：Wayfinder 適合巨大、模糊、跨工作階段的任務。它先整理決策路徑，不直接交付最終功能。

共享地圖只回答四件事

地圖欄位你要檢查的內容
Destination最後要得到哪一份規格、決策或可執行路徑。
Frontier目前沒有被阻擋、下一個工作階段可以認領的決策問題。
Not yet specified仍然說不清楚，現在不該硬切成工作項目的模糊區。
Out of scope明確不在這次目標內的工作。

工具會使用上面的英文欄位名稱，所以保留原文。你只要會用中文判斷：現在能不能清楚說出要回答的問題？能就建立工作項目，不能就留在模糊區。

實作步驟

如果你已經知道完整實作順序，就換一個案例，或直接承認這次不需要 Wayfinder。

/wayfinder

我想處理：[巨大而模糊的工作]。
最後希望得到：[規格／決策／可執行路徑]。

確認地圖至少有一個清楚目標、一張目前可處理的工作項目，以及仍待釐清的模糊區。依賴關係要能說明「為什麼現在不能先做」。

不要在同一個工作階段解第一張工作項目。下一課會用全新的 Claude Code 工作階段接手。

完成：你已有一張能讓新工作階段接手的共享決策地圖。

觀念檢查

哪種工作最適合先用 Wayfinder？

只有工作巨大、模糊又跨多個工作階段時，才需要先建立共享決策地圖。

什麼情況可以把模糊區變成工作項目？

判斷點是能不能精確說出要回答的問題，不必先知道答案或工時。
