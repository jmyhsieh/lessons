Phase 9 · Standardize · 009-0003 · One-of selector

依 audience 與執行責任只選一種 package

Entry：帶入已通過反例檢查的 workflow contract、intended audience、使用環境、source-of-truth、owner 與 change／retirement triggers。這一課只做 one-of package decision；四種格式不是能力階梯，也不要求全部完成。

1. 先問 package 要替誰承擔什麼

Package branch適合關鍵限制Canonical continuation
Playbook／template人需要閱讀、填寫、調整 judgment；跨 repo 或非技術 audience。不能假裝能 deterministic execute；owner 必須維護內容。009-0004-package-as-playbook-or-template.html
Repository CLAUDE.md規則只對一個 repo／path 生效，且 Claude Code 每次工作都應看到。不是通用知識庫；repo diff 要 Review，instructions 不授權外部 action。009-0005-package-as-claude-md.html
Reusable Skill需要可攜 instruction package、清楚 trigger、progressive disclosure 與 bundled resources。Skill 仍是 instructions；它不證明 workflow，也不自動取得 tools／permissions。009-0006-package-as-skill.html
Command／local processRouting、validation、transform 或 repeatable execution 應由 deterministic code 承擔。只把 code 能可靠決定的部分自動化；judgment 與 approval 留在人手上。009-0007-package-as-command-or-process.html

One-of rule：以最小 package 承載完整 contract。只有出現第二個獨立 consumer requirement，且單一 package 無法合法服務時，才另開新 version／ticket；不要為了「完整」把相同 truth 複製到四處。

  1. 若主要價值是讓人理解並作 judgment，先選 playbook／template。
  2. 若 contract 必須在特定 repo context 每次載入，選 CLAUDE.md。
  3. 若同一 instruction workflow 要跨工作區重用且需要 resources，選 Skill。
  4. 若步驟可由 code 對相同 inputs 產生可靠、可驗證結果，選 command／local process；仍把例外與批准留給人。

Authority／source-of-truth boundary：Package location 決定誰會讀到與誰負責維護，不會自動提升權限。不要讓 playbook、CLAUDE.md、Skill 與 command 各自維護一份互相漂移的規則；selection card 必須指定唯一 authoritative contract 與 package owner。

Tangible win：一張選定且只選定一種 package format 的 decision card，包含 rejected alternatives、owner、authority、Review 與 return point。
Observable feedback：另一位 reviewer 使用同一 selector 能得到相同 primary choice，或精確指出是哪個 audience、scope、judgment、portability 或 deterministic-execution fact 造成分歧。

Workflow 是單一 repo 的 coding conventions，每次 Claude Code 修改該 repo 都必須看到，而且變更要走 repo Review。首選哪個 package？

Audience 與 source-of-truth 都是 repo-specific；CLAUDE.md 是最小 fitting package，且其 diff 仍須完整 Review。

Legal stop／return／continuation：Contract 尚未證明、audience 或 source-of-truth 不明、需要多種 package 才能掩蓋需求衝突、owner 缺失、repo Review／write authority 尚未確認，或 branch lesson 尚未發布時，保存 selection card 後停止；contract gap 回 009-0002，proof gap 回 009-0001。條件成立後只前往上表選定的一個 branch，再 rejoin 009-0008；本票不建立 branch page，也不因完成選擇而宣稱 Standardization closeout。
