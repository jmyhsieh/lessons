控制 Claude Code 工具行為（hooks）

任務目標：理解 hooks 在 Claude Code 生命週期中何時執行，以及 exit 0/exit 2 的差異。這一課先做最小的格式化 hook。

本課只做：理解 hook 何時會執行，以及 exit code 代表什麼。
先不要做：一開始就寫複雜 hook 取代人工 review。

三層模型

層機制性質
指引CLAUDE.md模型會參考，但不保證。
閘門permission rules決定工具能不能做。
自動化hooks固定時點必定執行 shell 指令。

最重要的 exit code

exit 0  → 放行
exit 2  → 擋下，stderr 內容會回饋給 Claude
其他    → 視為 hook 自身錯誤，動作通常照常進行

常用事件：PreToolUse 在工具前、PostToolUse 在工具後、Stop 在回合結束時。
