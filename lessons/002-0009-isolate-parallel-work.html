用工作樹隔離一條平行工作線

任務：在可丟棄 Git 練習環境開一個 Claude Code 工作樹，證明兩個工作目錄的檔案改動不互踩，再安全清理。

Stop condition:
Worktree 隔離Worktree 不隔離
工作目錄、分支、受追蹤／未追蹤檔案變更。Git 物件資料庫、遠端、憑證、網路、資料庫、部署目標與其他外部副作用。
適合兩條可能改檔的獨立本機任務。不是權限沙箱，也不會自動解決分支合併衝突。

建立、觀察、清理

  1. 只在乾淨、可丟棄的 Git 練習環境執行；先保存 git status --short 與 git worktree list。
  2. 用目前 claude --help 確認 --worktree，再執行 claude --worktree toolbox-isolation。不要重用現有分支名稱。
  3. 在新工作階段只建立一個練習環境標記；回原工作目錄確認標記不存在，再用 git worktree list 比對兩個路徑／分支。
  4. 記錄新工作樹是否缺少被 gitignore 排除的設定或依賴項目；不要為了方便把密鑰改成受追蹤檔案。
  5. 退出工作階段。清理前檢查該工作樹的狀態、未追蹤檔案與提交；只有確認無需保留的工作後才移除，最後再跑 git worktree list。
具體成果：一張工作樹隔離紀錄，含事前／進行中／事後清單。
可觀察回饋：標記只出現在新工作樹；兩個分支/路徑可辨識；清理後清單回到基準，沒有遺失未保存工作。

兩個工作樹同時指向同一個預備資料庫，是否已被安全隔離？

Worktree 解決本機檔案系統／分支衝突；外部系統、憑證與副作用仍是共享風險。

合法停止／返回：Fixture 不乾淨、分支/路徑已存在、兩條任務會碰同一外部資源、或無法判斷工作樹是否有未保存工作時，保留現況並停止，不使用 --force 清理。把隔離證據寫回 Return notebook，記為 Lesson practiced，返回 Targeted-remediation return point。
