安裝 Claude Code，開第一個 session

任務目標：把 Claude Code 裝好、登入，並開出第一個 session。這一課只確認工具與權限介面，不進行 repo 導覽或改檔。

本課只做：安裝、登入，並確認第一個 session 與權限介面。
先不要做：打開正式 repo 後直接批准修改檔案。
正式專案安全規則（本課唯一要背的東西）：
Claude Code 預設在修改檔案或執行指令前都會逐項徵求你的同意。在正式 repo，保持這個預設模式。這一課先認得權限介面，下一課才讓它讀你的 repo。 （出處：官方 Quickstart：「Claude Code always asks for permission before modifying files.」）

實作步驟（做完打勾）

建議路徑：從 claude.com/download 下載 Claude 桌面 App（Windows），安裝後登入，點上方的 Code 分頁 — 這就是 Claude Code 的圖形介面，有視覺化 diff 檢視，權限同樣逐項詢問。裝好就可跳到步驟 2。

替代路徑：CLI 安裝（之後想在終端機用再回來看）

Windows PowerShell（提示字元開頭是 PS C:\）：

irm https://claude.ai/install.ps1 | iex

Windows CMD（開頭只有 C:\）：

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

macOS / Linux / WSL：

curl -fsSL https://claude.ai/install.sh | bash

Windows 原生環境建議另裝 Git for Windows，Claude Code 才能使用 Bash 工具（WSL 不需要）。也可用 winget install Anthropic.ClaudeCode 或 macOS 的 brew install --cask claude-code，但這兩種不會自動更新；原生安裝會自動更新，官方建議優先使用。

桌面 App：啟動 Claude，登入你的帳號（需 Pro/Max/Team 訂閱或 Console 帳號），點 Code 分頁。先停在新增 session 的畫面，不急著選 repo。

CLI：cd 到 repo 目錄後執行 claude，第一次會引導你到瀏覽器登入。登入一次後憑證會保存，之後不用重登。

桌面 App：在輸入框附近找到權限模式選單（如 Ask permissions / 逐項詢問）。CLI：按 Shift+Tab 循環切換。現在只要認得位置，最後停在預設（逐項詢問）模式。

桌面 App：選一個低風險資料夾或測試 repo，直接送出一句不會改檔的確認：

Before reading many files, tell me what you can do in this session without changing files.

CLI：若你是在終端機使用，可以輸入 /help 看可用 commands。桌面 App 不以 /help 作為第一個檢查動作，先用畫面上的 session、權限與模型選單。

例如：

Tell me what Claude Code can do in this session without changing files.

重點是確認工具能正常對話、你也看得懂權限提示。

桌面 App：直接關閉或切換 session 即可，歷史會保留，隨時可回來續聊。CLI：輸入 /exit（或 Ctrl+D），之後用 claude -c 接續同目錄最近一次對話。

🎉 全部完成！回到對話視窗告訴老師：你用桌面 App 還是 CLI？權限模式選單找到了嗎？

本課速記

  • 桌面 App：Code 分頁開 session、用權限選單保持逐項詢問、用 session sidebar 續聊
  • CLI：claude 啟動 / claude -c 續聊 / /help 看 commands / /exit 離開
  • Shift+Tab 是 CLI 互動模式快捷鍵；桌面 App 用畫面上的權限模式選單
  • 先確認 session 可用，再進正式 repo 做任務

觀念檢查（憑記憶作答）

1. 正式 repo 第一堂課應停在哪種權限習慣？

正式 repo 先維持逐項詢問，讓你看懂每一次修改或指令執行前的風險。

2. 這一課開 session 後先做什麼？

本課只用低風險問題確認 session 可用；若使用 CLI 才用 /help 看 commands，不進 repo 導覽或修改。

3. 不應在本課完成的事情？

安裝與第一個 session 只確認工具、登入與權限介面；修改檔案留到後續安全流程。
