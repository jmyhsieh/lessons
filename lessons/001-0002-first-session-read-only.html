Phase 1 · 第 02 課 · 約 15 分鐘 · 實作課

安裝 Claude Code，開第一個工作階段

本課成果：一個已登入、尚未修改檔案的 Claude Code 工作階段（session）。

本課只做：安裝、登入，並確認第一個工作階段與權限介面。
先不要做：打開正式程式庫後直接批准修改檔案。
正式專案安全規則（本課唯一要背的東西）：
Claude Code 在工作目錄內讀檔、Grep，以及執行內建認得的唯讀指令時，通常不會跳出詢問；預設模式會在修改檔案或執行其他終端機指令前徵求同意。既有允許／詢問／拒絕（allow / ask / deny）規則與你曾批准的選項也會改變結果，所以正式程式庫先用 Desktop 的 Manual（舊版稱 Ask permissions）或 CLI 的 default，並逐項看懂有出現的提示。 （出處：官方 Permissions）

先備檢查：Git 可用嗎？

Claude Code 可以用自然語言幫你操作 Git，但電腦本身仍要先有 Git。進工作程式庫前，先在終端機跑：

git --version

看得到版本號就可以繼續；如果顯示找不到指令，先到 Git 官方下載頁安裝 Git，安裝後重開終端機或 Claude 桌面 App 再檢查一次。

實作步驟（做完打勾）

建議路徑：從 claude.com/download 下載 Claude 桌面 App，安裝後登入，點上方的 Code 分頁。這就是 Claude Code 的圖形介面，有視覺化程式差異與權限模式選單。裝好就可跳到步驟 2。

替代路徑：CLI 安裝（之後想在終端機用再回來看）

Windows PowerShell（提示字元開頭是 PS C:\）：

irm https://claude.ai/install.ps1 | iex

Windows CMD（開頭只有 C:\）：

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

macOS / Linux / WSL：

curl -fsSL https://claude.ai/install.sh | bash

也可用 winget install Anthropic.ClaudeCode 或 macOS 的 brew install --cask claude-code，但這兩種不會自動更新；原生安裝會自動更新，官方建議優先使用。

桌面 App：啟動 Claude，以有 Code 使用權的 Claude.ai Pro、Max、Team 或 Enterprise 帳號登入，再點 Code 分頁。桌面 App 與雲端工作階段使用 OAuth，不會讀取你終端機環境裡的 ANTHROPIC_API_KEY 或 apiKeyHelper；組織部署的第三方推理設定是例外。

CLI：cd 到程式庫目錄後執行 claude。Claude.ai 訂閱帳號與受邀的 Console 帳號可依瀏覽器提示登入；使用 Bedrock、Google Cloud Agent Platform 或 Microsoft Foundry 時，則先依組織文件設定服務供應商憑證。登入後憑證會保存，失效或換帳號時再用 /login。

桌面 App：在輸入框附近找到權限模式選單，最後停在 Manual（舊版稱 Ask permissions）。CLI：按 Shift+Tab 循環切換，最後停在 default。這兩種基準模式都允許工作目錄內讀檔與內建唯讀指令直接執行，但會在編輯與其他指令前詢問。

桌面 App：選一個低風險資料夾或測試程式庫，直接送出一句不會改檔的確認：

在讀取大量檔案前，先告訴我你在這個工作階段中能做哪些不會修改檔案的事。

桌面 App：也可以在輸入框輸入 /，查看目前可用的斜線指令；本課先用操作介面與低風險提問確認工作階段。CLI：可用 /help 查看指令清單。

例如：

告訴我 Claude Code 在這個工作階段中能做哪些不會修改檔案的事。

重點是確認工具能正常對話、你也看得懂權限提示。

桌面 App：直接關閉或切換工作階段即可，歷史會保留，隨時可回來續聊。CLI：輸入 /exit（或 Ctrl+D），之後用 claude -c 接續同目錄最近一次對話。

完成條件：已登入 Claude Code、確認目前權限模式，並記下使用的是桌面 App 還是 CLI。

本課速記

  • 桌面 App：在 Code 分頁開工作階段、正式程式庫先用 Manual、用工作階段側欄續聊
  • 桌面 App：在輸入框輸入 / 查看可用的斜線指令；快捷鍵清單則看 App 顯示
  • CLI：claude 啟動 / claude -c 續聊 / /help 看指令 / /exit 離開
  • Shift+Tab 是 CLI 互動模式快捷鍵；桌面 App 用畫面上的權限模式選單
  • 先確認工作階段可用，再進正式程式庫做任務

觀念檢查（憑記憶作答）

1. 正式程式庫第一堂課應停在哪種權限習慣？

正式程式庫先用 Manual/default：讀檔與內建唯讀指令通常直接執行，編輯與其他指令則停下詢問。

2. 這一課開工作階段後先做什麼？

本課只用低風險問題確認工作階段可用；桌面 App 可輸入 / 看斜線指令，但不進程式庫導覽或修改。

3. 不應在本課完成的事情？

安裝與第一個工作階段只確認工具、登入與權限介面；修改檔案留到後續安全流程。
