Phase 7 · 驗證 · 007-0006 · 條件式診斷

只有失敗還解釋不了，才保留trace

條件式進入：只在007-0005的test仍失敗／不穩定，而且失敗輸出、直接觀察、主控台／網路請求證據不足以區分假說時進入。若同一test已有關鍵的RED與修正後的GREEN，立刻略過本課，直接準備007-0007附錄；trace不是每次必跑的證據層級。

操作方式校準：2026-07-17以 @playwright/test@1.61.1 將 trace 設為僅失敗時啟用的條件式設定：有缺陷的執行在 TRACE_MODE=1 產生非空 trace.zip；修正後重跑在 TRACE_MODE=0 通過且沒有 trace 成果。這證明設定行為，不代表trace內容已診斷你的應用程式。

進入判定準則：如果你不能寫出至少兩個可被trace區分的假說，先不要擷取。追蹤是用來回答已命名的診斷問題，不是為附錄增加一個漂亮附件；screenshot或trace本身也不會讓斷言變得可持續重跑。

2. 將擷取限定在失敗的執行

// playwright.config.ts — 只示範 conditional shape
const diagnose = process.env.PW_DIAGNOSE === '1';

export default defineConfig({
  retries: 0,
  use: { trace: diagnose ? 'retain-on-failure' : 'off' }
});

# 只跑 exact failing test；使用 repo command 與已核准 artifact path
PW_DIAGNOSE=1 npx playwright test tests/browser/checkout.spec.ts \
  --grep "guest can complete checkout" --retries=0

# 在可信本機環境查看，不把 artifact 上傳未知服務
npx playwright show-trace path/to/trace.zip
檢查面只記直接觀察另列推論
操作／DOM點擊前後定位資訊、可見的狀態、URL與時間資訊。「可能等待錯誤元素」仍是假說。
主控台／網路精確訊息、網路請求URL／方法／狀態、回應時間；敏感payload不抄入備註。「API壞了」要由具體回應或另一個check驗證。
原始碼／呼叫堆疊追蹤能顯示的呼叫與失敗位置。根本原因仍須由修正後同斷言重跑證明。
Artifact檔案本機路徑、SHA／大小、擷取模式、保留與清理。有trace不等於找到原因，也不等於真實使用者證據。

3. 用trace導出一個可反證修正

  1. 將trace觀察對回已命名假說；不符合的明確排除，仍未知的保持未知事項。
  2. 只修最小根本原因或受控的fixture；若應用程式／test候選版本有任何位元組改變，記錄新候選版本識別，稍後重新套用完整Review contract。
  3. 以 PW_DIAGNOSE=0 重跑同一test／斷言；GREEN才是修正證據，trace不是。
  4. 確認正常路徑沒有新的 trace 成果；保留必要artifact識別與精簡觀察，依保留計畫清理原檔。

隱私／成本邊界：追蹤可能包含DOM、URL、需求中繼資料、主控台、來源與螢幕截圖。只在安全的fixture或已核准資料範圍擷取；不要用真實機密資料、付款、個人資料或未授權已登入的工作流做教材練習。看見超出權限的資料就停止、隔離並依repo政策清理，不要把trace附加到議題、PR或外部服務。

可見成果：一份只為未解失敗建立的追蹤診斷紀錄，包含擷取理由、artifact識別、直接觀察、分離的假說、有界修正與關閉追蹤後的 GREEN 重跑。
可觀察回饋：審查者能指出trace中哪一項觀察排除／支持哪個假說，並確認正常重跑沒有依賴trace；若拿掉trace仍沒有可驗證的修正決策，本課尚未完成。

007-0005已有同識別的關鍵 RED與修正後的GREEN，沒有未解失敗。下一步是？

追蹤是條件式診斷artifact。持久主張的核心是同斷言能對故障RED、修正後GREEN；沒有診斷問題就不應增加擷取。

合法停止／返回／續行：追蹤理由不成立、擷取可能越過資料／網站／artifact權限、artifact檢視器不可信、trace無法區分假說、修正後同test不綠、結果仍不穩定、清理未完成，或變更後候選版本尚未重新審查時，保存非敏感事實並停止；回007-0005重新建立可比較失敗，或回原始的工程路線修候選版本。只有trace觀察導出可反證修正且關閉追蹤後重跑 GREEN，才續到 007-0007；完成本條件式課程不代表瀏覽器證據route、Phase或Migration完成。
