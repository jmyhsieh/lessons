Phase 1 · Orient · 001-0004 · Code readiness entry

先證明 CLI 與 session 可用

任務：在不修改任何 repo 的情況下，記錄 Claude Code binary、help surface 與一次互動 session 的 smoke evidence。

先做 non-mutating checks

claude --version
claude --help

記下實際版本與 help 中的互動入口。課程在 2026-07-16 的已驗證環境是 macOS arm64／zsh、claude-code@2.1.211；你的版本可以不同，必須記錄而不能假裝相同。

在空白練習資料夾開 session

  1. 建立或選擇一個不含專案資料的空白 fixture folder。
  2. 在該資料夾執行 claude，依產品流程完成登入。
  3. 請它只回答目前工作目錄與可看到的檔案，不建立或修改檔案。
  4. 離開 session，記錄成功輸出、版本、平台與任何登入阻塞。
Tangible win：一筆 session smoke record。
Observable feedback：--version、--help 與互動 session 都有可辨識輸出，且 fixture 內容未改變。

若登入或 session 啟動失敗，正確的 route 動作是什麼？

本課是 Code readiness entry；session 尚不可用時，後續 repo 探索與 edit evidence 都不可信。

停止線：本課不授權 repo write。沒有 smoke evidence 就不要前進；成功後進入read-only reconnaissance。
