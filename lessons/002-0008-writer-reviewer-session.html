「Writer／Reviewer 雙 session」已合併到 Review contract 與執行課

穩定公開網址識別：lessons/002-0008-writer-reviewer-session

轉接原因

原課以 session topology 表達獨立 review；現在由共同 contract 定義不可變 candidate、reviewer write boundary 與證據，再由 Build 課選擇合適 execution surface。

何時選哪個最終目標

執行一次 final review

何時選：writer 已建立 immutable review checkpoint，要用隔離 reviewer context 完成 Standards 與 Spec。

前往 final candidate review

查共同 Review contract

何時選：需要判斷雙 session、subagent 或 worktree 的責任邊界，而不是立即執行 review。

開啟 Repo review contract

證據沿用

若你已保存舊課的 writer checkpoint 與 reviewer report，可保留為 Lesson practiced；只有 report 對應目前 final checkpoint，且 findings 已由人類 disposition，才能計入 current Review evidence。它不會自動成為 Route artifact、approval 或 completion。
