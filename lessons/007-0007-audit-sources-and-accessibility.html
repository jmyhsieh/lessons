稽核來源與無障礙

本課成果：一份針對實際輸出的來源與無障礙查核紀錄。

程式化不等於可信或可及：React 元件能重用版型，不能自動證明數字正確、閱讀順序合理或對比足夠。

完成雙軸稽核

使用 Phase 5 主張查核表，讓它指出每個高影響數字的來源位置與限制；你要打開來源抽查。

請 Claude Code 檢查標題順序、圖片等價文字、對比與顏色依賴；結果只是待驗檢查清單。

用鍵盤完成三頁導覽，檢查窄版與投影距離；把通過、問題或未驗證項目交回 Claude Code。

完成：你已留下來源與無障礙兩種不同證據，不會用建置結果替代內容查核。

觀念檢查

程式碼優先的簡報完成後，應該怎麼查核？

主張要回查來源，實際輸出也要由人操作與閱讀；兩種證據不能互相替代。

關鍵判斷

可信內容與無障礙呈現是兩道不同的交付關卡，都要在實際輸出上查核。
