把 Playwright MCP 接到 Claude Code

今天只做一件事：在個人本機範圍連接 Playwright MCP，並讓 Claude Code 顯示它真的可用。

先用 local scope：local 設定只供你在這個 project 使用，不會新增可提交的團隊設定。只有團隊審查 command、來源與權限後，才考慮 project scope。

連接並核對

執行 node --version，確認是 Node.js 20 以上；也先確認目前位於正確 repo。

使用目前 Claude Code 文件的參數順序；-- 後面才是 stdio server command。

claude mcp add --transport stdio --scope local playwright -- npx @playwright/mcp@latest

執行 claude mcp get playwright；進入 Claude Code 後再用 /mcp 查看狀態。若來源或 command 與預期不同，先移除，不要授權。

完成：你已留下 Node 版本、MCP command 與連線狀態三項 setup evidence。

觀念檢查

第一次把 Playwright MCP 接到 Claude Code，建議怎麼做？

Local scope 讓你先驗證 command 與權限，不會先把未審查的 MCP 設定推給團隊。

帶走這個就好
