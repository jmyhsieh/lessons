Phase 3 · Deliver · 003-0002 · Provenance

先建立 raw source pack，讓生成內容永遠不是 source of truth

任務：替 mission 所需來源建立 stable IDs、原始位置、capture context、rights 與 handling metadata，並將 working notes 分開保存。

Raw source 與衍生內容分層

Layer包含規則
Raw sourceOriginal file、URL、export、recording 或 approved snapshot。不被模型改寫；保留 owner、date、version／range 與原始位置。
Evidence note帶 source ID／locator 的摘記、短 paraphrase、row／timestamp。可追溯，不把 note 冒充原文。
Generated candidateOutline、summary、claim、draft wording。尚未驗證前不是 evidence，也不能回填成 raw source。

建立 provenance ledger

  1. 只收 mission scope 需要的 sources；先檢查 access、sensitive data、copyright／license、retention 與可分享範圍。
  2. 為每份來源建立 stable local ID，例如 S-01；保存 title、owner、原始 location、captured at、version／time range 與 content type。
  3. 能合法保存時保留原檔或 approved snapshot；只能連結時記錄 access assumption 與未來失效風險。
  4. 記錄 transformation history，例如 OCR、conversion、filter 或 manual cleanup；raw copy 與 normalized copy 不覆蓋彼此。
  5. 隨機抽一份 source，請另一個人從 ledger 找回原始內容並說出可用／不可用 boundary。

Tangible win：一份 raw source pack 與 provenance ledger。
Observable feedback：抽查者能從任一 source ID 找回原始內容、辨識版本與使用限制，且不會把 generated draft 認成來源。

Claude 依三份文件產生一段摘要，這段摘要應放在哪一層？

生成摘要是衍生內容；即使寫得正確，也不能取代原始來源與逐 claim verification。

Conditional／legal stop：若 PDF／文件需 normalize，走 MarkItDown／Docling；corpus 需 local search，走 QMD；tabular source 需 query，走 DuckDB。只有 active input 確實命中時才選一支，完成後都返回 003-0003，那些工具不是必修。來源無合法 access、rights／privacy 不明、raw copy 無法保存且沒有可接受的 reference boundary 時，記錄 gap 後停止，不開始生成。
