第 6 階段 · 建置 · 006-0014 · Conditional branch

只解一張 frontier decision ticket，再更新 map

進入條件／條件分支：Shared map 已存在；本 session 先讀它的低解析全貌，再選一張 open、所有 blockers 已關閉、而且 unclaimed 的 frontier ticket。Assignee 是並行鎖：任何調查或對話開始前，第一個寫入動作必須是 claim。

1. 依 ticket type 建立正確 feedback loop

類型怎麼解解題證據
research（離席執行，AFK）讀 primary sources 或指定 local material；charting 可平行派出 read-only research agent。有 citations 的 findings 與 ticket context pointer。
prototype（人類參與，HITL）做便宜、可反應的 artifact，由真人給 feedback。Artifact link、人類反應與形成的 decision。
grilling（人類參與，HITL）一次一題詢問真正的 decision owner；agent 不替人回答。可引用的明確 decision 與仍未決問題。
task（離席執行／人類參與，AFK／HITL）只做「決策前不可少」的操作，不藉機交付 destination。做了什麼與後續 decision 依賴的 facts。

漸進式揭露：不要一次讀完所有 child tickets。先載入 map，再打開選中的 ticket；只有答案依賴某個 linked decision 時才 zoom in。這能讓一個 session 保持在一個 decision boundary 內。

2. Resolution 同時維護 ticket 與 map

Session stop:
  1. 把完整答案、證據、limitations 與 assets 留在 ticket resolution comment，然後 close ticket。
  2. 在 map 的 Decisions so far 只追加 ticket 名稱、連結與一句答案 gist，不複製完整 resolution。
  3. 若 decision 讓一塊 fog 變得可精確提問，從 Not yet specified 移除，建立 child tickets，再 wire 真實 blocking edges。
  4. 若發現既有 ticket 超出 destination，關閉它並把 linked reason 放進 Out of scope；不要當作已走過的 decision。
  5. 即使下一張普通 frontier 已出現，也在此停止，交給下一個乾淨 session。
返回邊界：Wayfinder 不形成獨立 completion path。仍有 open ticket 或可升級 fog，就在下一個 session 重做本課；沒有 open tickets、沒有可升級 fog，而且 route 已清楚時，把 linked decisions 帶回 delivery flow，不直接施工。
具體成果：一張已被 claim、依正確 feedback loop 解完並關閉的 frontier ticket，加上一條只索引答案的 map gist。
可觀察回饋：Reviewer 能由 tracker 確認 claim、blocker state、resolution comment、closed state 與 map pointer 一致；下一張普通 ticket 未被本 session 偷跑。

解完一張 ticket 後，map 應保存什麼？

完整答案只有一份，留在 ticket；map 是低解析 index，只保存 linked gist。

Map 已沒有 open tickets 與可升級 fog，而且通往 destination 的路已清楚，下一步是？

Wayfinder 清除 planning fog，但不取代 alignment、delivery spec、ticket DAG、implementation 或 Review。

合法停止／返回／續行：Ticket 非 frontier、claim 失敗、HITL 缺少真人、evidence 不足、resolution 還沒回 tracker、map 與 ticket 內容重複，或 session 開始實作 destination 時停止。Map 尚未完成就由新 session 留在本課；map 完成後回 006-0003 對齊 decision evidence，再依序到 006-0005 與 006-0006，不能跳過已核准 spec 直接施工。
