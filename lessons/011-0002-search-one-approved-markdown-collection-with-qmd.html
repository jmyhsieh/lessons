用 QMD 搜尋一組核准的 Markdown 文件

本課成果：一筆搜尋紀錄，包含問題、找到的檔案與原文對照結果。

先從關鍵字搜尋開始：本課只用 QMD 的全文搜尋，不下載向量模型（embedding model），也不做自動改寫。搜尋結果只是線索，仍要回到原始 Markdown 確認答案。

只搜尋一個已核准的目錄

選一個不含機密、而且你有權使用的 Markdown 目錄，例如這個課程的 reference/。不要把整個家目錄或不明確的上層路徑加入文件集合（collection）。

請檢查 QMD 最新版的安裝方式與 --help，先不要執行。
只把 ./reference 加入名為 course-reference 的文件集合，
再用全文搜尋查「強制 OCR」。
不要加入其他目錄，不要執行 qmd embed 或下載模型。

核准後，命令會像 qmd collection add ./reference --name course-reference 與 qmd search "強制 OCR"；參數仍以目前版本為準。
