第 6 階段 · 建置 · 006-0001 · Route entry

先選 Engineering on-ramp，再進 repo

進入條件／準備狀態：只有已完成 Code readiness、能指出安全 repo、副本或 worktree、instructions、權限邊界與可跑 checks 時才進入。這條 route 要交付 repository change，不是只看 skill demo。

收到難解 intermittent bug，但還沒有可重現 feedback loop，應怎麼選？

難解 bug 的第一個 evidence 是能捕捉 exact symptom 的 feedback loop；不要先用 code reading 或原因假說取代它。
