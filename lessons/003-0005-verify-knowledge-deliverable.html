Phase 3 · Deliver · 003-0005 · Verification

把「看起來完整」改成可查核的 deliverable

任務：對選定 artifact slice 執行 claims、rights、limitations、target-format 與 audience feedback 五個 checks，保存 failure 與 disposition。

建立 verification matrix

CheckPass evidenceFail action
ClaimsMaterial claim 能反查 source ID／location；推論有標記。補 source、縮小或移除 claim。
Rights／handling使用、分享、privacy、retention 與 attribution 符合 source pack。移除受限內容或停止交付。
LimitationsUnknown、conflict、coverage gap 與時間邊界在 artifact 中可見。補 limitation，不把不確定改寫成事實。
Target format輸出重新開啟後，結構、links、tables、images 與 citations 可用。修正後重開，不把 export success 當驗證。
Audience feedback一位符合目標 audience 的 reviewer 能回答用途、信任點與下一個問題。記錄誤解，修正 artifact 或 scope。

執行與記錄

  1. 鎖定 deliverable version；後續每次修正產生新 identity，不覆蓋原始 failure evidence。
  2. 至少抽查三個 material claims，含一個數字／日期或高風險 claim；保存 source location 與結果。
  3. 逐項核對 source pack 的 rights／handling，並確認 limitations 在 target artifact 內可被 audience 看見。
  4. 重新開啟實際 target format，不只看 authoring preview。
  5. 請 reviewer 回答：「這份 artifact 要幫誰做什麼？哪個 claim 最需要證據？看完還缺什麼？」保存原話與你的 disposition。

Tangible win：一份綁定 artifact version 的 verification／feedback record。
Observable feedback：每個 check 有 pass 或具體 fail action；reviewer 的誤解能追到 artifact revision，而不是只留下「很好」。

PDF 成功匯出，但 citations links 全部失效，應如何記錄？

Export success 只證明產生檔案；target-format validation 必須觀察實際 artifact 的結構與引用是否可用。

Legal stop／return：Rights 不明、material claim 無 source、target format 無法驗證，或沒有可用 feedback 時，保留 failure evidence 並停止，不進 closeout。補齊後返回本課重跑；全部 checks 有 disposition 才進入 Knowledge delivery closeout。
