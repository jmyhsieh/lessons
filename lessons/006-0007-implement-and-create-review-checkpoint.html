Immutable boundary：把通過 checks 的 commit SHA 記為 candidate SHA，並另記比較起點 fixed point。只有 exact SHA 可進 Review；branch name、working tree 或「最新版」都是會移動的別名。

Tangible win：一個綁定 exact commit SHA、可交給 reviewer 的 implementation checkpoint。
Observable feedback：另一位 reviewer 能 checkout 該 SHA、重跑相同 commands，並由 fixed point 重建同一份 diff。

哪一個可以作為下一課的 immutable Review candidate？

Review evidence 只能綁定不會移動的 candidate identity；branch 與 working tree 不能證明 reviewer 看的是哪一版。

Legal stop／continuation：RED 不是因 acceptance behavior 失敗、relevant check 未跑或不綠、diff 混入票外變更、仍有未提交修改，或 candidate 沒有 exact SHA 時，保存 ticket notes 後停止，不得進 Review。Checkpoint 成立後續到 006-0008 independent Review；Review 若產生 finding，回本課只修 findings，建立新的 candidate SHA，再從頭 Review。這不是 Engineering closeout。
