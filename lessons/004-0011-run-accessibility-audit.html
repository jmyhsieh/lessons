Phase 4 · 進階第 11 課 · 約 15–20 分鐘

跑一輪 accessibility audit

本課成果：一份小介面的無障礙檢查紀錄，分清 Claude Code 建議與真人實測證據。

模型 review 只是待查清單：真正證據來自你實際操作、瀏覽器工具與使用者輔助技術；不要讓 Claude 自評取代測試。

三個 focused checks

讓它依現有頁面與 W3C Easy Checks 列出鍵盤、200% 縮放、名稱／狀態／顏色三組檢查，不要先宣稱通過。

只用鍵盤走完主要任務，再放大到 200%；確認焦點、順序、內容與主要動作仍可用。

逐項記錄 pass／issue 與 evidence，讓它只修一個 blocker；名稱、狀態與重要差異不能只靠顏色。

完成：你已留下三類 accessibility evidence，並能分清楚模型建議與實際驗證。

觀念檢查

哪一項才是 accessibility 實際證據？

實際以鍵盤完成任務能揭露焦點、順序與操作問題；模型或截圖只能提供線索。

關鍵判斷

Focused audit 不等於完整合規認證，但能提早阻止會卡住主要任務的問題進入 handoff。

主要閱讀：W3C WAI — Easy Checks。
