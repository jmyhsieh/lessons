第 5 階段 · 溝通 · 005-0001 · Route entry

先固定受眾與交付環境，再開始做 deck

進入條件／準備狀態：帶入一個真實簡報任務、明確 audience、使用時刻、要促成的決定、可用來源與素材權利。這條 route 的 core stop 是一份可重開、可查核、可及且完成目標格式驗證與彩排的 deck，不是「成功生成投影片」。

建立 route selection card

Audience / prior knowledge:
Moment / duration / room or device:
Decision or next action:
Confirmed source pack owner:
Asset-rights owner / restrictions:
Primary target format and target app:
Audience-question checklist / optional feedback giver:
Legal stop: accessible deck + target-format validation + rehearsal record
Continuation: stop / return to catalog / choose an elective
  1. 用一句話寫出 audience 在簡報結束後要能重述或決定什麼。
  2. 先指定 primary target format 與實際開啟它的 app；不要等 export 後才猜交付環境。
  3. 確認至少一位能核對 claims／rights 的 owner，並建立 audience-question checklist：至少三個可能不懂的詞、三個會追問的問題與一個反對點。若有接近 audience 的 feedback giver，可選擇性記錄，但不是進入條件。
  4. 把未知資料、未核准引言、素材權利與 accessibility 工具限制列成 blocker。
具體成果：一張把 audience、decision、sources、rights、format、audience-question checklist 與 stop line 放在一起的 route selection card。
可觀察回饋：逐項用 card 回答 audience-question checklist，確認 deck 是正確交付物、primary format 有明確驗證環境，並指出至少一個會阻止進入第 02 課的缺口；真人 feedback 若有則是選用加值證據。

哪一個條件最能證明可以開始 core Presentation route？

Surface access、選修工具或真人 feedback giver 都不能替代 route readiness；先固定交付情境、evidence owners 與可獨立執行的 audience-question checklist，後續 claims、accessibility、export 與 rehearsal 才有驗收基準。

合法停止／針對性修正：Audience、decision、來源、素材權利、audience-question checklist 或 target app 任一不明時，保存 selection draft，回 001-0002 補最小缺口，再回本課。真人 feedback path 缺席不構成 blocker。Card 可驗收後進 005-0002 來源包。完成第 07 課後可合法停止並回課目表；只有新的交付需求明確需要時，才另選 單頁稿／社群素材、Open-Slide 或 Mermaid CLI，它們不是 core spine 的必修步驟。
