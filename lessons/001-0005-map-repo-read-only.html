第 1 階段 · 定向 · 001-0005 · Code readiness

先用檔案證據畫出 repo map

任務：在可丟棄的練習 repo 或安全副本中，只讀取高層結構、instructions、entry points 與 checks，產出一張有檔案依據的 map。

宣告 read-only boundary

告訴 Claude Code：「只做 read-only reconnaissance。不要建立、修改、刪除檔案，不要安裝套件，不要執行會改變 state 的命令。請先找 repo instructions，再用具體路徑說明結構、入口與可用 checks。」
  1. 確認它找到的 instructions 路徑，例如 README、AGENTS.md 或 CLAUDE.md。
  2. 要求它說明主要目錄、入口、資料流與最相關的 3–5 個檔案。
  3. 每個主張都要附路徑；你抽查至少兩個檔案，確認摘要與內容相符。
  4. 把 map 複製到 Return notebook；不要為了保存 map 讓它寫入 repo。
具體成果：一張包含 instructions、entry point、relevant files 與 checks 的 repo map。
可觀察回饋：抽查的檔案支持 map，且 git status --short 沒有因 reconnaissance 產生變更。

哪一種 repo map 最可 review？

可 review 的 map 用路徑支持主張，也保留 unknown；模型的信心或一般化描述不是 evidence。

停止線：若讀檔需要未授權資料或出現意外 write，立即停止並回到 safe scope。完成後前往fixture plan。
