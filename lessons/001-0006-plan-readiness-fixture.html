第 1 階段 · 定向 · 001-0006 · Code readiness

用 Plan mode 收斂一個 bounded fixture edit

任務：在 read-only Plan mode 中，讓 Claude Code提出一個只改一個練習檔案、能用既有 check 驗證、也能安全放棄的計畫。

進入 read-only planning

claude --permission-mode plan

使用 001-0005 的 map，指定一個低風險 fixture，例如修正練習 README 的一個錯字或補上一句已知說明。要求計畫包含：

  • 目標與不處理事項
  • 預計修改的唯一檔案與理由
  • 修改前要讀的 evidence
  • 預期 diff 與既有 check
  • 意外擴張時的 stop condition
規劃 prompt：「保持 Plan mode。根據 repo instructions 與剛才的 map，規劃一個只修改 fixture README 的 bounded edit。不要現在動手。列出檔案、預期 diff、驗證命令、停止條件與尚未確認的假設。」
具體成果：一份可逐項驗收的 fixture plan。
可觀察回饋：計畫只列一個預期檔案、引用實際 instructions，並有一個會因錯誤變更而失敗或顯示差異的 check。

哪個條件代表計畫仍然 bounded？

Bounded plan 在動手前固定檔案、驗證與停止條件；相鄰清理與事後補 check 都會擴大不確定性。

停止線：本課只產生 plan，不修改 source。計畫出現多檔案、外部 write 或未知 command 時，先縮小再前往就緒證明。
