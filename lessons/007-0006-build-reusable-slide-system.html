建立可重用 slide system

本課成果：一個有重複證據支持、已套用到兩頁的共用版型。

先有重複再抽象：沒有兩個實際使用點，就先保留頁面內寫法，不建立推測性的元件庫。

完成一個可重用 pattern

只讀三頁，從標題區、證據卡或頁尾來源挑一個至少出現兩次、內容不同而結構相同的 pattern。

色彩、字級、間距進 theme；元件只接收真正會變的內容。先看 interface，不讓它順手建立完整元件庫。

審查 diff、並排看兩頁，再核對 build output，確認抽取沒有改變內容順序。

完成：你已用兩個真實使用點證明一個 theme／元件規則可以重用。

觀念檢查

什麼時候最適合抽出共用元件？

已經重複的版型提供明確介面與驗證樣本；還沒出現的需求不值得先抽象。

關鍵判斷

可重用的證據是兩個實際使用點，不是元件名稱看起來很通用。
