Phase 8 · Operate · 008-0005 · Completion proof

讓 oracle 對本次 run 下判斷，不讓 agent 批准自己

Entry：帶入 008-0001 已校準的 deterministic check，以及一般 branch 的 008-0004 run ledger，或日後 elective branch 返回的 recoverable maintenance evidence。Run ID、inputs、workflow revision、fixture 與 actual write set 必須可識別；缺一項都不能把 proof 綁到本次執行。

1. 先核對 proof 與 run 是同一件事

Identity核對方式常見假 green
InputsOracle 讀到的 ID／version／count 等於 run ledger。檢查到上一次成功 output。
Workflow／candidateExact revision、instructions 或 commit 可解析。只寫 branch、latest 或「目前版本」。
Fixture／scopeExpected output 在 allowed fixture，fixture 外 fingerprint 未變。目標結果正確但另有越界 mutation。
Run／timeEvidence 含 run ID、start／finish、exit 與 evidence path。Dashboard green 無法連回是哪一輪。

2. 重跑同一 oracle，保留原始 evidence

  1. 先保存 run ledger 與 outputs，不讓後續 check 自動修補結果；validator 若會 mutation，就不符合獨立 oracle。
  2. 用 008-0001 的 exact command／inspection 與 predicate 執行，不因 agent summary 調低門檻。保存 exit status、關鍵 output、environment 與時間。
  3. 逐項比對 input coverage、output invariants、error／skip 清單與 scope fingerprint；「總數相同」不能掩蓋 ID 重複或錯配。
  4. 抽一個可復原的 proof copy，重現先前校準的 disconfirming state，確認同一 oracle 仍會 fail；不要破壞本次 output。
  5. 把 direct observations、captured artifacts、agent inference 與 learner judgment 分開。Oracle pass 只證明其 predicates，不批准品質、風險或 production readiness。

Completion ≠ acceptance：Deterministic oracle 可以回答「是否符合明定 predicates」。若 artifact 品質、敏感資料、費用、rights、不可逆風險或例外是否可接受仍需 judgment，就保留 approval stop，讓 learner／owner disposition；模型不因 check green 取得批准權。

External evidence：本 canonical run 預期 external actions: none。若真實任務另有核准 side effect，completion proof 還須對上 target／payload、idempotency key、service receipt 與 postcondition；缺 receipt 不可用 local green 猜測 remote success。沒有 external action 不影響 self-study proof。

Tangible win：一份綁定 run／inputs／workflow／fixture identity，含 decisive oracle result、negative calibration、scope check 與 honest limits 的 completion proof。
Observable feedback：另一人能重新執行同一 oracle，讓反證 copy 失敗、讓本次 output 通過，並把 deterministic observation 與 agent inference／human acceptance 分開。

Validator exit 0，但檢查的是未標 run ID 的 shared output 目錄，該怎麼 disposition？

Deterministic 不只指命令可重跑；proof 必須識別本次 claim。未綁 identity 的 green 可能只是舊 output，不能由 agent 目測補足。

Legal stop／return／continuation：Oracle mutation output、identity 對不上、negative calibration 不再失敗、input coverage／scope fingerprint 不完整、partial／skip 未 disposition，或 judgment 被偽裝成 deterministic pass 時，保存 proof draft並回 008-0001 或相應 execution branch。Proof 完整後，進 008-0006 做 controlled failure／recovery exercise；現在仍不能 closeout。
