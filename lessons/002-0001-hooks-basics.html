控制 Claude Code 工具行為（hooks）

任務目標：理解 hooks 在 Claude Code 生命週期中何時執行，以及為什麼 exit 2 的效果必須依事件判斷。這一課先做最小的格式化 hook。

本課只做：理解 hook 何時會執行，以及 exit code 代表什麼。
先不要做：一開始就寫複雜 hook 取代人工 review。

三層模型

層機制性質
指引CLAUDE.md模型會參考，但不保證。
閘門permission rules決定工具能不能做。
自動化hooks固定時點執行 command、HTTP、prompt、agent 或 MCP tool。

Exit code 必須連同事件一起看

事件exit 2 的效果
PreToolUse工具尚未執行，可以阻擋並把 stderr 回饋給 Claude。
PostToolUse工具已經執行，不能回復動作；stderr 只作為回饋。
Stop阻止 Claude 結束，讓它依理由繼續處理。
exit 0 表示 hook 成功；其他非零通常是 hook error。需要 structured control 時，改用 exit 0 搭配 JSON，不要和 exit 2 混用。

觀念檢查

1. 想在工具執行後自動格式化，適合哪個事件？

格式化要等檔案被 Edit/Write 後才有東西可處理。

2. PreToolUse hook 想擋下動作並說明原因，該？

在可阻擋的 PreToolUse 事件，exit 2 會取消工具呼叫，stderr 會回饋給 Claude；同一 exit code 在其他事件可能有不同效果。
