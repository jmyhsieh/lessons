Phase 3 選修 · 第 14 課 · 約 45 分鐘 · Wayfinder

完成一張可處理的決策工作項目

本課成果：完成一張目前可處理的決策工作項目，並把答案更新回共享地圖。

本課只做：認領一張目前可處理的決策工作項目，留下完整答案，再更新共享地圖。
先不要做：同時打開所有工作項目，或順手開始最終功能。

先找目前真的能處理的項目

Wayfinder 把這種項目稱為 Frontier。一張工作項目必須同時符合三個條件：

  • 仍然開啟。
  • 前置問題都已解決。
  • 尚未被其他人或工作階段認領。
先認領再開始：在議題追蹤系統把工作項目指派給自己。聊天裡說「我來做」不能避免兩個工作階段同時處理。

只讀這張工作項目需要的資料

共享地圖
  ↓ 選一張目前可處理的工作項目
認領
  ↓
只讀本項目與必要的舊決策
  ↓
回答 → 留言 → 關閉 → 更新地圖

不要一次載入所有子項目。需要舊決策時，再沿連結打開相關資料，讓 Claude Code 的對話脈絡保持乾淨。

答案要留在兩個位置

位置內容
工作項目留言完整答案、證據與相關連結，完成後關閉工作項目。
共享地圖工作項目名稱、連結與一句答案摘要，不複製整份內容。

實作步驟

/wayfinder [map URL 或編號]

先只讀地圖，選排序最前、沒有被阻擋也沒被認領的工作項目。

若已有人認領，就回到地圖選下一張，不要搶同一張。

把判斷、證據與限制寫進工作項目留言，確認能回答原問題後再關閉。

補上一句答案摘要；若出現新的清楚問題，再建立新工作項目。下一張仍留給新的工作階段。

完成：你已完成一張決策工作項目，完整答案與地圖摘要也各自放在正確位置。

觀念檢查

開始處理工作項目前，第一個動作是什麼？

先確認它沒有被阻擋或認領，再指派給自己，才能避免平行工作互相踩到。

完整答案應該放在哪裡？

完整答案留在工作項目；共享地圖只保留名稱、連結與一句摘要。

回到一般交付流程

當地圖已沒有待解決的決策問題，就把已確認的答案帶回 /to-spec → /to-tickets → /implement。

主要閱讀：Wayfinder SKILL.md，並搭配Wayfinder 地圖速查表。

把工作項目留言與地圖摘要貼回 Claude Code，請它檢查完整答案是否只維護在一個地方。
