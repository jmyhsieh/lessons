讓已審查測試在 CI 執行

本課成果：一張 CI 證明卡，列出已審查測試的範圍、執行結果與限制。

不要宣稱全部介面都被保護：CI 只證明指定測試、環境與瀏覽器設定在該次執行的結果；易用性、完整無障礙與視覺品質仍需其他證據。

建立一張 CI 證明卡

請 Claude Code 檢查 CI 工作流程、支援瀏覽器、機密資料、產出保留政策與既有測試命令；先回報最小方案，不要直接編輯。

只加入產品明確支援的瀏覽器設定。報告、追蹤記錄與截圖可能含 token 或資料，必須限制存取與保留期限。

先在本機用相同命令通過，再確認 CI 結果與產出。證明卡要列出範圍、命令、瀏覽器設定、結果、保留政策與已知限制。

進階完成：你已有一張把已審查測試、真實 CI 結果與限制連在一起的證明卡。

觀念檢查

對外說明 Playwright CI 結果時，可靠的做法是什麼？

可信說法要列出實際測試、瀏覽器設定、執行結果與限制，並把敏感產出留在受控位置。
