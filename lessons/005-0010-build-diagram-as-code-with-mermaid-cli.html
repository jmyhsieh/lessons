用 Mermaid CLI 建立可審查的圖表即程式碼

進入條件／Code readiness：第 07 課的核心收尾已通過，而且新需求需要可 diff、可重跑的流程圖／關係圖；圖中每個節點與連線都能回到已確認的來源 ID。使用固定版本 Mermaid CLI 只建立一張圖表垂直切片，將原始碼、轉譯命令與輸出一起交給審查者。

本課只做：一個有界限.mmd source、一次 SVG 轉譯、一次事實／可及性／投影片適配審查。
先不要做：把整份簡報圖表化、把轉譯成功當成內容正確，或用圖中的箭頭自行創造因果關係。
完成邊界：這是選用 continuation。完成、跳過或失敗都不會增加或撤銷第 07 課的簡報完成；單張圖表與成功轉譯也不能單獨構成簡報交付收尾。

用固定版本 CLI 轉譯最小切片

# 應顯示 11.16.0；使用既有本機 Chrome，避免下載另一份 browser
PUPPETEER_SKIP_DOWNLOAD=true npx --yes @mermaid-js/mermaid-cli@11.16.0 --version

cat > diagram.mmd <<'EOF'
flowchart LR
  Source["Source · S01"] --> Claim["Verified claim · C01"]
  Claim --> Slide["Reviewed slide · P03"]
EOF

cat > puppeteer-config.json <<'EOF'
{"executablePath":"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome","args":["--no-sandbox"]}
EOF

PUPPETEER_SKIP_DOWNLOAD=true npx --yes @mermaid-js/mermaid-cli@11.16.0 \
  -p puppeteer-config.json -i diagram.mmd -o diagram.svg
test -s diagram.svg
shasum -a 256 diagram.svg

命令證據邊界：本課釘定 @mermaid-js/mermaid-cli@11.16.0，並假設本機 Google Chrome 路徑存在。版本、瀏覽器或輸出雜湊與紀錄不符時先停下來查明；不要無聲改用 latest。Hash 只能辨識輸出位元組，不能證明圖中主張。

實作清單

從已通過的故事板／主張台帳取一個流程或關係；列出來源 ID、箭頭語意、需要揭露的未知項目與文字備援。

限制在能回答問題的節點與邊；待確認主張保留 [待確認]，不要為了對稱補資料。

保存精確版本、命令、結束狀態、非空白輸出與雜湊；用瀏覽器打開 SVG，檢查裁切、字型備援、對比與 200% 縮放。

在實際尺寸檢查標籤文字的可讀性、投影距離與周邊內容；同時提供等價文字說明。依 005-0006重查主張／可及性。

若 .mmd、config 或 SVG 進儲存庫，建立不可變候選版本 SHA，再依 Repo Review contract分開做 Standards Review 與 Spec Review。任何修正都建立新 SHA，重跑轉譯、checks 與兩軸 Review。

具體成果：一組可由別人重跑的 .mmd、固定版本轉譯命令、非空白 SVG、雜湊、文字備援與精確 SHA Review evidence。
可觀察回饋：請審查者從來源 ID 逐一核對節點與箭頭，再於目標投影片只看圖重述其主張；記錄錯誤關係、無法理解的連線、被截斷文字與缺少的備援，修正後重新轉譯／審查。

觀念檢查

1. Mermaid CLI 轉譯成功後，哪個結論成立？

轉譯器只能證明這次輸入可轉成輸出；它不知道箭頭是否符合來源，也不會替你完成目標脈絡審查。

2. 哪一個需求適合進入本 elective？

圖表即程式碼的價值是可追蹤、可重跑的關係表達；它不應創造主張，也不能替代核心收尾。

返回與停止線

返回／續行：圖表、文字備援、目標投影片 check 與 Review 套件都通過後，直接回 課目表。若新需求改為版本控制 React 簡報，另選 005-0009 Open-Slide 簡報；兩個選修沒有先後依賴。

合法停止點：CLI／瀏覽器識別不符、事實 node 或箭頭無來源 ID、待確認主張被畫成已確認、SVG 為空、文字備援缺少、目標投影片不可讀、候選版本未固定，或 Review 發現未解決時，保留 source 與命令 evidence 後停止。回 005-0002或本課對應步驟修正；不可發布，也不可改寫核心收尾。
