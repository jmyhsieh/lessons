從 Claude Code 連接 Claude Design

本課成果：一張視覺工具選路卡；需要探索畫面時，再確認 Claude Design MCP 已連線。

Claude Code 是主場：畫面還沒決定，就讓 Claude Code 透過 Design MCP 建立與修改設計；畫面已決定、只要改 repo，就留在一般 code workflow。

建立一個可核對的入口

請 Claude Code 只讀判斷：你要比較兩個畫面方向，還是已經能直接實作？先不要改 repo。

claude mcp add --scope user --transport http claude-design https://api.anthropic.com/v1/design/mcp

先核對 server 名稱與官方 URL；這是 user scope，會供你的其他 projects 使用。

在 Claude Code 執行 /design-login，完成登入後用 /mcp 確認狀態。若來源或 URL 不符就停止。

完成：你已決定是否需要視覺探索；需要時，Claude Code 也已能使用官方 Claude Design MCP。

觀念檢查

版面還沒決定，想先看兩種方向，應先用什麼？

視覺方向尚未確定時，先在 Claude Design 看見並比較，比直接進 repo 容易調整。

關鍵判斷

你不必先離開 Claude Code 學一套新工具；需要視覺能力時，再把 Design MCP 接進目前工作流。

主要閱讀：Anthropic — Move between Claude Design and Claude Code。
