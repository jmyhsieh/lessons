Effort／cost只比較共同 frame 已實際記錄的項目用估計補空值
Judgment load記錄 learner intervention 的原因與品質把人工判斷當成零成本或錯誤

No synthetic certainty：可用 deterministic calculation 算 count、duration 或 rubric subtotal，但不得自動填 missing evidence、推論 qualitative quality、消除 conflict，或產生 keep／change／retire disposition。

Honest comparison：若某 run 的 environment、input、authority 或 candidate identity 不同，保留 observation，但標為 non-comparable。資料少就降低 claim，不用不透明加權製造精確感。

Tangible win：一份把 candidate／comparator、success／failure lanes、raw observations、scores、deviations 與 limitations 對齊的 comparative evidence record。
Observable feedback：Reviewer 能從任何 comparative finding 走回 exact run 與 artifact，並看見 missing、non-comparable、retry 和 material failure，無法只靠總分掩蓋。

Candidate 平均分較高，但有一次未授權 write；comparator 較慢但安全停止。應如何記錄？

Material failure 不得被平均、outlier removal 或較高品質分遮蔽；它需要獨立 disposition。

Legal stop／return／continuation：Run identities 對不上、raw evidence 不可追溯、frame deviation 未標、missing 被猜成數值或 material failure 被平均時停止，回對應 case set 修 record。Comparative lanes 可抽查後，續到 010-0006。
