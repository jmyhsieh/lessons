先讓 Claude Code 讀 repo，不改檔案

任務目標：在工作 repo 中讓 Claude Code 解釋專案結構、入口點與主要模組，全程不改檔。你要練的是「讓它讀 repo」與「驗證它讀得準不準」。

本課只做：讓 Claude Code 只讀 repo、整理地圖。
先不要做：批准 edit、write、install、delete 或 commit 類動作。
本課邊界：允許讀檔、允許唯讀查詢；不批准任何寫入、格式化、commit、install 或測試指令。若它要求修改檔案，直接拒絕。

實作步驟（做完打勾）

桌面 App 選工作 repo 並確認是 Manual；CLI 則 cd 到 repo 後執行 claude，確認是 default。工作目錄內讀檔與內建唯讀指令通常不會詢問；本課若出現任何寫入或非唯讀動作，一律拒絕。
