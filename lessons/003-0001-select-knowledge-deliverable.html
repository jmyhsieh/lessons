只選一個 artifact 分支

任務形狀選定分支第一個可 review 切片
要支持一個決策或說明發現報告一個發現／建議章節。
要讓受眾閱讀、採用或照著做文件一個可使用的完整章節。
主要 evidence 是列、指標或比較結果資料產物一個有 schema、來源與詮釋的表格／繪製。
要維護可搜尋、可互連的本機語料庫本機知識庫一個主題群集或 LLM Wiki 切片。

Artifact 格式是替代分支，不是必修順序。LLM Wiki、正規化、本機搜尋與表格查詢只在已選輸入／artifact 命中時插入；它們完成後仍回到共同主張、驗證與收尾。

寫下 route 選擇卡

  1. 選一個分支，寫下為何它最直接服務受眾的決策／用途。
  2. 定義最小可審查切片、目標格式、回饋提供者與本次不做的內容。
  3. 把 Route promise 寫成：artifact、來源沿革、learner judgment 與回饋缺一不可。
  4. 設定 合法停止點 為 知識交付收尾，而不是工具成功、讀完六課或產生第一版。
  5. 把選擇卡與下一課寫回 Return notebook。
具體成果：一張知識路線選擇卡，鎖定一個 artifact 分支與可審查切片。
可觀察回饋：另一個人能從卡判斷格式是否服務任務、哪些工具是 conditional、何時可停止，以及什麼 evidence 才算 route 收尾。
