只選一個 artifact branch

Mission shapeSelected branchFirst reviewable slice
要支持一個 decision 或說明 findingsReport一個 finding／recommendation section。

主要 evidence 是 rows、metrics 或 comparisonData artifact一個有 schema、來源與 interpretation 的 table／chart。

Artifact formats 是替代 branches，不是必修順序。LLM Wiki、normalization、local search 與 tabular query 只在 selected input／artifact 命中時插入；它們完成後仍回到共同 claims、verification 與 closeout。

寫下 route selection card

  1. 選一個 branch，寫下為何它最直接服務 audience 的 decision／use。
  2. 定義最小 reviewable slice、target format、feedback giver 與本次不做的內容。
  3. 把 Route promise 寫成：artifact、provenance、learner judgment 與 feedback 缺一不可。
  4. 設定 legal stop 為 Knowledge delivery closeout，而不是工具成功、讀完六課或產生第一版。
  5. 把 selection card 與下一課寫回 Return notebook。
Tangible win：一張 Knowledge route selection card，鎖定一個 artifact branch 與 reviewable slice。
Observable feedback：另一個人能從 card 判斷格式是否服務 mission、哪些 tools 是 conditional、何時可停止，以及什麼 evidence 才算 route closeout。
