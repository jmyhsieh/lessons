把一個 bounded question 交給 read-only subagent

任務：在可信 local repo 中，把一個只需蒐集檔案證據的問題交給 fresh Explore／Plan subagent，抽查引用後把摘要帶回 active route。

先寫 delegation contract

Active route / return point:
One bounded question:
Allowed paths and evidence:
Denied actions: Edit, Write, commit, network, external service
Expected answer shape: claim + file:line evidence + uncertainty
Stop condition:
Main-session spot check:
需要正確 isolation
大量 read-only 探索，不污染主對話 contextFresh Explore／Plan subagent；不給 Edit、Write 或外部 side effect authority。
另一條工作線需要改檔本課停止；改選 worktree lesson。Context isolation 不會隔離 filesystem。

執行最小 investigation

  1. 把問題縮成一個能由指定路徑回答的 fact，例如「哪個函式建立 session？」；不要委派整個 feature。
  2. 選目前介面可用的 read-only Explore 或 Plan subagent，逐字附上 allowed paths、denied actions、答案格式與 stop。
  3. 要求每個結論帶 file:line；證據不足時回報 uncertainty，不猜測、不改檔補證據。
  4. 主 session 隨機打開至少一個引用，確認 claim、path 與 line context 相符；不把 subagent summary 當 source of truth。
  5. 保存 delegation contract、摘要、抽查結果、未回答事項與 learner judgment。
Tangible win：一份 bounded read-only investigation record。
Observable feedback：摘要回答唯一問題、附可開啟的檔案引用，抽查相符，working tree 沒有因 investigation 改變。

Subagent 發現需要修改設定檔才能繼續查證，應怎麼做？

Read-only subagent 隔離的是 context，不會因為委派就取得 filesystem write authority；需要改檔時必須回到 selector 重新決定。

Legal stop／return：目前介面沒有 read-only subagent、問題無法縮成 bounded investigation、需要外部資料或需要修改檔案時，記錄 gap 後停止。把 record 寫回 Return notebook，狀態記為 Lesson practiced，返回 Targeted-remediation return point。
