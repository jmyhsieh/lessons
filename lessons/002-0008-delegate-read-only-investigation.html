把一個有界限的問題交給唯讀 subagent

任務：在可信本機儲存庫中，把一個只需蒐集檔案證據的問題交給全新探索／計畫 subagent，抽查引用後把摘要帶回目前路線。

先寫委派契約

Active route / return point:
One bounded question:
Allowed paths and evidence:
Denied actions: Edit, Write, commit, network, external service
Expected answer shape: claim + file:line evidence + uncertainty
Stop condition:
Main-session spot check:
需要正確隔離
大量唯讀探索，不污染主對話脈絡全新探索／計畫 subagent；不給編輯、寫入或外部副作用權限。
另一條工作線需要改檔本課停止；改選工作樹課程。脈絡隔離不會隔離檔案系統。

執行最小調查

  1. 把問題縮成一個能由指定路徑回答的事實，例如「哪個函式建立工作階段？」；不要委派整個功能。
  2. 選目前介面可用的唯讀探索或計畫 subagent，逐字附上允許的路徑、遭拒動作、答案格式與停止點。
  3. 要求每個結論帶 file:line；證據不足時回報不確定性，不猜測、不改檔補證據。
  4. 主工作階段隨機打開至少一個引用，確認主張、路徑與行號脈絡相符；不把 subagent 摘要當事實來源。
  5. 保存委派契約、摘要、抽查結果、未回答事項與 learner judgment。
具體成果：一份有界限的唯讀調查紀錄。
可觀察回饋：摘要回答唯一問題、附可開啟的檔案引用，抽查相符，工作樹沒有因調查改變。

Subagent 發現需要修改設定檔才能繼續查證，應怎麼做？

唯讀 subagent 隔離的是脈絡，不會因為委派就取得檔案系統寫入權限；需要改檔時必須回到選擇器重新決定。

合法停止／返回：目前介面沒有唯讀 subagent、問題無法縮成有界限的調查、需要外部資料或需要修改檔案時，記錄缺口後停止。把紀錄寫回 Return notebook，狀態記為 Lesson practiced，返回 Targeted-remediation return point。

路線導覽 · 即時工具箱

  • 沒有有效返回點時回工具箱目錄
  • 完成後回到 Return notebook 的指定補強返回點；沒有有效返回點時才使用目錄備援。

合法停止點：每個選定課程都返回呼叫端提供的 active route；工具箱本身沒有 Phase completion
