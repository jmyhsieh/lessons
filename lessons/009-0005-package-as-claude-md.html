Phase 9 · Standardize · 009-0005 · Conditional branch

把 repo-local workflow contract 寫進最窄的 CLAUDE.md scope

Entry：009-0003 已選 claude-md，規則只對一個明確 repository／path 生效，且帶入 repo instructions、proven contract、owner、tests 與 Review standards。這是 repo artifact authoring，從第一個 diff 起就跨過 Repo delivery boundary。

1. 先讀現況，再決定 placement

  1. 列出 root 到 target path 之間既有的 instruction files、immediate callers、checks 與 owner；不要假設新檔一定優先。
  2. 選能涵蓋目標檔案、又不外溢到無關路徑的最窄 scope。
  3. 遇到衝突時採較 local、較近期或有 tests 支持的 pattern，並把另一個 pattern 記為待裁決，不發明 hybrid。
  4. 只移植 contract 的 invariants、commands、authority、checks 與 stops；通用教科書內容留在它原本的 source of truth。

Instruction is not authority：CLAUDE.md 可以縮小行為、要求 ask 或 deny，不能授權 secrets、external writes、production mutation、push、deploy 或 human approval。每次執行仍服從當下 sandbox、tool permissions 與 task authority。

2. 用 recoverable fixture 與 fresh session 檢查

ProbeExpected observable evidence
In-scope 正例全新 session 能指出 exact applicable scope，依規則產生 bounded diff，並跑指定 check。
Out-of-scope path不把 local rule 錯套到 sibling path；若 precedence 不清便停止。
Disallowed action拒絕或要求新 authority，不把文字解讀成 permission。
Failure fixture保留 failing evidence，依 recovery 規則回復或 safe stop，不隱藏 skipped check。

Fresh-context rule：用新 session 或等價隔離 context，只提供 repository、exact candidate ref 與 task；不得貼回作者先前推理。記錄 candidate SHA、fixed point、prompt、applicable instruction path、diff 與 checks。

3. 回到 immutable Engineering Review

Candidate checklist
Tangible win：一個 bounded repository CLAUDE.md candidate，附 fresh-context probe 與 immutable Review checkpoint。
Observable feedback：新 session 能正確辨識 scope、遵守 required checks、對 out-of-scope／disallowed fixture 停止；兩軸 Review 能將 findings 綁到同一 candidate SHA。

Fresh session 能遵循 CLAUDE.md，但 Review 後修了一行模糊 authority。可以沿用原 Review 嗎？

任何 repo candidate mutation 都讓舊 immutable Review evidence 失效；需回 006-0008 的完整 contract。

Legal stop／return／continuation：若 repo scope、instruction precedence、owner、authority、required check 或 Review source 不清，或 fresh context 依賴舊聊天，停止並回 009-0003／009-0002。若有 finding，回 implementation 建立新 SHA，再由 006-0008 重跑兩軸。只有最終 SHA 無未解 finding且 fresh-context evidence 有效，才前往 009-0008-complete-standardization-closeout.html；不要再完成其他 package branch。
