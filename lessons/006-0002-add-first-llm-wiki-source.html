加入第一份真實來源

本課成果：一筆從可信資料加入 Wiki、仍能回到原文的更新。

第一份來源要小：選一份你看得完、知道作者或出處、之後能重新開啟的資料。先證明流程可用，再慢慢增加。
來源若是 PDF、Office 或掃描文件：可以先走選修 文件轉 Markdown，把已查核 Markdown 連同原始文件位置交回本課；這不是 Phase 5 的必修前置。

第一次更新

可以是一份專案筆記、一篇官方文件或一段會議紀錄。把檔案放進資料夾，或準備可直接讀取的連結。

請把這份來源加入剛建立的 LLM Wiki：
[貼上檔名或連結]

保留來源位置；資料沒有說的內容不要自行補上。
完成後告訴我改了哪些檔案。

從更新後的 Wiki 選一個說法，回到原始資料確認它沒有被寫反、誇大或斷章取義。

完成：你的 Wiki 已加入第一份真實來源，而且至少有一個說法可以回到原文確認。

觀念檢查

加入第一份來源後，最重要的檢查是什麼？

Wiki 是整理層，不是新的權威來源。先抽查一點，就能提早發現誤讀。

關鍵判斷

先加一份，先查一點。你不需要先懂 ingest；現在做的「把新資料交給 Claude Code 更新 Wiki」，就是最小版本。
