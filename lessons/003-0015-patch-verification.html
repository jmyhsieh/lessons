Phase 3 · 第 15 課 · 約 25 分鐘 · Patch verification

確認流程修正真的有效

目標：用第二輪 repo rehearsal 驗證 Phase 3 第 14 課的 workflow patch 是否真的改善流程。這一課只比較 patch 前後，不把一次成功直接固化成 runner、hook 或團隊平台。

本課只做：產出 patch 是否有效的第二輪證據。
先不要做：一次成功就直接固化成 hook 或平台。

Patch 要靠第二輪證據驗證

Claude Code best practices 強調給 Claude 可執行的驗證方式，並要求它展示 evidence，而不是只宣稱完成。Patch verification 把同一原則用在流程改進：第二輪 rehearsal 要能證明 patch 減少了問題，而不是只讓文件變漂亮。

Observability 能追蹤工具、延遲、token、成本與失敗位置；Cost tracking 提醒成本只是估算。這些訊號適合當輔助 evidence，但最重要的仍是 reviewer 能否更快判斷、gate 是否更清楚、handoff 是否少問問題。

只比較同類型任務

比較項Patch 前Patch 後
Clarifying questionsAgent 需要重問 scope 或驗收。Brief 已回答關鍵問題。
Gate clarityPass/fail 還靠模型判斷。有 command、artifact 或明確人工 owner。
Evidence accessReviewer 找不到檔案。Artifact path 可直接開。
Handoff quality下一個 agent 仍需問上下文。可用 handoff 接手。
Overhead流程比任務重。步驟變少或 downgrade。
判斷規則：patch verification 需要同類型小任務；拿不同風險、不同 repo、不同 gate 的任務比較，不能證明 patch 有效。

Patch verification note 範例

{
  "patchId": "finding-0048-01",
  "beforeRunId": "run-0048",
  "afterRunId": "run-0052",
  "sameTaskClass": true,
  "expectedImprovement": "brief states when link-check evidence is enough",
  "observedChange": "agent did not ask for test scope; gate evidence linked to link-check output",
  "result": "keep",
  "nextDecision": "update input contract reference; do not change runner"
}

實作步驟（做完打勾）

任務要和第一輪 finding 同類型：文件對文件、測試對測試、gate 對 gate。不要用更大或更高風險的任務驗證 patch。

在開始前寫一句可觀察的期待，例如「agent 不再重問 test scope」或「handoff 能直接指到 screenshot」。

照 Phase 3 第 13 課流程跑，不新增工具。保留 afterRunId、gate results、handoff 與 closeout decision。

只比較一到三個訊號：少問問題、證據更清楚、handoff 更能接手、流程更輕。不要補長篇心得。

keep 代表 patch 有效；revise 代表方向對但太弱；revert 代表 patch 增加成本或轉移問題。

你已完成 patch verification。回對話視窗貼上 verification note，請 AI 老師檢查這個 patch 是否值得保留。

觀念檢查（憑記憶作答）

1. 驗證 patch 最重要的是？

要證明 patch 有效，第二輪任務要和第一輪同類型。否則差異可能來自任務本身，不是 patch。

2. Patch 後流程更重，應該？

如果 patch 讓流程更重，應該 revise 或 revert，不應把成本更高的流程固化。

3. 一次 verification 最好比較幾個訊號？

比較一到三個與 patch 直接相關的訊號即可；太多訊號會讓判斷失焦。

下一步

若 verification 結果是 keep，接著進入 Phase 3 第 16 課：選擇最小 repo contract，把 verified workflow 放到下一個 agent 會自然讀到的位置。若是 revise 或 revert，回到 Phase 3 第 14 課重切 patch。
