初始化 Playwright Test Agents

今天只做一件事：在已有 Playwright Test 的 repo 產生 Claude Code 專用 agent definitions，並審查它們的邊界。

三個角色：planner 先寫可讀 test plan，generator 依核准 spec 產生 tests，healer 診斷與修復失敗。它們是可審查的工作流，不是免審自動駕駛。

建立可控的 agent 起點

請 Claude Code 找出 config、test directory、啟動方式與 Phase 8 第 04 課的 passing test；缺少地基就先停，不要直接初始化。

確認 diff 範圍後執行：

npx playwright init-agents --loop=claude

Playwright 升級後應重新產生，不要靠手改 generated definitions 維護舊版本。

確認生成檔只授予預期工具與目錄；把既有最小 passing test 當 seed，確認它使用真實 config、fixtures 與 app 起點。

完成：你已留下 generated agent definitions review note 與一個可重用 seed test。

觀念檢查

導入 Playwright Test Agents 的可靠順序是什麼？

先從已通過的 Playwright 地基生成 definitions，再審查工具、範圍與 seed test，才能控制後續產出。

帶走這個就好

Test Agents 把規劃、生成與修復分開；第一個進階能力是把每個角色的輸入、輸出與權限看清楚。
