建立 Playwright 測試代理

本課成果：一份 Playwright Test Agents 產生檔案的邊界審查紀錄。

三個角色：規劃代理（planner）整理測試規格，產生代理（generator）依核准規格寫測試，修復代理（healer）診斷失敗。每個結果都要人工審查。

先建立可審查的代理設定

請 Claude Code 找出設定檔、測試目錄、啟動方式與上一課已通過的測試；少任何一項就先停。

確認程式差異範圍後執行：

npx playwright init-agents --loop=claude

Playwright 升級後重新產生，不要靠手改產生檔維護舊版本。

確認產生檔只授予預期工具與目錄；起始測試（seed test）必須沿用程式庫真正的設定、測試資料與應用程式起點。

完成：你已留下代理產生檔清單、權限邊界與起始測試的審查紀錄。

觀念檢查

導入 Playwright Test Agents 的可靠順序是什麼？

先從已通過的測試地基產生設定，再審查工具、範圍與起始測試，才能控制後續產出。

關鍵判斷

先看清楚三個角色的輸入、輸出與權限，再讓它們處理真實測試。

主要閱讀：Playwright — Test Agents。

入門完成線：第一個持久測試 · 下一課：審查測試規格
把產生檔清單與起始測試貼回 Claude Code，請它檢查工具與目錄是否超出必要範圍。
