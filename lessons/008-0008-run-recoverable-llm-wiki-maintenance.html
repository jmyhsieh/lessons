Phase 8 · Operate · 008-0008 · Conditional maintenance branch

在 raw-source boundary 內維護一次既有 LLM Wiki slice

Entry：Mission 明確需要維護 Phase 3 已完成且已 review 的 LLM Wiki slice；raw source pack、stable source IDs、provenance、既有 revision identity，以及 008-0001 deterministic check 和 008-0003 authority envelope 都存在。若要建立第一個 slice，應回 003-0007；本課不把維運頁面變成新的 Knowledge source of truth。

Source-of-truth rule：Changed wiki page、generated summary、internal link 與 machine-readable export 都是 derived artifacts。只有原始 source pack 與 claim-level locator 能支持 material claim；maintenance 不得用舊 wiki 文字反向證明新 claim，也不得默默替換、刪除或擴大來源集合。

2. 先比較，再更新最小 slice

  1. 在 recoverable fixture 複製既有 revision，驗證 restore 能重建原始 pages、links、exports 與 review log；不要直接在唯一 working copy 練習。
  2. 以 stable source ID 比對 raw source change，只列出 added、changed、removed、conflict 與 unchanged claims。來源版本或 rights 不明時停止，不讓 agent 猜測差異。
  3. 用相同 input boundary 執行 read-only preview，記錄預測的 page／link／export write set。Preview 超出 topic cluster 或需要讀取未授權資料時回 authority gate。
  4. 建立唯一 run／idempotency identity，只對最小 affected cluster 執行一次 update；保存逐檔 before／after fingerprint、source locator diff、actual write set 與 command output。
  5. 逐頁重跑 title、source references、internal links、duplicate／blank-page、export 與三個 material-claim trace checks；actual scope 必須等於 envelope。
Maintenance evidence checklist

3. 保存可退回的 maintenance evidence

Evidence另一人必須能觀察
Source delta哪個 raw source identity 觸發哪一個 claim／page change；derived wiki 不是證據來源。
Artifact delta新增、修改、刪除或保留哪些 pages、links、exports，且沒有 cluster 外 mutation。
Verification同一 oracle 對 baseline／disconfirming copy 失敗或指出 stale state，對 maintained fixture 通過。
RecoveryRestore 能回原 revision，或 checkpoint 能安全重跑而不產生 duplicate／orphan pages。
JudgmentReviewer 對 unsupported、conflict、omission、rights 與 limitations 的 disposition；agent 不批准自己的 maintenance。

Maintenance boundary：Canonical hands-on 只更新 recoverable local fixture。若真實 wiki 位於 shared／remote system，本課只建立可檢查的 change set 或 payload preview；發布、同步、push、deploy、通知與刪除 remote content 都需要另行 authority、approval、receipt 與 recovery，不是本選修的 completion requirement。

Tangible win：一次具 raw-source delta、bounded artifact diff、revision identity、restore／retry evidence 與 review log 的 recoverable LLM Wiki maintenance run。
Observable feedback：Reviewer 能由每個 changed claim 回到 raw source locator，重建 before／after cluster，確認 cluster 外未變，並在 restore 後得到原 revision；這份 evidence 可回到 Operations completion proof，而不取代 Phase 3 Knowledge evidence。

Maintenance 後 wiki summary 新增一個合理結論，但 raw source pack 找不到 locator，該怎麼做？

Maintenance 只更新 derived artifact；原始 sources 與 claim-level provenance 仍是 Knowledge source of truth，不能由 wiki 或 agent 自我背書取代。

Legal stop／return／continuation：Raw source identity／rights 不明、existing revision 不可重建、restore 未實測、preview 或 actual scope 超界、source locator 缺失、link／export／claim check 失敗、partial／duplicate 未 disposition，或 external write 未另行核准時，保存 checkpoint 後停止；source／artifact 問題回 Phase 3 Knowledge verification，authority 問題回 008-0003。Maintenance evidence 完整後立即進 008-0005，用同一 deterministic oracle 建立 completion proof；不要接著擴寫其他 clusters，也不要宣稱 Phase 8 或 Knowledge route 已完成。
