用 MarkItDown 轉換一份文字型文件

本課成果：一份由 MarkItDown 產生、尚待人工查核的 Markdown 檔。

MarkItDown 是輕量轉換器：它適合有文字層的 PDF 與 Office 文件。基礎套件不會自動替掃描 PDF 做本機 OCR；轉出空白或亂碼時不要硬修輸出，先回到第 01 課改路線。

讓 Claude Code 完成一次轉換

請檢查目前環境是否已有 MarkItDown。
如果還沒安裝，請提出隔離安裝方案與完整命令，先不要執行。
目標只轉換 docs/vendor-guide.pdf，輸出到 converted/vendor-guide.md。
不要覆寫原檔，也不要把文件傳到雲端。

審查來源、輸出位置與安裝範圍後再核准。官方 CLI 的核心形式是 markitdown input.pdf > output.md；實際命令以目前版本與 Claude Code 查到的環境為準。

打開 Markdown，確認輸出不是空檔，而且看得到原文件的標題與主要段落。這一步只證明轉換器有輸出，不代表內容與原檔一致。

完成：你保留原始文件，並得到一份可供下一課逐項對照的 Markdown。

觀念檢查

MarkItDown 輸出檔成功產生後，能證明什麼？

命令成功只證明有輸出；表格、頁面與 OCR 品質仍需與原始文件對照。

關鍵判斷

MarkItDown 先解決「把可讀文字轉成 Markdown」；若輸入沒有可靠文字層，應換 Docling，而不是假設基礎套件有 OCR。

主要閱讀：Microsoft MarkItDown README、MarkItDown on PyPI。
