Phase 11 · Roll out · 011-0006

只收最小 feedback，並用 tabletop 證明可停可回

Entry：Review/escalation map 已能處置 scope drift、unexpected data、workflow mismatch 與 blocking findings。本課設計 task-level feedback，並在 disposable local fixture 演練 pause／rollback；沒有真實參與者或 production state。

2. 注入 failure，演練 pause 與 rollback

  1. 在 disposable copy 先保存 known-good fixture hash 與空 output inventory。
  2. 注入一張標記 suspected-real-data 的假事件卡；operator 必須在讀取內容前 pause、記錄 trigger、通知 stop authority。
  3. Rollback：刪除本次 output、還原 known-good fixture copy、重跑 inventory／hash／zero-secret checks；保留最小 incident record，不保留注入內容。
  4. 只有 checks 再次 PASS 且 accountable owner 明確記錄 resume-tabletop 才可繼續；否則維持 stopped。

Tabletop evidence format：記錄 exercise ID、start state、injected event、observed stop、rollback steps、restored checks、human resume／stop decision、limits。不要寫成真實 incident、user impact 或 production recovery。

Rollback ceiling：本次只證明 local fixture 的 planned steps 可被演練。它不證明 production rollback、災難復原、資料刪除合規、SLA 或任何外部系統可恢復。

Tangible win：一份 non-surveillant feedback register，加上一筆在 disposable fixture 可追溯的 pause／rollback tabletop record。
Observable feedback：Reviewer 能確認注入事件先觸發 pause、known-good state 被恢復、resume 由人決定，且沒有個人監控或 production claim。

Local rollback checks 全部恢復 PASS 後，可以自動 resume 嗎？

恢復證據與人類決策必須分開；checks 不能批准自己的 continuation。

Legal stop／return／continuation：Feedback 需要監控個人、pause trigger 不可觀察、rollback 無 known-good state、恢復 checks 失敗或 resume authority 不明時，維持 stopped 並回前課修正。Tabletop record 完整後，續到 011-0007。
