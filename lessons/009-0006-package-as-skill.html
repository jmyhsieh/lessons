Phase 9 · 標準化 · 009-0006 · Conditional branch

把跨 workspace 的 bounded instructions 包成 reusable Skill

進入條件：009-0003 已選 skill，因為同一 proven workflow 需要跨 workspace 被正確觸發，且 contract、audience、dependencies、owner 與 distribution boundary 都清楚。Skill 是 instruction package，不是 workflow proof、tool installer、permission grant 或 universal policy。

能力邊界：Skill 可以指示如何使用已可用的 capability，但不能創造 tool、credential、sandbox access 或 approval。缺 dependency 時應輸出 gap 與 safe stop，不得偷偷安裝、改全域設定或改用未授權服務。

2. 用 trigger matrix 驗證選擇性

測試材料預期結果
精確的正向任務觸發 Skill，讀取最少必要 resources，依 contract 產生 evidence。
近似但不符合的任務不觸發，或先指出缺少的 decisive input。
缺少 dependency停止並列出缺口，不安裝、不擴權。

3. 在 fresh context 重跑 package

  1. 建立隔離 fixture，只安裝或掛載 exact Skill package 與 declared dependencies；不要帶入作者 session。
  2. 以一個正例與至少一個 near-miss 執行；保存輸入、是否觸發、載入 resources、steps、check output 與 stop reason。
  3. 由另一位 reviewer 比對 Skill behavior 與 extracted contract，確認 package 沒新增 promise、authority 或 hidden dependency。
  4. 任何修訂都增加 package version／digest並重跑受影響 fixtures。
Package 證據
可見成果：一個有 bounded trigger、progressive resources、version／owner 與 fresh-context fixture evidence 的 reusable Skill package。
可觀察回饋：正例會選中並完成 declared checks；near-miss 不誤觸發，缺 dependency／authority 時安全停止，reviewer 能把 behavior 逐項追到 workflow contract。

Skill 在 fresh context 發現缺少 CLI dependency，contract 未授權安裝。正確行為是？

Package 不會擴張 capability 或 authority；missing dependency 是可觀察的 stop，不是繞過邊界的理由。

合法停止／返回／續行：Trigger 無法區分 near-miss、resources 重複 truth、dependency／distribution／owner 不明、fresh context 依賴 personal state，或 Skill 擴張 authority 時，保存 fixture evidence 並回 009-0003／009-0002。只有 exact package version 通過正例、near-miss、missing-dependency 與 failure checks，才前往 009-0008-complete-standardization-closeout.html；不要再完成其他 package branch。
