把三頁簡報改成一頁摘要

今天只做一件事：請 Claude Code 透過 Design MCP，把已核准三頁改作成可獨立閱讀的一頁摘要。

不是把三張縮小：重用已確認的內容，重新排成一頁閱讀順序。

完成一頁摘要

現況一句、證據一句、下一步一句；你要對照 approved storyboard，刪除任何新主張。

告訴 Claude Code 這份內容會獨立閱讀，不能依賴講者補充，也不能只是把三張縮小。

請他說出重點與下一步；若需要你口頭解釋，回去補足一頁內容。

完成：你已把同一組可信內容改作成能獨立閱讀的一頁摘要。
