比較兩個不同方向

今天只做一件事：請 Claude Code 透過 Design MCP 產生兩個方向，再依事先寫好的標準選擇。

先寫標準再生成：例如「最容易找到主要按鈕」。這能避免只選第一眼最好看的版本。

做一次簡單比較

只選一個：容易理解、容易操作或更符合品牌。不要一次做完整評分表。

透過 Design MCP 要求內容相同、版面安排不同，並回傳兩個可查看版本；只換顏色不算真正不同。

格式：「我選 B，因為主要按鈕更容易找到。」

完成：你已用一個可說明的標準選出方向，而不是只說「我比較喜歡」。

觀念檢查

什麼時候應該先寫選擇標準？

先寫標準能讓比較聚焦在任務，而不是事後替個人偏好找理由。

帶走這個就好

初學者只比較兩版、使用一個標準即可。複雜比較矩陣留到高風險設計決策再用。
