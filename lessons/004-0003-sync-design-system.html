給一份正確的視覺參考

今天只做一件事：把一份核准過的視覺參考交給 Claude Code，明確說明 Design MCP 可以學什麼。

不要一次丟很多：第一輪只用一張核准過的截圖、既有頁面或品牌範例，能減少互相衝突的風格訊號。

加上一份 context

優先用自己的既有產品、核准簡報或品牌資產；先確認 Claude Code 能讀到該檔案，不要用來源不明的設計。

例如「透過 Claude Design 參考這張圖的按鈕風格與資訊密度，不要複製內容」。

請 Claude Code 重述 include／exclude；確認它沒有把參考圖當成完整需求，再交給 Design MCP。

完成：Claude Code 已把一份清楚的參考與禁止照搬項目交給 Design MCP。

觀念檢查

加入參考圖時，還要補上什麼？

明確指出要參考的部分，才能避免 Claude 猜錯重點或整張照搬。

帶走這個就好

入門先學會提供一份清楚 context；完整 design system 匯入與 /design-sync 留到真的需要團隊一致性時再學。
