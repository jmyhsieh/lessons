Phase 12 · Govern · 012-0006

同時演練 material change 與 retirement

Entry：帶入 charter、change control、risk register、data lifecycle、current package 與 clean local fixture。Exercise 比較「批准新 version」與「退休 workflow」兩條路，兩者都只作用於 disposable fixture。

1. Change lane：新來源改變輸出規則

Proposed vNext / changed source and behavior:
Impact on promise, permissions, data, risk and cost:
Required approver / recertification / regression cases:
Decision: approve-for-fixture | revise | reject
Retest result / rollback result / open findings:

若 approval、source recertification 或受影響 test 缺失，vNext 保持 proposed；current version 不被靜默覆寫。若 test 失敗，依既定 rollback point 恢復 exact prior version，並保留失敗 evidence。

2. Retirement lane：owner 或維護能力消失

步驟有 successor沒有 successor
Disable停止 current fixture entry，保留 stable notice停止 entry，明列沒有替代方案
Archive／delete保存 policy、version、decision、evidence lineage；依 lifecycle 刪工作資料同左，不因無 successor 無限保留資料
Carryover／reopen逐項說明哪些 evidence 可帶入 successor，重新做 readiness記錄 reopen trigger：新 owner、可維護 source 或新 mission
Exercise checklist

Tabletop boundary：Disable、archive、rollback 與 successor 都是 local artifact 操作。Exercise PASS 不證明真實服務下線、使用者通知、contract 終止、資料刪除義務完成或 organization approval。

Tangible win：一份同時證明 change fail-closed、version rollback，以及 retirement disable/archive/successor-or-none/reopen 流程可重查的 tabletop record。
Observable feedback：Reviewer 能辨認哪個 version 仍有效、何者被拒絕或退休、資料如何處理，以及沒有 successor 時如何誠實停止。

退休 workflow 但沒有 successor，正確 record 是？

沒有 successor 也是有效 disposition；不能因此重用 identity、繼續運作或造出替代方案。

Legal stop／return／continuation：Change approval/retest 或 retirement owner/disable/archive/data/successor disposition 任一失敗時，保留 exercise FAIL，回相應控制修正。兩條 lane 可重播後續到 012-0007。
