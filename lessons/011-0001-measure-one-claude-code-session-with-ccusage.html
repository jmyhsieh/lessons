用量與查找工具 · 工具實作卡 01 · 約 15 分鐘

用 ccusage 記錄一個 Claude Code 工作階段的用量

本課成果：一張工作階段用量基準卡，記下模型、token 分布與下次比較方式。

先量再談省：ccusage 讀取本機 Claude Code 使用紀錄，適合比較不同工作階段的用量。它不能判斷成果品質，也不是 Pro／Max 剩餘額度的權威來源。

留下第一個看得懂的用量基準

請唯讀檢查這台電腦是否可使用 Node.js 與 npx，並查看 ccusage 最新版的 --help。
先提出查看 Claude Code 工作階段用量的命令，不要執行。
不要修改程式庫，也不要把本機使用紀錄傳到外部服務。

目前可先以 npx ccusage@latest claude session 查看工作階段報表；若 --help 顯示的子命令不同，以實際版本為準。第一次使用 npx 可能下載套件，確認來源與版本後再同意。

輸入／快取／輸出 token：________________

比較時要選相近的工作與完成條件；不要拿「改一行文字」和「跨模組除錯」直接比高低。

觀念檢查

這張 ccusage 報表最能告訴你什麼？

ccusage 可整理本機使用紀錄；成果品質仍要靠測試與審查，訂閱方案的額度則以官方產品介面為準。

關鍵判斷

用量只是比較起點。要判斷工具是否值得保留，還要看同類工作是否完成、花了多久，以及驗證是否通過。

主要閱讀：ccusage README；工具選擇與停止線見 Claude Code 用量與查找工具路線卡。
