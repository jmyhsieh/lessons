相容性入口 · 原 Phase 1 第 11 課

「從探索到 commit 的安全四步驟」已拆入 Build route

穩定公開網址識別：lessons/001-0011-explore-plan-implement-commit

轉接原因

原本把 route choice、implementation、review 與 closeout 放在單一課；現在依不同 evidence boundary 拆成四個最終課程。這是選擇式 transition，不會自動替你挑一個中途步驟。

何時選哪個最終目標

先選 route

何時選：尚未界定交付類型、readiness 或 legal stop。

前往 Engineering route entry

進入 implementation

何時選：已有 approved plan，要實作並建立 immutable review checkpoint。

前往 implementation

執行 final review

何時選：已有固定 checkpoint，要完成 Standards 與 Spec review。

前往 final candidate review

完成 closeout

何時選：final checkpoint 已 review，現在要記錄 checks、disposition 與交付邊界。

前往 Engineering closeout

證據沿用

若你已保存舊課的 diff、commit 或 verification record，可保留為 Lesson practiced；只有 readiness check 確認它仍滿足目前 route stop 時，才可作為 current route input。它不會跳過尚缺的 Build evidence，也不會自動成為 Route artifact 或 completion。
