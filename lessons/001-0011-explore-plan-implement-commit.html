Phase 1 · 第 11 課 · 約 20 分鐘 · 完整流程

從探索到 commit 的安全四步驟

任務目標：用 Claude Code 跑完一次官方建議的四階段開發流程。這一課只練流程節奏，確認結果並整理 context放到下一課。

本課只做：練一次探索、規劃、實作、commit 的安全節奏。
先不要做：跳過 plan 或 review 直接要求它大量修改。

四階段流程

階段模式你要把關的事
Exploreplan mode它讀哪些檔？有沒有問清楚需求？
Planplan mode計劃是否列出檔案、步驟、風險？
Implementdefault逐項批准，讀 diff，不接受看不懂的改動。
Commitdefault看完整 diff，寫清楚 commit message。
一句話能描述 diff 的小改可以省略 plan；跨檔、不熟、方向不確定，就完整跑四階段。

實作步驟（做完打勾）

半天內做得完、出錯可回復、範圍清楚。不要拿部署、資料庫 migration 或大型重構當第一次練習。

Use plan mode. Explore the relevant files and propose a plan.
List files you expect to modify. Do not edit yet.

計劃過關後離開 plan mode。每次修改都看過再同意；看到偏離範圍就拒絕。

桌面 App：先點 diff stats 或打開 diff pane 看完整變更。若 / 清單有 /diff，也可當快捷。確認後再請它產 commit message 草稿，你審過才 commit。

🎉 完成！你已經跑完一次四階段流程。

觀念檢查
