用格式檢查（Lint）修一個 Wiki 問題

本課成果：一項由唯讀格式檢查（lint）找出並修好的 Wiki 問題。

格式檢查先找問題，不先大改：它檢查矛盾、過期說法、孤兒頁、缺少連結與資料缺口；你決定先修哪一項。

先報告，再修一項

請對目前 LLM Wiki 做一次唯讀格式檢查，先不要修改檔案，也不要上網補資料。

請分組列出：
- 互相矛盾或可能過期的說法
- 沒有被連到的孤兒頁
- 缺少來源或交叉連結的內容
- 值得後續補資料的缺口

每項附上檔案位置，並依影響排序。

優先選有原始資料可以回查、範圍清楚的問題。資料不足的項目只標記待確認，不讓 Claude Code 猜答案。

只授權修正選中的問題，查看程式差異，再請 Claude Code 確認該問題已消失且沒有新增壞連結。

完成：你已用格式檢查找到真正的問題、修好一項，並用同一檢查確認結果。

觀念檢查

Wiki 格式檢查的主要用途是什麼？

格式檢查是健康檢查：先找矛盾、過期、孤兒頁與缺口，再由人決定怎麼處理。

關鍵判斷

一次格式檢查不必修完整個 Wiki。報告、選一項、修正、重跑，這個小回圈才是可持續的維護方式。
