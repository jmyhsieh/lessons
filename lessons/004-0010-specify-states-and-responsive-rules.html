補齊狀態與響應式規則（responsive rules）

本課成果：一張狀態與畫面寬度表（state × viewport matrix），由工程師核准後再實作。

矩陣不是列出所有可能：只涵蓋這條任務真正會遇到的 default、loading、empty、error、success，以及窄／寬兩種代表尺寸。

完成一張小矩陣

讓它只讀現有 UI 與資料流，寫出進入點、主要動作與完成結果；不要把整個產品放進同一張矩陣。

狀態：default / loading / empty / error / success
尺寸：窄版 / 寬版
每格：看見什麼、能做什麼、下一步是什麼

請 Claude Code 透過 Design MCP 生成窄版 error 與 empty；確認文字、主要動作與復原方式沒有消失，再決定是否擴大。

完成：你已把設計從單張理想畫面，擴成能交給實作者與測試者的狀態規則。

觀念檢查

狀態矩陣主要補上哪個缺口？

矩陣讓 loading、empty、error 等真實狀態在不同尺寸都有明確行為。

關鍵判斷

響應式設計不只是縮放；狀態、內容優先序與復原動作都可能隨尺寸改變。
