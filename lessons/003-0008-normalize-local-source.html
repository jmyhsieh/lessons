第 3 階段 · 交付 · 003-0008 · Conditional 分支

只把目前 source 正規化成可檢查的工作副本

進入條件：原始來源可合法處理，但其 PDF、Office、影像或版面讓主張擷取不可靠。可讀 source 不需轉換；MarkItDown 與 Docling 是二選一，不是連續必修。

依來源型態選一個工具

選擇適合必查邊界
MarkItDown 工具需要輕量 Markdown 工作副本，原檔結構相對直接。輸出服務文字分析，不代表人工版面保真度；處理程序 I/O 權限必須受限。
Docling 工具版面、表格、OCR 或結構化輸出需要較細檢查。限制輸入／輸出；遠端服務與外部外掛未明確授權時保持關閉。

  1. 在隔離環境閱讀目前官方說明，只選一個轉換器與最窄輸入範圍；原始檔案保持不變。
  2. 輸出到獨立工作目錄，記錄工具、時間、選項與正規化檔案版本識別。
  3. 抽查開頭、含表格／圖像的一段與結尾；比較標題、閱讀順序、數字、連結、註腳與缺漏內容。
  4. 把錯置、OCR 不確定性與缺少元素標在轉換紀錄；不得靜默修成看似合理的文字。
具體成果：一份不覆蓋原始來源、帶轉換紀錄的正規化工作副本。
可觀察回饋：審查者 能用抽樣位置重做原始／正規化對照，辨識工具選擇、遠端 邊界 與至少一項已檢查的保真度風險。

一份可直接閱讀的 Markdown 來源已有穩定識別碼，下一步應該是？

正規化只修正目前 source 的可用性缺口；沒有缺口就不增加衍生副本。

返回／合法停止：抽樣保真度可接受且 限制 已記錄後，回 003-0003；工具成功不是路線完成。若權利、敏感資料政策、輸入邊界、遠端行為或數字／閱讀順序無法驗證，保存原始來源與失敗紀錄後停止，改用人工擷取或回 準備度。
