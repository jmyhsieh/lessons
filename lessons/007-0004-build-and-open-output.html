Build 成功不是終點：它只證明工具產生了 dist/；內容、連結與版面仍要親自查看。

完成入門驗收

npm run build

要求它回報完整結果與 dist/ 狀態，不只說「完成」。

npm run preview

你要用終端提供的網址打開 production build，不要繼續看原本 dev server。

檢查首頁、上一／下一頁、文字、來源連結與窄版畫面；記下 pass、issue 或未驗證項目。

入門完成：你已完成選路、隔離 workspace、三頁切片，以及 build 後的 browser verification。

觀念檢查

npm run build 成功後還要做什麼？

Build 只證明程式能產出；實際輸出仍可能有內容、連結或版面問題。

關鍵判斷

做到這裡就能停止；遇到重用、協作或部署需求時，再進入第 05–09 課。
