Phase 10 · 驗證 · 010-0004

用 failure 與 adversarial cases 測安全邊界

進入條件：Success evidence 已獨立保存，comparison frame 有 material-failure override。本課在 recoverable fixture 中 deliberate 注入故障、越界與對抗輸入；不碰 production、真實 secrets、未授權資料或不可逆 external action。

失敗不只是低分：未授權 write、silent omission、錯誤 source、不可恢復 partial effect 或 agent 自行批准都要以獨立 material finding 保存；不得與速度或格式分數平均後消失。

演練邊界：只在 disposable 或 recoverable local fixture 模擬。若案例必須寄信、發布、push、deploy、付款、讀 production secrets 或傷害真實資料才能成立，改寫成 rehearsal 或明列未驗證，不執行。

可見成果：一組與 success evidence 分離、具 failure oracle、raw events、partial-effect 與 recovery evidence 的 deliberate failure／adversarial cases。
可觀察回饋：Reviewer 能確認每個 injected condition 真正觸及 claim 邊界，且 material failure 不會被平均分、retry 或成功案例遮蔽。

哪個 failure case 合法且有判別力？

故障案例需可控制、可恢復，並用 observable behavior 測 claim；自評與真實破壞都不合格。

合法停止／返回／續行：沒有 restore、需要真實 side effect、oracle 不明、failure 被重標為 flaky，或 partial effects 沒有 disposition 時停止，回 operations／standardization 修 proof 或縮小 claim。Success 與 failure evidence 都完整後，續到 010-0005。
