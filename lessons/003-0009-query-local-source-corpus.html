第 3 階段 · 交付 · 003-0009 · Conditional branch

用 QMD 找候選 evidence，再親自打開原文件

進入條件：Active sources 是已核准的 local markup corpus，而且人工逐檔查找成本過高。只有少量已知文件時，直接閱讀，不需要建立 search collection。

Misses, ranking uncertainty, next query:
  1. 依 current official QMD documentation建立一個明確命名、範圍最窄的 collection；確認 ignore rules、local model storage 與首次下載是否符合 policy。
  2. 補上 collection context，先跑 keyword search，再於 mission 需要同義概念時跑 semantic／hybrid query；保存 exact query 與 result IDs。
  3. 不要把 snippet 或 ranking 當 evidence。打開命中的原文件，記錄 source ID、section／line range 與它實際支持的 claim。
  4. 用一個已知存在的 phrase 檢查 recall；若找不到，記為 retrieval miss，調整 scope／context 或回 manual search。
具體成果：一份含 exact queries、result IDs、opened source locators 與 retrieval misses 的 local corpus search log。
可觀察回饋：Reviewer 能重跑一個 query、打開同一份原文件，並指出 result ranking 與 claim evidence 之間的差別。

QMD 的第一名結果摘要正好回答問題，下一步是？

Retrieval result 是候選 evidence；只有原文件與 locator 能進入 source-to-claim ledger。

返回／合法停止：取得足夠候選 evidence 或確認 retrieval gap 後，停止搜尋並回 003-0003；QMD 不是必修索引層。若 collection scope、privacy、model download、index freshness 或 recall 無法接受，保存 query log 後停止，改用 manual search，不以空結果證明資料不存在。
