第 1 階段 · 定向 · 001-0007 · Code readiness stop

把 bounded edit、diff 與 checks 組成 readiness evidence

任務：只在 recoverable fixture 中執行 001-0006 的計畫，review exact diff、跑既有 checks，並建立一個可辨識的 local checkpoint。

執行與驗證

  1. 確認目前目錄是 fixture，working tree 起始狀態已記錄，且沒有敏感 remote side effect。
  2. 請 Claude Code 嚴格依核准 plan 修改唯一檔案；遇到新檔案、dependency 或額外範圍就停止。
  3. 親自查看 exact diff，確認每一行都服務原目標。
  4. 執行 plan 中的 repo-specific check，再執行 git diff --check。
  5. 只在 checks 通過且 diff 正確時建立 local commit；記下 commit、commands 與結果。
證據 bundle：fixture identity、起始狀態、approved plan、exact diff、check commands／results、local checkpoint、learner judgment、尚未驗證事項。
具體成果：一份 Code readiness evidence bundle。
可觀察回饋：checkpoint 只包含預期檔案；既有 check 與 git diff --check 通過；Return notebook 能指出這是 fixture practice。

哪一個 closeout claim 符合本課證據？

Readiness evidence 有明確環境與範圍；它不會自動升級成真實 repo deliverable 或 production authorization。

Code readiness 合法停止點：把 bundle、learner judgment 與 feedback 寫進 Return notebook 後即可停止。狀態是 Lesson practiced 與 已證明 Code readiness，不是 Route artifact produced。若新 mission 要交付 repo change，沿下方 continuation 進入 canonical Engineering route。
