第 1 階段 · 定向 · 001-0007 · 程式碼作業準備度停止點

把有界限的編輯、diff 與 checks 組成就緒證據

任務：只在可復原的練習環境中執行 001-0006 的計畫，審查精確差異、跑既有 checks，並建立一個可辨識的本機檢查點。

執行與驗證

  1. 確認目前目錄是 fixture，工作樹起始狀態已記錄，且沒有敏感遠端副作用。
  2. 請 Claude Code 嚴格依核准計畫修改唯一檔案；遇到新檔案、依賴項目或額外範圍就停止。
  3. 親自查看精確差異，確認每一行都服務原目標。
  4. 執行計畫中的儲存庫專用檢查，再執行 git diff --check。
  5. 只在 checks 通過且 diff 正確時建立本機提交；記下 commit、commands 與結果。
證據套件：練習環境識別、起始狀態、已核准計畫、精確差異、檢查命令／結果、本機檢查點、學習者判斷、尚未驗證事項。
具體成果：一份 Code 就緒證據套件。
可觀察回饋：檢查點只包含預期檔案；既有 check 與 git diff --check 通過；Return notebook 能指出這是練習環境實作。

哪一個收尾聲明符合本課證據？

準備度 evidence 有明確環境與範圍；它不會自動升級成真實儲存庫交付成果或正式環境授權。

Code readiness 合法停止點：把套件、學習者判斷與回饋寫進續作筆記本後即可停止。狀態是 Lesson practiced 與 已證明 Code readiness，不是 Route artifact produced。若新任務使命要交付儲存庫變更，沿下方 continuation 進入標準工程路線。
