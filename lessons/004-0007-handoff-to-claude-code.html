相容性入口 · 原 Phase 4 第 07 課

設計交接已拆成套件與任務選定的 continuation

穩定公開網址識別：lessons/004-0007-handoff-to-claude-code

轉接原因

原課把設計收尾、工具準備與儲存庫實作入口綁成單一路線；新版先完成可審查的交接套件，再依真實任務選擇後續，不假設每份設計都必須立即進入 Claude Code。

何時選

組裝 Design handoff bundle：原型假設已驗證，現在要封存意圖、狀態、規則、evidence 與已知限制，完成設計路線停止點。
選擇即時工具箱課程：下一步需要先補一個具體工具能力或快速驗證測試，再回到原任務。
進入工程路線：交付物將包含版本控制儲存庫差異，而且 Code readiness 已具備或可先補齊。

證據沿用

舊交接套件與唯讀檢視對照可保留為 Lesson practiced；它不會自動成為目前設計路線收尾或儲存庫交付核准，須按目前任務與路線停止點重新驗證。
