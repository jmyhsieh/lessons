把 Claude Design 工作帶回 repo

本課成果：一份回到程式庫的有限實作計畫，包含設計意圖與停止線。

不要只交截圖：官方 handoff 可延續 Design 工作；仍要附上設計版本、使用者任務、必須保留與本次範圍。

完成一次 dry handoff

請 Claude Code 透過 Design MCP 讀取選定版本；必要時使用官方 handoff／import，而不是只從截圖猜。

例如「使用者要完成報名；必須保留主要按鈕的位置、內容優先序與手機排列」。

例如「只做登入頁，不改導覽與後端；先列出可重用元件、預計檔案與驗證方式，不要改檔」。

完成：Claude Code 已把 Design intent 與 repo 現況放在一起，並提出一個尚未動手的 bounded plan。
