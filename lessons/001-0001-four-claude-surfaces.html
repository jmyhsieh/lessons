Phase 1 · Orient · 001-0001 · Common foundation entry

先選工作表面，再選 Task route

任務：用成果、工作環境與權限邊界，替目前任務選一個 Claude 工作表面，並把選擇寫進 Return notebook。

四個表面，各自負責什麼

Claude

適合對話、分析附件與形成草稿。成果主要留在對話，由你提供 context 並判斷可否採用。

Cowork

適合在授權範圍內完成多步驟知識工作與檔案任務。先從低風險副本開始，交付後仍由你 review。

Claude Design

適合探索視覺方向、原型與簡報。Prototype 是 feedback artifact，不是 usability、accessibility 或 production readiness 證明。

Claude Code

適合在 repo 中探索、修改、執行 checks 與建立可 review 的 diff。進真實交付前，先完成 Code readiness。

建立你的 route choice

  1. 寫下一句 mission：「我要讓誰能用什麼成果完成什麼事？」
  2. 列出成果所在環境：對話、文件資料夾、視覺畫布或 git repo。
  3. 標出允許的 read、write 與 external side effects。
  4. 用產品選用速查表選一個起始表面。
  5. 把 mission、選定表面與一個尚未確認的假設寫進Return notebook。
Tangible win：一張可解釋的 route choice card。
Observable feedback：另一個人只看 mission、成果環境與權限，就能重述你為何選這個表面。

快速判斷

要在練習 repo 中做 bounded edit、查看 diff 並跑 check，應從哪個表面開始？

正確：Claude Code 的工作環境就是 repo；但本階段只使用 readiness fixture，不代表已完成真實 repo deliverable。

邊界：本課只完成工作表面選擇，狀態記為 Lesson practiced。還沒有 Route artifact，也沒有 production authorization。
