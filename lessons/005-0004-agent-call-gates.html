Phase 5 Lab · 第 04 課 · 約 35 分鐘 · One bounded call

呼叫 agent 並執行 deterministic gates

目標：把 Phase 5 第 03 課的 dry-run plan 接成一次 bounded noninteractive call，安全保存 evidence，再由 deterministic code 執行一個 gate 並產生最小 report。

本課只做：一個 input、一次 agent call、一個必要 gate、一份 report。
先不要做：多 gate 編排、自動修復、batch、scheduler 或開放全部工具。

這一片為什麼要小

Claude Code CLI reference 說明 claude -p 會送出查詢後結束，並提供 output、turn、budget、tool、permission、settings 與 MCP 相關旗標。Runner 的第一個真 call 應該先把有效執行契約固定下來。

Agent SDK overview 適合需要程式化 session、tool、permissions 時使用；但若你只是把單一 dry-run plan 接成一個可驗證 call，先用 CLI wrapper 比較容易看見每個 artifact。

Wrapper 只做四件事

段落要留下什麼不做什麼
Invoke實際 argv、cwd、startedAt。不手寫 shell 字串。
Limitturns、budget、tool surface、permission/settings/MCP policy。不把 pre-approval 當 allowlist。
Captureredacted stdout/stderr、exit code、duration、retention。不先落地 raw secrets。
Classifypassed、failed、blocked、needs-review。不在這一片自動修復。
判斷規則：agent call 一旦接上，wrapper 的第一責任不是成功完成任務，而是讓 reviewer 能重建「它被要求做什麼、實際回了什麼、為什麼停下」。

凍結有效執行契約

--tools 限制 Claude 可見的 built-in tools；--allowedTools 只把規則預先核准，並不是 tool allowlist。Bounded noninteractive call 應以 --permission-mode dontAsk 搭配最小 --tools，再把 contract scope 展開成 Read(/path/**)、Edit(/path/**) 與精確 Bash rules：未匹配的請求會被拒絕，不會在無人值守時等待互動。

Path-scoped Edit rules 只約束 built-in file tools，不能限制 Bash subprocess 寫檔；因此真正的 filesystem boundary 必須來自隔離 worktree／container 與 OS sandbox allow-write paths，before/after scope gate 再負責偵測越界。MCP 也不受 --tools 限制，本 lab 使用 strict MCP config 並拒絕 mcp__*。同時固定 setting sources、設定檔 hash 與 CLI version；managed policy 仍可能優先拒絕請求，不能被 runner 放寬。

欄位要記錄
claudeVersionclaude --version 的實際輸出。
modelalias 或完整 model id。
efforthigh、xhigh、或 auto，並說明升級原因。
goalCondition從 runner contract 來的完成條件。
budgetturns、cost cap、timeout。
permissionMode本課固定 dontAsk；禁止 bypassPermissions。
effectiveSettingssetting sources、settings path/hash、解析後 allow/ask/deny 摘要。
toolPolicytools、allowedTools、disallowedTools 分開記錄。
mcpPolicy本課為 none；若啟用則記 server allowlist 與 config hash。
Effort 也是契約的一部分：第一版預設 high；只有既定升級條件成立時才切到支援 xhigh 的模型並留下理由。Unattended runner 不使用 max，也不因失敗無限升級。

  prompt.redacted.txt

{

  "claudeVersion": "<captured version>",
  "model": "sonnet",
  "effort": "high",
  "goalCondition": "All declared gates pass and report includes evidence paths.",
  "permissionMode": "dontAsk",
  "settingSources": ["project"],
  "effectiveSettingsSha256": "<hash>",
  "tools": ["Read", "Edit", "Bash"],
  "allowedTools": ["Read(/src/auth/**)", "Read(/tests/auth/**)", "Read(/package.json)", "Edit(/src/auth/**)", "Edit(/tests/auth/**)", "Bash(npm test -- auth)"],
  "disallowedTools": ["mcp__*"],
  "mcpPolicy": "none",
  "stdoutPath": ".harness/evidence/run-0042/agent.stdout.json",
  "stderrPath": ".harness/evidence/run-0042/agent.stderr.txt",
  "exitCode": 0,
  "status": "needs-review"
}

--allowedTools <tools...> 是 variadic flag；上例刻意讓每條 permission rule 成為獨立 argv element。CLI 也接受 comma-separated 值，但 wrapper 不應先把規則串回一條 shell 字串。

Capture boundary：先 scrub，再 durable write

Prompt、stdout、stderr 與 telemetry body 都可能含 secret、token、PII 或客戶資料。Capture pipeline 應先做 redaction，再寫入 durable evidence；report 與 run history 只保存摘要、redaction result 與 artifact path。.harness/evidence/ 預設加入 .gitignore，目錄／檔案使用 owner-only ACL（例如 0700／0600 或平台等價設定）。

Retention 也是 contract：retention.json 要記 owner、classification、expiresAt 與 deletion method。若除錯真的需要 unredacted raw output，必須另行核准，只能放在受控的 ephemeral store，設定最短 TTL，刪除後留下 deletion status；不可先把 raw log 寫進 repo 再補 redact。

一個 gate 與 report 由 deterministic code 負責

本課只接一個必要 gate。模型可以修改內容、摘要結果，但不能自己宣告 check 通過。Wrapper 先用 before/after manifest 算出包含 untracked files 的本輪 change set，再執行 contract 命令，保存 command、exit code、redacted output 與 artifact path，最後依固定 precedence 決定狀態。

狀態何時使用
blocked缺權限、憑證或必要環境，無法完成驗證。
failed至少一個必要 gate 明確失敗。
needs-review命令通過，但仍有人工判斷或未驗證項目。
passed所有必要 gates 通過，且沒有未處理風險。
狀態 precedence：blocked > failed > needs-review > passed。Report 至少列出 status、scope、gate table、evidence paths、unverified items 與 next action。

實作步驟（做完打勾）

不要重新組一套規則。Phase 5 第 03 課列出的 prompt、tool/permission/settings/MCP policy、單一 gate、paths 與 workspace baseline，應該是這一片唯一的 input。

避免把 prompt、paths、tool rules 串成一條 shell 字串。使用 dontAsk、path-scoped Read/Edit rules、精確 Bash rule、隔離 worktree／sandbox 與明確 MCP policy；把實際 argv、version、effective settings、model、effort 與 goal condition 寫進 command.json。

先 redact prompt/stdout/stderr，再用 owner-only ACL 寫到 gitignored evidence 目錄；同時寫 redaction 與 retention metadata。Report 只引用路徑與摘要。

先以 baseline 算 change set，再由 deterministic code 執行一個必要 gate，並依 precedence 分類。Report 引用 evidence paths，不複製完整 logs。

觀念檢查（憑記憶作答）

1. 加入真 agent call 後，wrapper 第一責任是什麼？

第一個真 call 的重點是能重建過程：argv、prompt、stdout、stderr、exit code 與分類結果。

2. 哪一組最適合 bounded noninteractive call？

dontAsk 讓 path-scoped 與 command-scoped rules 直接核准，其餘請求直接拒絕；bypassPermissions 不會被 allowedTools 限制。

3. 哪個 capture 順序符合本課的資料邊界？

Redaction 必須發生在 durable write 之前；raw output 若有必要，只能另行核准進受控的短期儲存。

4. 哪個 unattended effort policy 較合理？

第一版 runner 要可控且可重跑，預設 high；只有明確升級條件且模型支援時才用 xhigh，max 不應作為 unattended 預設。

5. 誰應該判定 test gate 是否通過？

可機械判定的 gate 應由 deterministic code 執行並記錄 exit code；模型不能用自述取代證據。
