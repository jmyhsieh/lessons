Phase 1 · Orient · 001-0002 · Common foundation stop

把安全範圍與續作點寫成 Return notebook

任務：把模糊的「開始使用 Claude」改寫成可安全開始、可觀察成功、也能合法停止的 route contract。

建立 learner-owned notebook

複製Return notebook Markdown 模板到你自己控制的位置。它跨裝置、跨 session 都能帶走，但不會自動判定你完成課程。

  1. Mission：一句話說清楚對象、成果與目的。
  2. Safe scope：列出可以讀、可以寫、不得碰的範圍。
  3. Verifiable success：寫一個人或工具能觀察的結果。
  4. Selected route：記下 route、current anchor 與下一個 tangible win。
  5. Readiness：保留有效 evidence；若有缺口，只指定最小 remediation 與 return point。
  6. State：明確區分 Lesson practiced 與 Route artifact produced。
Tangible win：一份至少填完 Mission、Selected route、Readiness 與 Resume line 的 Return notebook。
Observable feedback：隔十分鐘不看本頁，只讀 Resume line，仍知道下一步、停止線與遇到缺口時要回哪裡。

選擇下一條 readiness branch

  • Cowork starter（conditional）：想先練低風險檔案任務，前往001-0003，完成後可合法停止。
  • Code readiness（requires readiness）：之後要進 Engineering，前往001-0004，走到 001-0007 才取得 readiness evidence。
  • 其他 Task routes：在 coherent catalog 完成前只記錄為 optional continuation，不把尚未完成的 route 當成可用入口。

哪一筆最適合放進 Resume line？

Resume line 要能還原具體 route、下一個 win、阻塞條件與停止線；Return notebook 不替你判定完成。

Common foundation legal stop：route choice 與 readiness evidence 已記錄後，可以停在這裡。這只證明你能選路與界定成功，不代表任何 Task route 已產出交付物。
