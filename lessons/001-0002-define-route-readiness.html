第 1 階段 · 定向 · 001-0002 · 共通基礎停止點

把安全範圍與續作點寫成 Return notebook

任務：把模糊的「開始使用 Claude」改寫成可安全開始、可觀察成功、也能合法停止的路線契約。

建立學習者自有筆記

複製續作筆記本的 Markdown 模板到你自己控制的位置。它跨裝置、跨工作階段都能帶走，但不會自動判定你完成課程。

  1. 任務：一句話說清楚對象、成果與目的。
  2. 安全範圍：列出可以讀、可以寫、不得碰的範圍。
  3. 可驗證成功：寫一個人或工具能觀察的結果。
  4. 已選路線：記下 route、目前錨點與下一個 tangible win。
  5. 準備狀態：保留有效 evidence；若有缺口，只指定最小補救課程與返回點。
  6. 狀態：明確區分 Lesson practiced 與 Route artifact produced。
具體成果：一份至少填完 任務使命、已選路線、準備度 與續作指引的續作筆記本。
可觀察回饋：隔十分鐘不看本頁，只讀續作指引，仍知道下一步、停止線與遇到缺口時要回哪裡。

選擇下一條就緒分支

  • Cowork 入門任務（有條件）：想先練低風險檔案任務，前往001-0003，完成後可合法停止。
  • 程式碼作業準備度（需要先達 準備度）：之後要進 Engineering，前往001-0004，走到 001-0007 才取得就緒證據。
  • 其他任務路線：從課程目錄選擇目前 任務使命 對應的標準路線；只在有新 任務使命 時續作，不把選用續作當成必修。

哪一筆最適合放進續作指引？

續作指引要能還原具體 route、下一個 成果、阻塞條件與停止線；續作筆記本不替你判定完成。

共通基礎合法停止點：路線選擇與就緒證據已記錄後，可以停在這裡。這只證明你能選路與界定成功，不代表任何 Task route 已產出交付物。
