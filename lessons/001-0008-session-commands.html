整理與切換對話狀態（App 與 CLI）

本課成果：一張符合目前 Claude Code Desktop 介面的工作階段管理速查卡。

本課只做：學會桌面 App 操作入口、可用的斜線指令，以及 Desktop 不適用的指令。
先不要做：把所有 / 指令都當成 Desktop 一定支援。

先記四組就好

目的桌面 App 主路徑斜線指令補充
看快捷鍵打開 App 的快捷鍵清單。這不是指令清單；它只列鍵盤快捷鍵。
看可用指令在輸入框輸入 /。清單裡出現的才代表目前可用。
控制對話脈絡點用量環；需要時開新工作階段或切換檢視模式。/compact 若可用，可提早壓縮對話。
看變更點程式差異統計或差異檢視窗格。/diff 若可用，可作為快捷。
旁支問題開旁支對話。/btw 若可用，也會開旁支對話。
終端機開啟內建終端機。只在本機工作階段可用。

Desktop 不適用：/permissions、/config、/agents、/doctor 這類會開啟終端機對話框的指令。遇到這些需求，桌面 App 先用操作介面或設定檔；必要時再到 CLI。

長時間工作不要只靠同一段對話維持狀態；把完成條件、目前證據與下一步寫進可長期保存的紀錄，需要換工作階段時留下交接。

實作步驟（做完打勾）

打開 App 的快捷鍵清單，再在輸入框輸入 / 查看目前可用的斜線指令。兩個清單用途不同。

點模型選單旁的用量環。若對話已長但方向正確，先整理需求；若 /compact 可用，再考慮提早壓縮。

點程式差異統計或打開差異檢視窗格。若 /diff 在 / 清單裡，也可當快捷。

用側邊欄開新工作階段並切回舊工作階段。桌面 App 的主要路徑是側邊欄、工作階段紀錄、程式差異與 Git；/clear、/resume、/rewind 留給 CLI 情境。

完成條件：速查卡分別記錄桌面 App 控制項與目前可用的斜線指令。

觀念檢查

1. 任務做太久、對話脈絡開始混亂，第一個該想的是？

對話脈絡髒掉時，桌面 App 先看用量環、開新工作階段或切換檢視模式；提高推理程度無法清理舊脈絡。/compact 可用時才當快捷。

2. 交付前想快速看所有變更，該用？

桌面 App 使用程式差異統計或差異檢視窗格。/diff 若可用只是快捷。
