整理與切換對話狀態（App 與 CLI）

任務目標：用桌面 App 的面板與可用 slash command 管理 session，並知道哪些 commands 不適用 Desktop。

本課只做：學會桌面 App 操作入口、可用 slash commands、以及 Desktop 不適用的 commands。
先不要做：把所有 / command 都當成 Desktop 一定支援。

先記四組就好

目的桌面 App 主路徑slash command 補充
看快捷鍵打開 App 的快捷鍵清單。這不是 command 清單；它只列鍵盤快捷鍵。
看可用 commands在 prompt box 輸入 /。清單裡出現的才代表目前可用。
控制上下文點 usage ring；需要時開新 session 或切換 view mode。/compact 若可用，可提早壓縮對話。
看變更點 diff stats / diff pane。/diff 若可用，可作為快捷。
旁支問題開 side chat。/btw 若可用，也會開 side chat。
Terminal開內建 terminal。只在 local session 可用。

Desktop 不適用：/permissions、/config、/agents、/doctor 這類會開 terminal-dialog 的 commands。遇到這些需求，桌面 App 先用 UI 或 settings files；必要時再到 CLI。

/goal 先知道就好。它屬於較進階的持續工作控制，需要明確完成條件、gate 與 evidence，Phase 4 才正式接上。

實作步驟（做完打勾）

打開 App 的快捷鍵清單，再在 prompt box 輸入 / 看目前可用的 slash commands。兩個清單用途不同。

點 model picker 旁的 usage ring。若對話已長但方向正確，先整理需求；若 /compact 可用，再考慮提早壓縮。

點 diff stats 或打開 diff pane。若 /diff 在 / 清單裡，也可當快捷。

用 sidebar 開新 session 並切回舊 session。不要把 /clear、/resume、/rewind 當成桌面 App 主路徑；先用 sidebar、session history、diff 與 git。

🎉 完成！你已經知道桌面 App UI 與 slash commands 的分工。
