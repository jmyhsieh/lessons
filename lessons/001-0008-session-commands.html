整理與切換對話狀態（session commands）

任務目標：把 slash commands 當成 Claude Code session 的控制台。這一課只練常用 command，不處理模型選擇。

本課只做：學會幾個管理 session 狀態的基本 command。
先不要做：把 session command 當成會自動修好脈絡污染的萬用鍵。

先記四組就好

時點commands用途
第一次進 repo/init、/memory建立或檢查 repo 記憶。
任務中/plan、/context、/compact控制計劃與上下文。
交付前/diff、/run、/review看變更、執行、審查。
換任務/clear、/resume、/rewind清空、接續或回到 checkpoint。

/goal 先知道就好。它需要明確完成條件、gate 與 evidence，Phase 4 才正式接上。

實作步驟（做完打勾）

不要背文件；先確認你目前版本實際支援哪些 command。

執行 /context，觀察目前 session 裡有多少資訊。

在有變更的分支執行 /diff，把它當成交付前的固定動作。

比較 /clear 和 /resume 的用途：一個是清乾淨，一個是接續舊對話。

🎉 完成！你已經會用 command 管 session，而不是只靠自然語言硬聊。

觀念檢查

1. 任務做太久、context 開始混亂，第一個該想的是？

上下文髒掉不是推理程度問題；先處理 session 狀態。

2. 交付前想快速看所有變更，該用？

/diff 是交付前檢查變更的入口。
