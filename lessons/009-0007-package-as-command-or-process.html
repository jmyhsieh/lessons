Phase 9 · 標準化 · 009-0007 · Conditional branch

讓 deterministic code 承擔可可靠判定的流程

進入條件：009-0003 已選 command-process，因為 contract 的 routing、validation、parsing、formatting 或 transform 有穩定 machine interface。品質取捨、風險接受、exception disposition 與不可逆／external action approval 仍留給人。

1. 先定義 interface 與失敗語意

Command / process version / owner:
Inputs / schema / identity / size limits:
Outputs / stable format / evidence location:
Exit 0 means:
Non-zero exits / stderr contract:
Read / write set / dry-run / idempotency:
Timeout / retry ceiling / rollback or safe stop:
Human judgment and approval handoff:
Dependencies / verified fixture / retirement:
交給 code保留給人
Schema validation、bounded routing、sorting、parsing、formatting、literal threshold 與可重跑 checks。來源是否可信、結果是否夠好、風險是否可接受、例外怎麼處理、是否執行 external／production write。

明確失敗規則：Invalid input、partial output、timeout、dependency mismatch 或 skipped record 必須產生可辨識 non-zero／blocked state；不能為了「流程跑完」把未知結果格式化成成功。

2. 建立最小可判別 fixture matrix

  1. 正例固定 expected stdout／artifact 與 exit 0。
  2. Invalid schema、missing identity 或越界 input 固定 non-zero 與不產生 final artifact。
  3. 重跑同一 fixture，確認 output 可比較，且不重複 external effect。
  4. 若 command 產生 repo diff，建立 immutable candidate SHA，回 006-0008 做 Standards／Spec Review。
# Fresh-context rerun protocol
mkdir a-clean-disposable-fixture
copy exact package version + declared fixture only
start a minimal environment without prior session state
run: command --input valid.json
assert: exit 0 + exact expected output
run: command --input invalid.json
assert: non-zero + no final artifact
record: package digest, environment, commands, exits, outputs, diff

副作用邊界：Fresh-context test 預設只在 disposable local fixture 寫入。任何 network、recipient、production、billing、publish、push 或 deploy 都在 command 外形成明確 human approval stop；--yes 或 package 文件不能替代 authority。

3. 保存 fresh-context evidence

重跑紀錄
可見成果：一個 versioned command／local process contract，附 fresh-context 正反例與 rerun evidence。
可觀察回饋：乾淨 fixture 中正例產生 exact output、反例 fail loud 且不留下 final artifact；重跑結果可比較，judgment／external action 不會被 code 偷做。

Command 可穩定計算品質分數，但是否發布需要 owner 判斷。應怎麼包？

Deterministic calculation 可以自動化；風險與發布判斷不能因為有分數就被悄悄轉成自動批准。

合法停止／返回／續行：若 interface 不穩定、expected result 無獨立 literal、failure 回傳成功、retry 無界、fresh context 依賴隱藏 state、judgment 被寫進 code，或 side effect 無當次 authority，停止並回 009-0003／009-0002。Repo diff 先由 006-0008 完成 immutable Review；其餘 package evidence 齊全後前往 009-0008-complete-standardization-closeout.html，不要再完成其他 branch。
