Phase 8 · 入門第 01 課 · 約 10 分鐘

判斷即時查核或持久測試

今天只做一件事：請 Claude Code 讀 repo，再選出一條值得用瀏覽器查核的路徑與正確證據。

先分兩種結果：Playwright MCP 適合讓 Claude Code 當下操作真實瀏覽器；Playwright Test 才是能提交、重跑與放進 CI 的持久測試。即時查核成功，不等於 repo 已有測試。

做一張 route decision card

在 plan mode 請它讀 AGENTS.md、README、啟動命令與既有 tests，不要改檔；列出一條使用者最在意的 browser path。

寫下 URL、使用者動作與可觀察結果，例如「從課目表點入 Phase 8，應看見第 01 課標題」。避免只寫「網站正常」。

只想現在確認就選 MCP live check；要防止回歸就選 committed Playwright Test。若已使用 Claude in Chrome，也可做 live check，但仍不能取代 test。

請先只讀檢查這個 repo 的操作規範、啟動方式與既有 tests。
提出一條高價值 browser path，寫出開始 URL、使用者動作、可觀察結果，
並建議這次應做 Playwright MCP live check 或 committed Playwright Test。不要改檔。
完成：你已有一張寫清楚路徑、證據種類與停止線的 route decision card。

觀念檢查

Claude Code 用 MCP 成功操作一次頁面，代表什麼？

Live check 是當下觀察；只有把可重跑 test 寫進 repo、執行並審查，才形成持久回歸證據。

帶走這個就好

先決定要回答「現在正常嗎」或「以後壞了會知道嗎」，再請 Claude Code 選工具。

主要閱讀：Playwright MCP — Installation；替代 live surface 可看 Claude Code — Chrome。
