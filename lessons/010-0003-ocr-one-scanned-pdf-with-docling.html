用 Docling OCR 一份掃描 PDF

本課成果：一份由 Docling 本機 OCR 產生、尚待人工查核的 Markdown 檔。

Docling 需要安裝較多套件，但能處理掃描頁：它會分析版面、閱讀順序與表格，也可使用本機 OCR。第一次可能下載模型；先確認磁碟、網路與文件權限。課程不要求雲端 Vision API 或額外 API key。

只 OCR 一份掃描檔

抽查兩頁：文字無法搜尋或複製，才標記為掃描 PDF。若文件已有正常文字層，先不要使用 --force-ocr。

請依這台電腦的環境，提出 Docling 的隔離安裝與本機 OCR 計畫，先不要執行。

請列出預計下載的套件或模型、磁碟需求與完整命令。
不要使用雲端 OCR，也不要覆寫原始 PDF。

CLI 核心形式為 docling convert scans/invoice.pdf --to md --ocr --output converted。macOS 可依官方文件評估 ocrmac；實際旗標以目前安裝版本的 docling --help 為準。

完成：你已用本機 OCR 產生一份 Markdown，且保留原始掃描 PDF。

觀念檢查

何時不該直接加上 --force-ocr？

強制 OCR 會以辨識結果取代既有文字；文件已有可靠文字層時，反而可能降低品質。

關鍵判斷

Docling 可以在本機執行，但還是會占用磁碟、下載模型並花時間運算。敏感文件的處理仍要先核准。
