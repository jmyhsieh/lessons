Phase 8 · 操作 · 008-0004 · Core execution

在 restore point 與小批次界線內執行一次 workflow

進入條件：Deterministic check 已校準、local-first surface 已選、read-only rehearsal 的 predicted scope 已由 owner 接受，且 authority envelope 只允許一個 recoverable fixture。這一課執行一次 bounded local run；不碰 production，也不把 write 權限延伸成 external side effect。

Recoverability 不是口號：在第一個 write 前，實際讀回 restore point 或從 disposable copy 試做 restore，確認它涵蓋本輪所有 allowed writes。只有「有備份」文字、未驗證 branch 名稱或未知 snapshot 不足以開跑。

2. 以最小 batch 執行

  1. 重新跑 preconditions：inputs identity、fixture fingerprint、authority expiry、available disk／service、overlap lock 與 completion oracle 都仍有效。
  2. 建立唯一 run ID 與 idempotency／dedupe key；若 workflow 不能安全重試，明記 duplicate risk，並把任何 retry 交給 human stop。
  3. 先處理最小代表性 batch。每個 item 記錄 input ID、planned action、actual action、result 與 evidence，不讓 agent 用總結隱藏 partial failure。
  4. 將 actual read／write set 與 rehearsal 的 predicted set 比對。多一個 path、record 或 action 就停止，不在 run 中擴大 envelope。
  5. Batch 通過 local invariants 後才繼續下一批；達到 time／round／cost ceiling、oracle unavailable 或 supervision 中斷時 safe stop。

3. 保存 output，不先宣稱 completion

紀錄必須能回答
執行紀錄每個 input 處理一次、跳過、失敗或未處理？Retry 是否重複？
範圍差異Actual read／write 是否精確落在 envelope？Fixture 外 baseline 是否未變？
檢查點最後成功 batch、最後 evidence、safe resume point 與 restore point 是什麼？
Agent 聲明哪些只是 summary／inference，尚未由下一課的 oracle 觀察？

外部操作邊界：即使真實 workflow 最後會寄送、push、deploy 或更新 remote system，本課也停在可檢查的 local artifact／payload preview。若另有具體 authority，外部 action 仍須逐次 approval、idempotency／dedupe、receipt 與 recovery；它不是 self-study completion requirement。

可見成果：一次具有 run ID、restore point、bounded ledger、scope diff 與 safe resume／stop 的 recoverable local run。
可觀察回饋：Observer 能從 ledger 重建每個 item 的處置，核對 fixture 外未變，並在不依賴 agent summary 的情況下指出最後 checkpoint 與任何 partial failure。

第一批成功後，agent 發現輸入目錄外還有一個「應該一起修」的檔案，該怎麼做？

Restore 能力不等於授權；actual scope 超出 envelope 時必須 fail closed，重新界定 scope 後另開 run。

合法停止／返回／續行：Restore 未實測、preconditions 漂移、overlap 未排除、actual scope 超界、ledger 有不明 partial、external action 被要求但未另行核准，或 ceiling 已達時，保存 checkpoint 後停止；scope／authority 問題回 008-0003。Bounded run 結束後，進 008-0005，用 deterministic oracle 建 completion proof；本課的 green status 或 agent summary 都不算完成。
