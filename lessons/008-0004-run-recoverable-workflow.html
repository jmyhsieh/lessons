Phase 8 · 操作 · 008-0004 · 核心執行

在還原點與小批次界線內執行一次工作流

進入條件：Deterministic check已校準、本機優先介面已選、唯讀演練預測的範圍已由負責人接受，且權限範圍只允許一個可復原的 fixture。這一課執行一次有界的本機執行；不碰正式環境，也不把寫入權限延伸成外部副作用。

可復原性不是口號：在第一個寫入前，實際讀回還原點或從可丟棄副本試做還原，確認它涵蓋本輪所有允許的寫入。只有「有備份」文字、未驗證branch名稱或未知快照不足以開跑。

2. 以最小批次執行

  1. 重新跑前置條件：輸入識別、fixture指紋、權限到期時間、可用磁碟空間／服務、重疊鎖與完成oracle都仍有效。
  2. 建立唯一執行ID與冪等性／去重鍵；若工作流不能安全重試，明記重複風險，並把任何retry交給人工停止。
  3. 先處理最小代表性批次。每個項目記錄輸入ID、規劃的動作、實際的動作、結果與證據，不讓代理程式用總結隱藏部分失敗。
  4. 將實際讀取／寫入集合與演練預測集合比對。多一個路徑、紀錄或動作就停止，不在執行中擴大範圍。
  5. 批次通過本機不變條件後才繼續下一批；達到時間／輪次／成本上限、oracle不可用或監督中斷時安全停止。

3. 保存輸出，不先宣稱完成

紀錄必須能回答
執行紀錄每個輸入處理一次、跳過、失敗或未處理？重試是否重複？
範圍差異實際讀取／寫入是否精確落在範圍？測試資料外基準是否未變？
檢查點最後成功批次、最後證據、安全續作點與還原點是什麼？
Agent聲明哪些只是摘要／推論，尚未由下一課的oracle觀察？

外部操作邊界：即使真實工作流最後會寄送、push、部署或更新遠端系統，本課也停在可檢查的本機產物／承載資料預覽。若另有具體權限，外部動作仍須逐次核准、冪等性／去重、收據與復原；它不是自學完成要求。

可見成果：一次具有執行 ID、還原點、有界台帳、範圍diff與安全續作／stop的可復原的本機執行。
可觀察回饋：觀察者能從台帳重建每個項目的處置，核對fixture外未變，並在不依賴代理程式摘要的情況下指出最後檢查點與任何部分失敗。

第一批成功後，代理程式發現輸入目錄外還有一個「應該一起修」的檔案，該怎麼做？

還原能力不等於授權；實際範圍超出授權範圍時必須預設拒絕並安全停止，重新界定範圍後另開執行。

合法停止／返回／續行：還原未實測、前置條件漂移、重疊未排除、實際範圍超界、台帳有不明部分、外部動作被要求但未另行核准，或上限已達時，保存檢查點後停止；範圍／權限問題回008-0003。有界執行結束後，進 008-0005，用確定性判定器建完成證明；本課的通過狀態或代理程式摘要都不算完成。
