用 Claude Code LSP 畫一張程式符號地圖

本課成果：一張符號地圖，包含一個定義、兩個引用位置與人工核對結果。

先用內建能力：Claude Code 的 LSP tool 能依程式語言查 definition 與 references；它要有對應語言的 code intelligence plugin 與 language server 才會啟用。本卡只做唯讀探索。

追一個真實程式符號

不要用純靜態 HTML 教材練習。改選一個有對應 language server 的真實程式庫，再挑一個你知道名字的函式、類別或方法。

請先唯讀檢查目前是否有可用的 LSP tool，以及這個程式庫使用的語言。
若 LSP 尚未啟用，請依 Claude Code 官方文件提出對應的 code intelligence plugin
與 language server 安裝方式，先不要執行。
這次只查找一個符號的 definition 與 references，不修改任何檔案。

code intelligence plugin 只負責讓 Claude Code 連接語言伺服器；language server binary 仍需另外安裝。若目前語言沒有合適 plugin，就停在這裡，改用 rg／編輯器核對，或再評估 Serena。

觀念檢查

LSP 比純文字搜尋多提供了什麼？

LSP 依程式結構定位符號；結果仍受語言伺服器與專案設定影響，也不能替代測試或人工核對。

關鍵判斷

只找固定字串先用 rg；只查 definition／references 時先用 Claude Code LSP；需要更完整的專案探索工作流時，再評估 Serena。
