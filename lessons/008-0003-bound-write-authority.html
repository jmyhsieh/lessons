Phase 8 · Operate · 008-0003 · Authority gate

把 read、local write 與 external side effect 分成三份 authority

Entry：帶入 deterministic completion contract、唯一 execution surface 與 recoverable fixture。先用相同 inputs 做 read-only／plan rehearsal，列出預計 affected scope；只有 owner 看過 scope 並核准精確 write set 後，才可準備下一課的 local write。

1. 寫 authority envelope，不用「可以操作」含糊帶過

2. 讓 rehearsal 真正限制 write

  1. 以 production-equivalent input shape、但使用 non-sensitive recoverable fixture 執行 read-only inventory 或 dry-run；dry-run 若本身會寫，就不能當 read-only evidence。
  2. 保存 predicted write set、counts、targets、warnings 與 unknowns；由 owner 對照 mission，刪掉「順便」處理的 scope。
  3. 將 default 設為 deny：只有列出的 fixture paths／operations 可寫。任何新 target 都回到 rehearsal，不在執行中自動擴權。
  4. External action 預設為 none。若真實任務另需外部 write，逐一固定 target／payload、dedupe／idempotency、recovery 或不可逆 stop，並取得有權者 approval。

Self-study boundary：本 route 的 canonical hands-on 只需要 recoverable local write。可以在 closeout 誠實記錄「production／external action 未執行」；不得為了讓練習看起來完整而 push、deploy、寄信、付款、修改真實 wiki 或呼叫 production mutation。

Tangible win：一份由 read-only rehearsal 支持、清楚分離 read／local write／external action 的 authority envelope。
Observable feedback：Owner 能逐項圈出允許與拒絕的 paths／operations，確認 actual scope 若漂移會 fail closed，並證明 local write approval 沒有偷渡 production side effect。

Agent 在 dry-run 發現還需更新一個未列出的 external record，應怎麼做？

新 target 是 authority 變更；execution surface 或委派不會授權 side effect，必須停止並重新通過 scope 與 approval gate。

Legal stop／return／continuation：Rehearsal 有未解 scope drift、write paths／operations 含糊、restore point 無法驗證、approval owner 不明、external action 沒有 dedupe／recovery／irreversible stop，或任何 human judgment 被交給 agent 時，保留 envelope 並停止。一般 branch 準備完成後，進 008-0004 執行 recoverable workflow；LLM Wiki branch 只有 elective 可用且 boundary 成立時才進 008-0008。此處不執行 write，也不宣稱 route complete。
