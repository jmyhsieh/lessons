建立可重用 deck system

今天只做一件事：請 Claude Code 從已成功的 deck 抽出規則，再透過 Design MCP 重做一頁驗證。

系統要能重做：只寫「專業、簡潔」不夠；要留下字級、色彩、間距與版型規則。

做一個最小 deck system

只從現有成功頁面提取字級、色彩／對比、頁面邊界／間距，不先發明新 system。

封面、證據頁、下一步頁各寫清楚放什麼、不放什麼；你要審查是否真的有實際使用點。

與既有頁並排檢查；有偏差就請 Claude Code 修規則，不用逐頁補丁掩蓋 system 問題。

完成：你已有可重用的 deck system，下一頁不必重新猜一次版面。

觀念檢查

Deck system 最主要解決什麼問題？

Deck system 把反覆出現的視覺決定變成規則，讓多頁與多版本維持一致。

帶走這個就好

先從少量、可檢查的規則開始；只有實際重用過的規則，才算 system。
