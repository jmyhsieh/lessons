Phase 4 · 第 04 課 · 約 15 分鐘

讓 Claude Code 產生三頁初稿

本課成果：一份依核准故事板產生的三頁簡報初稿。

第一版不是成品：先確認內容與順序，不要立刻花時間調每個字級、顏色與裝飾。

生成第一版

把任務卡、三頁故事板與三份資料交給 Claude Code，明說哪份支持哪頁，不允許發明數字或引言。

要求回傳可查看的 Claude Design 專案；不要同時加入附錄、動畫或額外頁面。

標題正確嗎？資料用對嗎？下一步清楚嗎？把最重要的一個問題交回 Claude Code，不先精修裝飾。

完成：你已有一份三頁初稿，也知道下一輪最先要修哪個內容問題。

觀念檢查

第一版產生後，最先檢查什麼？

內容與順序決定簡報能否推動理解；視覺精修應在這個地基正確後進行。

關鍵判斷

好的第一版要能讓你清楚指出下一個修正，不必急著直接上台。

主要閱讀：Anthropic — Creating a presentation。
