安全初始化 OpenSpec

本課成果：一張可重現的初始化紀錄，包含版本、命令、寫入路徑、實際 diff 與移除方式。

先核對環境與寫入範圍：OpenSpec v1.6.0 需要 Node.js 20.19.0 以上。全域安裝與 repo 初始化是兩次不同的寫入，請分開核准、分開檢查。

初始化 Core profile

node --version
npm --version
git status --short

若 Node.js 未達版本需求，先處理執行環境。不要用 --force 略過現況，也不要在髒工作樹裡把既有修改算成 OpenSpec 產物。

npm install -g @fission-ai/openspec@latest
openspec --version

這是官方文件提供的全域安裝方式。若團隊有固定的 package manager 或版本鎖定政策，請依 repo 規則調整，並把實際版本寫進紀錄。

git status --short
openspec init --tools claude --profile core
git status --short
git diff --stat
git diff

Core profile 會提供 explore、propose、apply、sync 與 archive。先逐一看清新增或修改的路徑，不要急著建立 change。
