Phase 1 · 第 10 課 · 約 20 分鐘 · 實作課（桌面 App）

判斷 Cowork 適合的交付物

任務目標：在 Claude 桌面 App 的 Cowork 分頁完成一個真實的檔案整理任務。做完這課，三個產品你就都親手用過了 — Phase 1 第 01 課的判斷力從「紙上談兵」變成經驗。

本課只做：用 Cowork 做一次低風險文件型交付。
先不要做：把 Cowork 產物直接當 production code。

Cowork 跟 Claude Code 像在哪、差在哪

兩者都是「代理」：你描述成果，它多步驟執行，動手前徵求同意。差別只在工作對象與工具（官方上手指南）：

CoworkClaude Code
入口桌面 App 的 Cowork 分頁桌面 App 的 Code 分頁（或 CLI/IDE）
工作範圍你授權的資料夾git repo
擅長檔案整理、研究彙整、產 Excel/簡報/報告讀寫程式碼、跑測試、git/PR
權限模式Ask before acting / Act without askingPhase 1 第 06 課的權限模式
安全注意（官方原文）：程式碼在隔離環境中執行，但「Claude 能對你的檔案做出真實變更」。永久刪除檔案一定會先徵求你的同意。第一次使用請選 Ask before acting — 跟 Claude Code 的逐項詢問是同一個習慣。

實作步驟（做完打勾）

別直接拿重要資料夾開刀。建一個資料夾，丟進 10–20 個雜亂檔案（下載資料夾裡的舊檔、截圖、PDF 都行 — 先複製一份過去）。

桌面 App → Cowork 分頁 → 新任務 → 授權剛才的練習資料夾。確認權限模式是 Ask before acting。

把這個資料夾裡的檔案依類型分到子資料夾（圖片／文件／其他），
檔名統一改成「日期-描述」格式，最後產生一份 inventory.md
列出每個檔案的新位置。

觀察它的執行過程：它怎麼拆步驟？每次動作前的請求你都看得懂嗎？

打開資料夾親自確認結果，再讀 inventory.md。有不滿意的地方直接在同一個任務裡叫它修正 — 體驗「來回修到滿意」的節奏。

把資料夾裡的 PDF 重點彙整成一頁簡報大綱
🎉 三個產品都親手用過了！回對話視窗回報：用過之後，你覺得 Cowork 和 Claude Code 的「手感」差在哪？工作中有哪些非程式任務你想交給 Cowork？

觀念檢查（憑記憶作答）

1. 工作情境：「把上季 40 份客戶訪談逐字稿做成主題分析報告」，最適合？

（複習 Phase 1 第 01 課 判斷軸）大量本機檔案 + 文件產出 + 非程式碼 → Cowork。網頁版貼 40 份太費工；Claude Code 的強項在 repo 不在文件工作。

2. Cowork 的「Act without asking」相當於 Claude Code 的哪種情境？

（串連 Phase 1 第 06 課）Act without asking ≈ acceptEdits/auto 一類的自動批准：更快，但少了逐項把關。重要資料夾一律 Ask before acting。

3.（複習 Phase 1 第 04 課）不論 Cowork 還是 Claude Code，「批准它執行動作」之後你還欠一步？

（間隔複習：護欄三）放行 ≠ 驗收。Cowork 是打開資料夾檢查成果，Claude Code 是讀 diff — 同一個習慣的兩種形式。
