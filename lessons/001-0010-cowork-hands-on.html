Phase 1 · 第 10 課 · 約 20 分鐘 · 實作課（Desktop 本機檔案路徑）

判斷 Cowork 適合的交付物

任務目標：用 Claude Desktop 的 Cowork 完成一個真實的本機檔案整理任務，親手驗證「遠端代理透過 Desktop 存取本機資料夾」的工作方式。

本課只做：用 Cowork 做一次低風險文件型交付。
先不要做：把 Cowork 產物直接當 production code。

Cowork 跟 Claude Code 像在哪、差在哪

兩者都是「代理」：你描述成果，它會規劃並多步驟執行。Cowork session 在 Anthropic 的隔離環境遠端執行，可從 web、Desktop、mobile 接續；需要本機檔案、browser 或 computer use 時，才透過保持開啟的 Desktop 連回你的電腦（官方上手指南）。

CoworkClaude Code
入口Web、Desktop 或 mobile 的 CoworkDesktop 的 Code（或 CLI/IDE/Web）
工作範圍遠端 task files；Desktop 可接本機授權資料夾本機、cloud 或 SSH 環境中的 git repo
擅長檔案整理、研究彙整、產 Excel/簡報/報告讀寫程式碼、跑測試、git/PR
權限模式Manual / Auto / SkipPhase 1 第 04 課的權限模式
安全注意：隔離環境保護你的電腦，不會消除你授予的檔案與 connector 權限。永久刪除檔案一定會再詢問；第一次處理重要檔案請選 Manual（舊版稱 Ask before acting）。Auto 會做背景安全檢查，Skip（舊版稱 Act without asking）則不詢問也不做這層檢查。

實作步驟（做完打勾）

別直接拿重要資料夾開刀。建一個資料夾，丟進 10–20 個雜亂檔案（下載資料夾裡的舊檔、截圖、PDF 都行 — 先複製一份過去）。

在 Claude Desktop 的 message box 選 Cowork，建立新任務並授權剛才的練習資料夾。確認權限模式是 Manual；任務需要本機檔案期間保持 Desktop 開啟並連線。

把這個資料夾裡的檔案依類型分到子資料夾（圖片／文件／其他），
檔名統一改成「日期-描述」格式，最後產生一份 inventory.md
列出每個檔案的新位置。

觀察它的執行過程：它怎麼拆步驟？每次動作前的請求你都看得懂嗎？

打開資料夾親自確認結果，再讀 inventory.md。有不滿意的地方直接在同一個任務裡叫它修正 — 體驗「來回修到滿意」的節奏。

把資料夾裡的 PDF 重點彙整成一頁簡報大綱
🎉 你完成了 Cowork 的本機檔案路徑！回對話視窗回報：用過之後，你覺得 Cowork 和 Claude Code 的「手感」差在哪？工作中有哪些非程式任務你想交給 Cowork？

觀念檢查（憑記憶作答）

1. 工作情境：「把上季 40 份客戶訪談逐字稿做成主題分析報告」，最適合？

（複習 Phase 1 第 01 課 判斷軸）大量本機檔案 + 文件產出 + 非程式碼 → Cowork。網頁版貼 40 份太費工；Claude Code 的強項在 repo 不在文件工作。

2. Cowork 的 Skip all approvals 最接近 Claude Code 哪種風險？

（串連 Phase 1 第 04 課）Skip 不詢問，也沒有 Auto 的背景安全檢查；最接近 Claude Code 的 bypassPermissions。重要資料夾先用 Manual。

3.（複習 Phase 1 第 05 課）不論 Cowork 還是 Claude Code，「批准它執行動作」之後你還欠一步？

（間隔複習：護欄三）放行 ≠ 驗收。Cowork 是打開資料夾檢查成果，Claude Code 是讀 diff — 同一個習慣的兩種形式。
