Phase 7 · 驗證 · 007-0002 · Surface selector

依 claim、identity 與 session 選一個 surface

進入條件：007-0001 的 Browser claim card 已固定 app revision、starting state、observable outcome 與反證條件。這一課只選一個能最低成本看見該行為的 exploration surface；四個選項是 alternatives，不是熟練度階梯，也不需要全部操作。

已驗證環境：2026-07-17 檢查 Anthropic Claude Code Desktop Browser／Claude in Chrome 文件，以及 Playwright CLI eee5a185、Playwright MCP 55679f5f 的 first-party README snapshot。這只證明公開 surface contract；你的帳號、organization policy、extension、Node／package、browser binary、MCP trust 與 target app 必須在開始前另行確認。

四個入口，選一個 primary surface

工作表面何時最合適身分／session 邊界開始前要看到
Desktop Browser
Claude Code Desktop 版		Local app preview、project file 或不需個人 identity 的 clean-profile 探索；希望 app、server 與 browser 並排。獨立 clean profile；不要假設有個人 browser 的 login／history。External site 仍受 organization policy 與 action approval 控制。Browser pane 可用、target server／file 可開啟、domain 與 interaction authority 可說明。
Claude in Chrome
Claude Code 的 CLI／VS Code		Claim 必須在既有 logged-in session、真實 extension permission 或可見 Chrome 視窗中探索。共享現有 browser login state，暴露面較大；login／CAPTCHA 由 learner 接手，site permission 要明確。支援 browser、extension、direct Anthropic plan、Claude Code connection 與 target site permission。
Playwright CLI
由 Claude Code 執行 command／Skill		Code-oriented exploration，需要 concise commands、named session、snapshot／console／request 等可檢查 artifacts。CLI session 的 cookies／storage 與 profile 要記錄；artifact 只是觀察材料，還不是 repo 內 Playwright Test。Node 18+、可用 CLI、browser prerequisites、artifact write scope 與 session cleanup plan。
Playwright MCP
連到 Claude Code 的 trusted MCP server		探索需要 persistent structured context、反覆 page introspection 或較長的 agentic loop，且收益值得較大的 tool schema／trust surface。MCP server 與 browser context 皆在 authority boundary 內；MCP 不是 security boundary。可信來源、固定 configuration／server identity、允許 tools、target sites、browser profile 與 stop／disconnect 方法。

替代方案邊界：不要先 Desktop、再 Chrome、再 CLI、最後 MCP。Surface 只負責最短探索：若 claim 不需要登入，clean Desktop Browser 可能已足夠；若要現有登入，Chrome 的 identity boundary 才是理由；若 code workflow 需要可檢查 command artifacts，CLI 通常更小；只有 persistent structured loop 的收益足以負擔 MCP 時才選 MCP。多跑一個 surface 不會讓 claim 自動變成 durable evidence。

可觀察回饋：Reviewer 能由 claim 判斷選擇是否必要且足夠，並指出若換 surface 會改變的 session／login／trust boundary；若理由只是「全部都學」，selection 不通過。

Local fixture 不需登入，Claude Code 要用 concise commands 留 snapshot 與 console artifacts；最小合適選擇是？

這個 claim 不需要 personal browser identity，也沒有 persistent introspection 的必要。CLI 能提供本輪所需 artifacts，但 exploration artifacts 仍不能替代 durable test。

合法停止／返回／續行：沒有任何 surface 同時滿足 availability、target-site authority、profile／authentication boundary 與 recoverable interaction 時，保存 selection record 後停止，不安裝未知 MCP、不借用 production identity、不擴權硬闖。Claim 改變就回 007-0001；選擇成立後進 007-0003，只用 primary surface 記錄 observable baseline。完成本頁只代表 exploration 入口已選定，不代表已建立 Playwright Test、Browser evidence addendum、Phase 或 Migration complete。
