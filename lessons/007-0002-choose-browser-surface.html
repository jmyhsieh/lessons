Phase 7 · 驗證 · 007-0002 · 介面選擇器

依主張、識別與工作階段選一個介面

進入條件：007-0001的瀏覽器主張卡已固定應用程式修訂版、起始狀態、可觀察結果與反證條件。這一課只選一個能最低成本看見該行為的探索介面；四個選項是替代選項，不是熟練度階梯，也不需要全部操作。

已驗證環境：2026-07-17檢查Anthropic Claude Code Desktop Browser／Claude in Chrome文件，以及Playwright CLI eee5a185、Playwright MCP 55679f5f 的第一方 README 快照。這只證明公開介面契約；你的帳號、組織政策、延伸功能、Node／套件、瀏覽器執行檔、MCP信任與目標應用程式必須在開始前另行確認。

四個入口，選一個主要介面

工作表面何時最合適身分／工作階段邊界開始前要看到
Desktop Browser
Claude Code 桌面版		本機應用程式預覽、專案檔案或不需個人識別的乾淨設定檔探索；希望應用程式、伺服器與瀏覽器並排。獨立乾淨設定檔；不要假設有個人瀏覽器的登入／歷史紀錄。外部網站仍受組織政策與動作核准控制。瀏覽器窗格可用、目標伺服器／檔案可開啟、網域與互動權限可說明。
Claude in Chrome
Claude Code 的 CLI／程式碼編輯器整合		主張必須在既有已登入的工作階段、真實延伸功能權限或可見Chrome視窗中探索。共享現有瀏覽器登入狀態，暴露面較大；登入／驗證碼由學習者接手，網站權限要明確。支援瀏覽器、延伸功能、直接的Anthropic計畫、Claude Code連線與目標網站權限。
Playwright CLI
由Claude Code執行command／Skill		程式碼導向的探索，需要精簡命令、具名工作階段、快照／主控台／需求等可檢查產物。CLI工作階段的瀏覽器資料／儲存空間與設定檔要記錄；artifact只是觀察材料，還不是repo內Playwright Test。Node 18+、可用CLI、瀏覽器前置需求、artifact寫入範圍與工作階段清理計畫。
Playwright MCP
連到Claude Code的可信 MCP伺服器		探索需要持續的結構化脈絡、反覆頁面內省檢查或較長的代理程式迴路，且收益值得較大的工具結構／信任介面。MCP伺服器與瀏覽器脈絡皆在權限邊界內；MCP不是安全邊界。可信來源、固定設定／伺服器識別、允許工具、目標網站、瀏覽器設定檔與stop／中斷連線方法。

替代方案邊界：不要先桌面版、再Chrome、再CLI、最後MCP。介面只負責最短探索：若主張不需要登入，乾淨的Desktop Browser可能已足夠；若要現有登入，Chrome的識別邊界才是理由；若code工作流需要可檢查command產物，CLI通常更小；只有持續的結構化迴路的收益足以負擔MCP時才選MCP。多跑一個介面不會讓主張自動變成持久證據。

可見成果：一張只指定一個主要的探索介面的選擇紀錄，含可用性、識別、身分驗證、權限、產物、備援與返回點。
可觀察回饋：審查者能由主張判斷選擇是否必要且足夠，並指出若換介面會改變的工作階段／登入／信任邊界；若理由只是「全部都學」，選擇不通過。

本機 fixture不需登入，Claude Code要用精簡命令留快照與主控台產物；最小合適選擇是？

這個主張不需要個人瀏覽器識別，也沒有持續的內省檢查的必要。CLI能提供本輪所需產物，但探索產物仍不能替代持久的test。

合法停止／返回／續行：沒有任何介面同時滿足可用性、目標網站權限、設定檔／驗證邊界與可復原互動時，保存選擇紀錄後停止，不安裝未知MCP、不借用正式環境識別、不擴權硬闖。主張改變就回007-0001；選擇成立後進 007-0003，只用主要介面記錄可觀察基準。完成本頁只代表探索入口已選定，不代表已建立Playwright Test、瀏覽器證據附錄、Phase或Migration完成。
