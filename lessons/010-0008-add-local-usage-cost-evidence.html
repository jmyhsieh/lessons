隱私／權限邊界：不要把「工具能發現檔案」當成讀取授權。先由學習者確認路徑範圍、負責人、日期範圍、輸出位置與保留期限；不要把原始提示詞、專案名稱、工作階段內容、帳號識別資訊或未經核准的完整紀錄複製進課程repo、議題、聊天或檔案。無法證明權限或安全彙總時，停止並記錄缺口。

2. 固定可重現的執行方式

先在安全環境檢查精確套件的說明與預計輸入範圍；只有卡片已核准才執行。以下是依已審查的README整理的學習者操作程序，不是本次課程重新認證已跑過的結果：

npx --yes ccusage@20.0.17 --help
npx --yes ccusage@20.0.17 claude daily \
  --since YYYY-MM-DD --until YYYY-MM-DD \
  --timezone Asia/Taipei --offline --json

實際執行前，用精確版本說明核對選項；任何選項、紀錄位置、價格來源或輸出結構不符已審查的快照，就不要猜測替代指令，回報來源漂移。使用 --offline 不代表資料正確、完整或不敏感。

合法停止／返回：權限、相容的紀錄、路徑範圍、版本、日期範圍、時區、定價來源脈絡、缺少資料、隱私或保留任一不清楚時停止；不要試讀、補猜或擴大資料範圍。紀錄完成後只帶有界彙總、來源脈絡、未知事項與限制回 010-0007證據檔案，由學習者更新保留／變更／退役處置。本條件式branch不阻擋Phase 10核心收尾，也不授權Phase 11導入、外部寫入或正式環境動作。
