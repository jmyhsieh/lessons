Repo rehearsal 速查表

用一個低風險真實任務演練完整 harness 流程。

Rehearsal 的驗收句：一個真實 repo 任務從 brief 到 closeout 都跑完，並留下至少一個流程改進發現。

任務挑選

選它避開它
低風險、可 revert。資料刪除、付費、權限變更。
單 repo、單 branch。多 repo、多團隊同步。
本機可驗證。只能靠 production 驗證。
驗收條件清楚。目標抽象或仍在探索。

Run order

順序Artifact成功訊號
1BriefOutcome、scope、gates、stop 都清楚。
2Dry-run能預覽任務，不改檔。
3Agent evidencestdout、stderr、exit code 留下。
4Gate resultsPass/fail 由 command 或檢查決定。
5Run historyhistory show 找得到 artifacts。
6Final handoffReviewer 不看聊天也能接手。
7Closeoutship、review、rerun、blocked 或 downgrade。

完成定義

Done when:
- The task was small enough to inspect.
- Every artifact path exists.
- Closeout decision is explicit.
- One process finding is recorded.
- The next improvement is smaller than one lesson.
