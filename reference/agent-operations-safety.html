Agent Operations 安全參考

核心契約：先以 read-only 或 plan rehearsal 界定 affected scope；只授予任務必要的 tools、paths 與時間；write 只在 recoverable local fixture；任何 external side effect 另行取得明確 authority；以 deterministic evidence 證明結果，並保存 failure、recovery、unverified limits 與 stop。

Authority 與證據矩陣

層級允許前提必留 evidence立即停止
讀取可信 inputs、allowed paths、敏感資料 boundary 已寫明。讀取集合、baseline、未知事項。需要越界、解密、取得新帳號或外部資料。
寫入Explicit paths／operations、restore point、bounded batch、owner 已核准；只在 recoverable fixture。前／後、寫入集合、deterministic check、recovery point。Plan／actual scope 不符、fixture 無法恢復、oracle 失效。
外部副作用每一 action 的 target、payload、cost、audience、deduplication／idempotency 與 recovery 已由有權者核准。Approval identity、action receipt、postcondition、compensation 或 safe-stop disposition。Target／payload 漂移、無法避免重複、不可逆且 judgment 未完成。

五個不能被 agent 自評取代的 gates

  1. 範圍 gate：planned read／write／external targets 與 observed affected scope 一致。
  2. 權限 gate：每種 side effect 都能連回具體 approval；context isolation、排程或委派不會自動增加權限。
  3. 完成 gate：oracle 能對錯誤 state 失敗，並針對本次 run inputs 產生 proof。
  4. 復原 gate：controlled failure 後能重試而不重複、回復 restore point，或在無法安全恢復時停住。
  5. 判斷 gate：殘餘風險、未知與不可逆決定由 learner／owner disposition；模型不批准自己。

Production 邊界：Canonical self-study closeout 不要求 unattended production mutation、push、deploy、真實寄送、付款或其他外部 write。若真實 mission 另需這些行為，必須離開練習 fixture，重新確認 authority、Review 與組織 runbook；未執行 production action 不是 closeout 缺陷。
