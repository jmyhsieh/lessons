Template promotion 速查表

把多次有效的 input 或 review contract 升級成 template 欄位。

驗收句：下次任務一開始就帶著必要欄位，reviewer 不必反覆追同一份 evidence。

Target selector

Template放什麼升級條件
Issue templateoutcome、scope、gates、stop condition。任務啟動時重複缺同一欄。
PR templateevidence path、risk、manual check。review 時重複追同一證據。
Handoff templatecurrent state、artifacts、next decision。接手時重複缺上下文。
Reference template低頻但格式要一致的 note。還不適合每次必填。

欄位設計原則

原則做法
少一次只加一到三欄。
具體用 evidencePath，不要用「補充說明」。
可刪設定 review 條件，常空白就移除或改寫。
不強制化需要人類判斷時，不升級成 gate。
