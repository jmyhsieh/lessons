Agent call evidence 速查表

把 dry-run plan 接成真 agent call 時，先保護呼叫邊界與可回看的 evidence。

第一個真 call 的驗收句：即使任務失敗，reviewer 也能從 evidence 重建 prompt、限制、輸出、錯誤與停止原因。

Wrapper contract

欄位必留內容用途
command.jsonargv、cwd、version、model、permission/settings/tool/MCP policy、時間。重建有效執行契約。
prompt.redacted.txt在 durable write 前 scrub 過的 prompt。確認 input 沒跑偏。
agent.stdout.json先 scrub 的模型輸出或 structured output。供 gate 與 report 摘要使用。
agent.stderr.txt先 scrub 的 CLI 錯誤、警告、debug 摘要。判斷 blocked / failed。
exit.jsonexit code、status、分類理由。讓 runner 不靠聊天記憶。
redaction.json規則版本、命中類型、人工 review 狀態。證明敏感資料邊界。
retention.jsonclassification、owner、expiresAt、deletion status。確保 evidence 能到期清除。

最小 bounded argv

[
  "claude",
  "-p",
  "<prompt>",
  "--output-format",
  "json",
  "--max-turns",
  "3",
  "--max-budget-usd",
  "2.00",
  "--permission-mode",
  "dontAsk",
  "--tools",
  "Read,Edit,Bash",
  "--allowedTools",
  "Read(/src/auth/**)",
  "Read(/tests/auth/**)",
  "Read(/package.json)",
  "Edit(/src/auth/**)",
  "Edit(/tests/auth/**)",
  "Bash(npm test -- auth)",
  "--disallowedTools",
  "mcp__*",
  "--strict-mcp-config",
  "--setting-sources",
  "project"
]
三個欄位不能混用：--tools 限制可見的 built-in tools；variadic --allowedTools <tools...> 只預先核准後續各 argv elements；--permission-mode dontAsk 讓其他請求直接被拒絕。MCP 不受 --tools 影響，所以本例另用 strict MCP config 與 mcp__* deny。
Path rules 不是完整 sandbox：Edit(/src/auth/**) 會限制 built-in file tools，但不會限制 Bash subprocess。Runner 還要在隔離 worktree／container 啟用 OS sandbox，只開 contract 所需 write paths；after-run scope gate 再比對 tracked 與 untracked change set。

command.json 最少還要記錄

{
  "claudeVersion": "<captured version>",
  "model": "sonnet",
  "effort": "high",
  "permissionMode": "dontAsk",
  "settingSources": ["project"],
  "effectiveSettingsSha256": "<hash>",
  "tools": ["Read", "Edit", "Bash"],
  "allowedTools": ["Read(/src/auth/**)", "Read(/tests/auth/**)", "Read(/package.json)", "Edit(/src/auth/**)", "Edit(/tests/auth/**)", "Bash(npm test -- auth)"],
  "disallowedTools": ["mcp__*"],
  "mcpPolicy": "none"
}

狀態分類

Status何時使用下一步
completedProcess exit 0，structured output 可解析。進入 gate execution；不等於 overall passed。
needs-reviewAgent 有輸出，但分類仍需人工判斷。讀 redacted 摘要與 artifact。
failedCLI exit code 非零，或 structured output 不可解析。修 wrapper 或 prompt。
blocked缺權限、缺 credential、budget/turn limit 觸發。回到 input 或環境設定。

不要放進 report

內容放哪裡原因
完整 stdout/stderrEvidence artifact。Report 只需要摘要與路徑。
含祕密的 promptRedacted evidence。避免把 credential 或客戶資料擴散。
Telemetry raw body受控 observability backend。內容型資料需要額外同意與保護。

Capture 與 retention 邊界

控制最小政策
RedactionPrompt/stdout/stderr/telemetry body 在 durable write 前 scrub；report/history 只收摘要與路徑。
Version control.harness/evidence/ 預設加入 .gitignore；不得以 commit 當 artifact store。
AccessEvidence dir/file 使用 owner-only ACL，例如 0700/0600 或平台等價設定。
Retention每包 evidence 記 owner、classification、expiresAt 與 deletion method。
Raw exceptionUnredacted raw output 需另行核准，只放受控 ephemeral store；TTL 到期後記錄 deletion status。

完成定義

Done when:
- The wrapper reads exactly one dry-run plan.
- The real agent call freezes version, settings, MCP, permissions, tools, turns, and budget.
- stdout/stderr are scrubbed before durable write; evidence has ACL and retention metadata.
- Report only links to evidence and summarizes status.
- Failed or blocked calls are explicit, not hidden as success.
