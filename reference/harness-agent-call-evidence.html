Agent call evidence 速查表

把 dry-run plan 接成真 agent call 時，先保護呼叫邊界與可回看的 evidence。

第一個真 call 的驗收句：即使任務失敗，reviewer 也能從 evidence 重建 prompt、限制、輸出、錯誤與停止原因。

Wrapper contract

欄位必留內容用途
command.jsonargv、cwd、startedAt、endedAt、duration。重建實際呼叫。
prompt.txt送入 agent 的 prompt 或 redacted prompt。確認 input 沒跑偏。
agent.stdout.json模型輸出或 structured output。供 gate 與 report 摘要使用。
agent.stderr.txtCLI 錯誤、警告、debug 摘要。判斷 blocked / failed。
exit.jsonexit code、status、分類理由。讓 runner 不靠聊天記憶。

最小 argv

[
  "claude",
  "-p",
  "<prompt>",
  "--output-format",
  "json",
  "--max-turns",
  "3",
  "--max-budget-usd",
  "2.00",
  "--tools",
  "Read,Edit,Bash",
  "--allowedTools",
  "Bash(npm test -- auth)"
]

狀態分類

Status何時使用下一步
passedAgent 完成，且本片允許的基本檢查通過。進入 gate execution。
needs-reviewAgent 有輸出，但尚未由 reviewer 或 gates 確認。先讀 stdout 摘要。
failedCLI exit code 非零，或 structured output 不可解析。修 wrapper 或 prompt。
blocked缺權限、缺 credential、budget/turn limit 觸發。回到 input 或環境設定。

不要放進 report

內容放哪裡原因
完整 stdout/stderrEvidence artifact。Report 只需要摘要與路徑。
含祕密的 promptRedacted evidence。避免把 credential 或客戶資料擴散。
Telemetry raw body受控 observability backend。內容型資料需要額外同意與保護。

完成定義

Done when:
- The wrapper reads exactly one dry-run plan.
- The real agent call uses bounded tools, turns, and budget.
- stdout, stderr, command metadata, and exit status are written to evidence.
- Report only links to evidence and summarizes status.
- Failed or blocked calls are explicit, not hidden as success.
