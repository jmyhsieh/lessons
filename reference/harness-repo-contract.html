Repo contract 速查表

把 verified workflow patch 固化到最小、最合適的 repo-level 規範。

Repo contract 的驗收句：下一個 agent 不看聊天紀錄，也能在正確位置讀到規則，並用 evidence 判斷它是否仍有效。

Contract target selector

Target適合使用升級條件
CLAUDE.md每個 session 都需要的短規則。同一件事已重複解釋或被 review 抓到。
.claude/rules/*.md可依路徑或主題拆分的 repo 規範。規則只適用某類檔案或模組。
AGENTS.mdCodex 或多 agent 共用指南。repo 同時服務不同 agent。
Issue template任務啟動時必填的 input contract。每次 brief 都缺同一欄。
Reference checklist半手動流程、reviewer 或 handoff 判斷。規則還需要人類語境判斷。
Hook / runner gate低誤判、必須強制的檢查。同類任務連續驗證，且 failure signal 清楚。

# Repo workflow contract

Decision rules

情境處理方式
只是少問一個 brief 欄位。更新 issue template 或 reference checklist。
每個 session 都需要知道。更新 CLAUDE.md；若給 Codex 用，更新 AGENTS.md。
只適用某路徑。放進 .claude/rules/*.md，並加 paths scope。
必須阻擋危險指令或收工。用 settings、hook 或 runner gate。
還沒被第二輪驗證。不要固化，回 Phase 4 第 06 課。

完成定義

Done when:
- Source verification points to a keep result.
- Contract target is the smallest useful location.
- The rule is short, specific, and reviewable.
- Verification evidence is named.
- Rollback condition is explicit.
