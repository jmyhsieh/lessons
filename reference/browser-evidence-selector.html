瀏覽器證據選擇器

先主張、再介面：先由 007-0001 固定一個可被反證的使用者可觀察的主張，再選一個探索介面。Desktop Browser、Claude in Chrome、Playwright CLI 與 Playwright MCP 是替代選項；表格不代表工具階梯，也不要求交叉跑完。

來源快照：2026-07-17依 Claude Code Desktop Browser、Claude in Chrome、Playwright CLI README eee5a185 與 Playwright MCP README 55679f5f 校準。實際帳號、用戶端、延伸功能、套件、瀏覽器與組織政策以學習者當下可見介面為準。

30 秒選擇流程

  1. 要既有個人／工作登入狀態嗎？需要且有明確網站權限，選 Claude in Chrome；不需要，保持乾淨設定檔。
  2. 正在 Claude Code 桌面版驗證本機應用程式／專案檔案，且乾淨的瀏覽器設定檔足夠嗎？是，選 Desktop Browser。
  3. 需要程式開發代理程式用精簡命令、具名工作階段與可檢查產物探索嗎？是，選 Playwright CLI。
  4. 只有持續保留結構化脈絡、反覆頁面內省檢查或長時間執行的迴路才能回答主張嗎？是，且受信任的 MCP 設定／工具／網站都有邊界，選 Playwright MCP。
  5. 仍無法唯一選擇時，回主張卡找出真正的識別、工作階段或證據要求；不要以「全部都跑」消除決策。
主要工作表面選擇理由最重要邊界保留的探索證據不要宣稱
Desktop Browser本機預覽／乾淨設定檔／與 Claude Code 桌面版工作區並排與個人瀏覽器識別分離；外部網站仍有網域、動作與組織政策基準識別、直接觀察、必要快照／主控台／請求識別乾淨設定檔的結果適用於既有個人登入
Claude in Chrome主張需要現有已登入的工作階段或可見瀏覽器權限共享瀏覽器識別；登入、驗證碼、敏感資料與副作用由學習者控制瀏覽器／延伸功能／網站權限、設定檔／驗證狀態、直接觀察一個登入角色代表所有角色，或 screenshot 等於 test
Playwright CLI程式碼導向、留意權杖用量的命令與具名工作階段產物Node／套件／瀏覽器、artifact 寫入範圍、工作階段狀態與清理精確 CLI 識別、工作階段、快照／主控台／請求 artifact 路徑CLI 探索命令已是 repo 內持久的 Playwright Test
Playwright MCP持續的結構化脈絡與反覆內省檢查的收益足以負擔較大介面受信任的伺服器／設定、工具允許清單、網站、瀏覽器設定檔；MCP 不是安全邊界伺服器／設定識別、已啟用工具、工作階段／快照參照、直接觀察MCP 比 CLI 更高階、更安全，或兩者皆必做

證據進程，不是介面進程

階段真正前進的是
主張（聲明）固定行為、反證條件與範圍。
選擇一個工作表面固定探索的識別、工作階段、權限與成本。
可觀察基準固定比較識別，分離觀察、artifact 與推論。
持久 Playwright 證據把同一主張寫成在有缺陷的 fixture 會失敗、修正後可重跑的 repo test。
條件式 trace／附錄只有診斷需要才保留 trace，最後將 test、環境、限制與學習者判斷附回 Engineering 收尾。

共通停止點：主張不清、目標網站未授權、設定檔／身分驗證識別不可揭露或不可重建、介面不可用、MCP 來源不可信、artifact 會保存敏感資料，或操作會造成不可回復外部副作用時停止。備援必須保持同一主張；如果備援改變識別、範圍或預期結果，先回007-0001重寫主張。完成 selector 或基準不代表 Playwright Test、瀏覽器證據附錄、Phase 7或 Migration 完成。
