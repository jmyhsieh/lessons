Browser evidence selector

先 claim、再 surface：先由 007-0001 固定一個可被反證的 user-observable claim，再選一個 exploration surface。Desktop Browser、Claude in Chrome、Playwright CLI 與 Playwright MCP 是 alternatives；表格不代表工具階梯，也不要求交叉跑完。

Source snapshot：2026-07-17 依 Claude Code Desktop Browser、Claude in Chrome、Playwright CLI README eee5a185 與 Playwright MCP README 55679f5f 校準。實際 account、client、extension、package、browser 與 organization policy 以 learner 當下可見 surface 為準。

30 秒 selection flow

  1. 要既有個人／工作 login state 嗎？需要且有明確 site authority，選 Claude in Chrome；不需要，保持 clean profile。
  2. 正在 Claude Code Desktop 驗證 local app／project file，且 clean Browser profile 足夠嗎？是，選 Desktop Browser。
  3. 需要 coding agent 用 concise commands、named session 與 inspectable artifacts 探索嗎？是，選 Playwright CLI。
  4. 只有 persistent structured context、反覆 page introspection 或 long-running loop 才能回答 claim 嗎？是，且 trusted MCP configuration／tools／sites 都有邊界，選 Playwright MCP。
  5. 仍無法唯一選擇時，回 claim card找出真正的 identity、session 或 evidence requirement；不要以「全部都跑」消除決策。

Evidence progression，不是 surface progression

階段真正前進的是
Claim固定 behavior、反證條件與 scope。
Choose one surface固定 exploration 的 identity、session、authority 與成本。
Observable baseline固定比較 identity，分離 observation、artifact 與 inference。
Durable Playwright evidence把同一 claim 寫成在 faulty fixture 會失敗、修正後可重跑的 repo test。
Conditional trace／addendum只有診斷需要才保留 trace，最後將 test、environment、limits 與 learner judgment附回 Engineering closeout。

Common stop：Claim 不清、target site 未授權、profile／authentication identity 不可揭露或不可重建、surface 不可用、MCP 來源不可信、artifact 會保存敏感資料，或操作會造成不可回復 external side effect 時停止。Fallback 必須保持同一 claim；如果 fallback 改變 identity、scope 或 expected outcome，先回 007-0001 重寫 claim。完成 selector 或 baseline 不代表 Playwright Test、Browser evidence addendum、Phase 7 或 Migration complete。
