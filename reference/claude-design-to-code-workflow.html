Phase 4 · Design · Canonical reference

Design route 與 handoff 速查表

核心邊界：Design 把 bounded brief 轉成 selected direction、prototype evidence 與 reviewable handoff bundle。它可以在 bundle 合法停止；只有 mission 要交付 version-controlled implementation 時，才帶 bundle 進 Phase 6 Build。

Verified environment：2026-07-16 依 Anthropic Claude Design product、Help Center 與 launch pages 檢查 beta availability、design-system、revision、prototype 與 handoff surfaces。實際 plan、client、organization setting、labels 與連接方式可能變動；操作前以當下 first-party guide 為準。

七個 tangible wins

004-0001 Surface
Route selection card：artifact、uncertainty、availability、feedback 與 legal stop。
004-0002 Brief
可重述的 user task、真實 content、states、context、non-goals 與 acceptance。
004-0003 System（conditional）
只有 approved context 才進入；留下 source identity、mismatch 與 disposition。
004-0004 Directions
同一 brief 下比較不同 assumptions，保存 baseline 與 selection rationale。
004-0005 Revision
一次改一層，用同一 task 判斷 accept／revise／revert。
004-0006 Assumptions
直接操作 viewport、input、states 與 accessibility criteria；標示 untested。
004-0007 Handoff
整合 source、intent、rules、evidence、limits、learner judgment 與 feedback。

Conditional branch 與 return

情況動作返回點
有 approved design system／brand／product context走 004-0003，校正一個代表性 mapping回 004-0004
沒有 approved context明記「不發明 tokens」，跳過 004-0003直接到 004-0004
Readiness／access／rights 不足保存目前 artifact，補最小缺口回原 Design lesson，不重跑整條 route
Handoff 已完成且不需 repo change寫下 learner judgment 與 feedback disposition合法停止並回 catalog
需要 repo implementation確認 Code readiness，帶 bundle 進 Phase 6Build 負責 implementation、checks、Review、closeout

若選擇 Build，先做 read-only handoff

請先只讀 handoff bundle、repository instructions 與相關檔案，不要修改。
請回報：
- design intent 對應的既有 components、tokens 與 states
- bundle 與 repo 的衝突、缺漏及需人決定事項
- 最小 vertical slice、non-goals 與可能修改檔案
- deterministic repo checks、browser evidence 與 Review 計畫

不要跨越：Handoff、export、MCP connection、design sync、可分享 prototype 或 read-only repo mapping都不授權 repository writes，也不證明 implementation fidelity。進 Phase 6 Build 後，仍須依 repo instructions 完成 bounded spec／tickets、implementation、checks、immutable Review 與 closeout。

Evidence 判斷

可以聲明不能只靠這項聲明
「在所列 revision／environment，這項 prototype assumption 被直接觀察支持。」「Production implementation 正確。」
「另一人能由 bundle 重述 intent 並抽查 evidence。」「Handoff 已自動實作或核准。」
「Automated check 提出或排除特定 accessibility finding。」「符合完整 accessibility conformance。」
「學習者已完成 feedback disposition，選擇合法停止。」「整門課或所有 Phase complete。」
