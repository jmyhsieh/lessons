Claude Design → Claude Code 工作流

從設計探索到 repo 實作的一頁式速查表 · 更新：2026-07-14

核心規則：Claude Design 用來探索、精修與形成可測的 prototype；Claude Code 用來在既有 repo 做最小實作。中間必須交付 design intent 與 evidence，不只交一張 screenshot。

Design-to-code flow

1 · Frame選 surface，寫 goal、layout、content、audience。
2 · Ground沿用已發布 system，或匯入 project context。
3 · Explore比較 2–3 個真正不同的方向，記錄取捨。
4 · Refine一次改一層，保存 revision 與決定。
5 · Validate驗 responsive、interaction、a11y 與使用者任務。
6 · Bundle封裝 source、intent、states、rules、evidence、scope。
7 · InspectClaude Code read-only mapping；先不改 repo。
8 · Implement沿既有慣例完成最小垂直切片。
9 · Verify跑 repo checks；真實 browser 對照 intent。
10 · CloseReview diff，記錄 deviations、未驗項與下一步。

Handoff bundle checklist

  • Claude Design project 與 revision
  • Design system／repo source
  • 使用者目標與資訊優先級
  • 關鍵 interaction 與狀態轉移
  • Loading、empty、error、disabled
  • Responsive breakpoint 行為
  • Keyboard、focus、name、contrast
  • 驗證結果與 open questions
  • 可接受 deviation 與理由
  • 最小切片與 non-goals
  • 預計 repo checks 與 browser checks
  • 預計修改檔案，經 dry inspect 確認

官方同步與 Design MCP

先分流：組織 design system 的 setup／publish 在 Claude Design onboarding 或 organization settings；/design-sync 只負責把既有 systems 或 codebase context attach／import 到 project。兩者都要人工校正，但完成證據不同。
# 在 Claude Code 依官方 get-started 加入 Claude Design MCP
claude mcp add --scope user --transport http claude-design https://api.anthropic.com/v1/design/mcp

# 接著在 Claude Code 登入
/design-login

# 將既有 design system 帶入 Claude Design project
/design-sync
Beta 指令可能變動：上列內容於 2026-07-14 對照官方 get-started。實際執行前重新核對官方頁面。MCP 連線或 sync 不等於授權 agent 改動整個 repo。

Read-only dry inspect prompt

先以 read-only 方式檢查 handoff bundle 與目前 repo，不要改檔，
也不要執行會產生副作用的命令。請列出：
- design 元件／token 對應的既有檔案
- 缺漏、衝突與需要人決定的問題
- 最小可實作切片及預計 diff
- repo checks 與 browser verification 計畫

Browser verification 最小矩陣

面向至少檢查不能只靠
Intent層級、內容、元件、狀態與關鍵取捨視覺相似度
Responsive窄／中／寬 viewport、溢位、重排、觸控目標單張桌面截圖
Interaction滑鼠、鍵盤、成功、失敗、loading、emptyHappy-path unit test
Accessibility語意、名稱、焦點、鍵盤、對比、狀態訊息Claude 自我 review
Closeout命令、結果、deviation、未驗項與原因「看起來完成」

Beta、availability 與 known limits

  • 狀態：Claude Design 目前為 beta；功能、介面與指令可能調整。
  • 方案：官方現列 Pro、Max、Team、Enterprise；Enterprise 預設關閉，需管理員啟用。
  • 平台：目前只在 web（claude.ai/design）與 Claude Desktop 提供。
  • Usage：Design activity 與 Claude chat、Claude Code、Cowork 共用方案 usage limits。
  • Comments：Inline comments 偶爾不顯示；可開 comments view，未被讀取時貼回 chat。
  • 大型 repo：可能造成 lag／browser 問題；官方建議從 Claude Code 連結並使用 /design-sync。
  • Chat error：遇到 chat upstream error，官方 workaround 是在同一 project 開新 chat tab。
  • 多人編輯：同步多人編輯仍屬基礎能力，可能不可靠。
  • 輸入品質：不完整 design system 或混亂 codebase 會直接反映在輸出。
