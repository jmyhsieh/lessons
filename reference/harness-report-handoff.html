Report / handoff 速查表

把 gates/evidence 收束成 reviewer 可判斷的 report，並交接給下一個 session。

Report 給人判斷；handoff 給下一輪接手。report 說明這次 run 是否可信，handoff 說明下一步怎麼繼續。

# Handoff: [next focus]

- Issue / brief:
- Report:
- Evidence:
- PR / diff:

Decisions made:
Risks / blockers:
Suggested skills:
Next action:

放哪裡

內容建議位置理由
Report.harness/reports/、PR comment、issue comment。它是可審查結果，應該能被團隊回看。
Evidence.harness/evidence/<run-id>/ 或 CI artifacts。大 log、截圖、輸出檔不適合塞進 report。
HandoffOS temp、handoff note、下一個 session prompt。它是交接脈絡，不一定要進 repo。

常見錯誤

錯誤修正
Report 只有「完成」。補 status、gate result、evidence path、未驗證項目。
Handoff 複製整份 issue。改成引用 issue path，只寫正本沒有的決策與下一步。
Evidence 塞滿 report。report 放摘要與 artifact path，完整輸出放 evidence 目錄。
下一個 agent 不知道用什麼方法接手。加 suggested skills 與下一步 prompt。
