Phase 12 · 機會盤點

find-animation-opportunities

唯讀找出少量值得評估的動態位置，也主動列出不該加動態的地方。

解決的問題

把候選從整頁中找出來

檢查狀態變化、空間關係與因果回饋，找出動態可能提升理解的地方。

何時用

不知道下一個機會在哪

已有可用產品，想在有限頁面內找一個高價值、低風險候選。

何時不用

不是「每處都加效果」

已有固定 diff 要審查時用 review-animations；沒有合適機會也是有效結論。

會讀寫什麼

唯讀頁面、元件與狀態

只需讀核准範圍，不應在找候選時修改產品程式或建立完整計畫。

權限與副作用

同時要求採用與排除。限制頁面與路徑；候選必須有使用者目的，排除高頻、干擾性或純裝飾位置。

最低完成證據

  • 一個值得評估的候選：位置、問題、用途與風險。
  • 至少一個明確排除：位置與不做理由。
  • 結果保持唯讀，未把候選當成實作許可。

交給 Claude Code

請使用 find-animation-opportunities，唯讀檢查「＿＿」頁面與指定路徑。
最多提出三個候選，依使用者價值與風險排序；至少列出一個不該加動態的位置。
不要修改程式，也不要為了湊數提出裝飾效果。
