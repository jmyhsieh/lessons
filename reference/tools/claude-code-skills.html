Claude Code 擴充工具 · 重用知識與流程

Claude Code Skills

把會重複使用的工作方法、判斷規則與支援資源包成可發現、可重跑的能力。

解決的問題

不用反覆重寫長 prompt

將穩定流程與專業知識放進 Skill，讓 Claude 在符合描述的任務中載入一致指引。

何時用

同一做法會跨任務重複

適合 repo 慣例、固定交付流程、領域檢查表，以及需要搭配參考文件或腳本的工作。

何時不用

只有一次，或要隔離 context

一次性問題直接說明即可；需要把大量搜尋留在主 context 外時，改用 Subagents。

會讀寫什麼

讀 SKILL.md 與配套資源

Skill 可包含指令、references、scripts 與 assets；若執行腳本或工具，副作用由那些資源決定。

權限與副作用

先讀內容，再決定安裝範圍。專案專用 Skill 放專案內；第三方 Skill 要確認來源、版本、腳本與移除方式，不把 secrets 寫進檔案。

最低完成證據

  • 描述清楚何時觸發、何時不觸發。
  • 用一個真實任務驗證產物與流程。
  • 另測一個不該使用此 Skill 的案例。

交給 Claude Code

先盤點目前重複出現的流程與 repo 慣例。
判斷「＿＿」是否值得做成 Skill；若值得，只提出最小結構、觸發描述、必要資源與驗證案例。
不要先建立檔案或安裝第三方內容。
