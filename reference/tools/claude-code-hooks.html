Claude Code hooks

在 Claude Code 的生命週期事件執行可預測的檢查、格式化、記錄或通知。

解決的問題

把固定規則變成自動動作

不必每次提醒 Claude 執行同一件事；指定事件發生時，由 hook 一致處理。

何時用

規則可以明確判定

適合格式化、記錄、通知與機械式驗證，尤其是漏做一次就會影響品質的步驟。

何時不用

需要情境判斷或討論

需求取捨、程式審查與模糊政策不該硬塞進固定腳本；這些工作保留給人或 agent 判斷。

會讀寫什麼

設定、輸入與命令副作用

Hook 會讀設定與事件輸入，並可執行命令、呼叫服務或修改檔案；實際副作用取決於設定內容。

權限與副作用

先縮小事件、matcher 與設定範圍。專案規則優先放在專案設定；執行前閱讀腳本，不把 secrets 或完整敏感輸入寫進 log。

最低完成證據

  • 記錄事件、matcher、設定位置與實際命令。
  • 觸發一次並保留輸出，另確認不符合條件時不執行。
  • 說明如何停用或移除 hook。
