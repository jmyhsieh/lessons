讓 Claude Code 操作可見瀏覽器，回答「這條使用路徑現在是否正常？」

解決的問題

查核眼前狀態

開頁、點擊、輸入、讀取畫面與 console，取得真實瀏覽器證據。

何時用

探索與一次性驗收

需求尚在探索、需要人工一起看畫面，或先確認問題能否重現。

何時不用

需要長期防回歸

若同一風險必須在 CI 重複檢查，改用 Playwright Test。

會讀寫什麼

瀏覽器狀態

會開啟頁面、操作表單並讀取 console；本身不會自動在 repo 留下測試檔。

權限與副作用

把登入與外部寫入當成真實操作。優先使用本機或測試環境；送出表單、刪資料、寄信、付款或發布前必須停下來確認。

最低完成證據

  • 實際走過的步驟與測試環境。
  • 最後可見狀態、console error 與未知項目。
  • 不能把「頁面能開」當成完整流程通過。
