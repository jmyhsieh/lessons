Phase 2 · 一次性程式化任務

Claude Code headless（claude -p）

以非互動方式送入一個範圍明確的任務，取得可供 shell、程式或後續流程處理的輸出。

解決的問題

把單次任務放進 script

輸入、工具範圍與輸出格式穩定時，不需要開啟互動工作階段逐步操作。

何時用

任務有明確終點

適合摘要、分類、抽取、固定檢查與結構化回傳，並且失敗行為可以預先定義。

何時不用

還在探索或風險很高

需求需要來回釐清、可能修改大量狀態，或遇到例外必須即時判斷時，使用互動工作階段。

會讀寫什麼

由 flags、prompt 與 tools 決定

可從 stdin 或參數接收輸入並輸出文字／結構化資料；允許工具後，也可能讀檔、執行命令或寫入。

權限與副作用

顯式限制工具與輸出格式。先用非敏感資料和唯讀任務測試；設定 timeout、錯誤處理與成本邊界，不把 secrets 拼進命令或 log。

最低完成證據

  • 保留完整命令、輸入來源、工具限制與輸出格式。
  • 輸出可被下一步穩定解析，且 exit status 被正確處理。
  • 至少驗證一個失敗或無結果案例不會誤報成功。

交給 Claude Code

先把「＿＿」縮成一個 claude -p 可完成的唯讀任務。
提出完整命令、輸入方式、允許工具、結構化輸出、timeout 與失敗處理。
先用最小無敏感資料的樣本示範，不要改檔或呼叫外部寫入。
