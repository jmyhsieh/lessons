Phase 11 · 用量觀測

ccusage

讀取本機 coding agent 使用紀錄，整理工作階段的 token 與成本估算，建立可比較的用量基準。

解決的問題

看本機用量結構

把零散紀錄整理成日、月或工作階段報表，觀察任務規模與用量變化。

何時用

需要自己的基準

比較兩種工作方式、追蹤長任務或記錄一次 Claude Code 工作階段。

何時不用

不是官方剩餘額度

要查方案限制或帳戶可用量，回官方產品介面；用量較低也不代表成果較好。

會讀寫什麼

讀本機紀錄

會掃描支援工具的本機使用資料並輸出報表；先確認範圍，避免把不相干工作階段混入。

權限與副作用

報表可能揭露工作時間、模型與專案模式。分享前先移除敏感路徑或識別資訊；安裝方式與支援資料來源以目前 README 為準。

最低完成證據

  • 記錄工具版本、資料範圍與報表時間窗。
  • 保留一張工作階段基準卡，註明估算與未知項目。
  • 用量結論與交付品質分開，不用 token 數取代成果驗證。
