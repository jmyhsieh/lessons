Phase 11 · 本機 Markdown 搜尋

QMD

在核准的 Markdown collection 裡做本機全文、語意或混合搜尋，再回到原文確認答案。

解決的問題

跨文件找相關內容

管理多個 Markdown collection，快速找到可能回答問題的文件與片段。

何時用

文件已多到記不住位置

筆記、規格或課程資料分散，但仍希望搜尋與索引留在本機。

何時不用

幾個已知檔案先直接讀

固定字串先用 rg；資料來源未核准時，不要為了方便把整個家目錄加入 collection。

會讀寫什麼

讀文件、建本機索引

會索引指定 collection。語意／混合搜尋可能另外下載模型；精確全文搜尋不必先啟用它們。

權限與副作用

collection 是資料邊界。只加入明確核准的路徑；先從全文搜尋開始。下載模型、建立 embeddings 或擴大資料範圍前另行核准。

最低完成證據

  • 列出 collection 名稱、實際路徑與查詢模式。
  • 搜尋結果能連回原始 Markdown，而不是只保留摘要。
  • 人工讀上下文，確認命中片段沒有斷章取義。
