文件轉換 · 少量文件

Claude Code 直接讀文件

不先安裝轉換器，直接讓 Claude Code 讀取少量 PDF 或圖片，整理成一次性 Markdown 草稿。

解決的問題

降低一次性設定成本

文件很少、任務很短時，直接讀取與整理，不先建立完整轉換工具鏈。

何時用

少量、人工可抽查

一兩份文件、只需摘要或結構化筆記，且能逐頁回看來源。

何時不用

大量或需可重現批次

大量文件、固定 pipeline、精確 OCR 或複雜表格，改用 MarkItDown 或 Docling。

會讀寫什麼

讀指定檔案、寫草稿

Claude Code 會讀你放入範圍的文件，並建立或修改 Markdown；模型輸出不是原文複本。

權限與副作用

先限制檔案範圍與資料敏感度。不要把 Claude Code 訂閱視為第三方 OCR plugin 的 API 憑證；若要呼叫外部服務，需另行說明。

最低完成證據

  • 草稿保留來源檔名與頁碼或畫面位置。
  • 人工核對專有名詞、數字、表格與否定句。
  • 不確定內容明確標記，不用流暢文字掩蓋缺漏。
