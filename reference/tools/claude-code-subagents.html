Claude Code 擴充工具 · Context 隔離

Claude Code Subagents

把範圍明確的調查交給獨立 context，主工作階段只接收結論與可回查證據。

解決的問題

避免主 context 被大量細節淹沒

將搜尋、log 分析或文件整理放到旁線，保留主線的決策脈絡與 token 空間。

何時用

旁線任務可以清楚交付

輸入範圍、預期答案與停止條件都能說明，而且結果可用檔案、行號或來源驗證。

何時不用

需要獨立寫入空間

Subagent 隔離的是 context，不必然隔離 checkout；平行修改應改用 worktree 或明確檔案所有權。

會讀寫什麼

獨立 context 與受控工具

Subagent 有自己的 prompt、context 與工具設定；是否能寫檔或執行命令，取決於授予的工具與權限。

權限與副作用

先縮小任務，再縮小工具。唯讀調查不授予 Edit／Write；說清楚不可越界的目錄、輸出格式與遇到未知時的停止條件。

最低完成證據

  • 保留交付給 subagent 的範圍與問題。
  • 結論附檔案、行號、命令輸出或來源連結。
  • 主工作階段明確記錄採納、拒絕或仍待確認的項目。

交給 Claude Code

把「＿＿」交給一個唯讀 subagent。
限制在「＿＿」範圍，只能使用 Read、Glob、Grep（必要時再列出其他工具）。
回傳三項內的結論、檔案與行號、未知項目；不要修改任何檔案。
