解決的問題

理解符號關係

分辨同名文字與真正程式符號，追蹤定義、引用、型別與呼叫關係。

何時用

跨檔案程式理解

評估修改影響、找實作、追引用，且語言已有可用 code intelligence plugin。

何時不用

固定字串先用 rg

搜尋設定值、文案或檔名時，rg 更直接；需要完整專案探索工作流再評估 Serena。

會讀寫什麼

讀 repo 與語言服務

LSP 查詢本身用於讀取程式關係；啟用前仍需對應 plugin 與 language server，可能增加專案設定。

權限與副作用

內建不代表自動可用。先確認支援語言、plugin 來源與 language server 安裝範圍；唯讀畫符號地圖時不要順手修改程式碼。

最低完成證據

  • 一個定義與至少兩個引用，含檔案與行號。
  • 以 rg 或人工閱讀交叉確認結果。
  • 清楚區分直接引用、間接呼叫與未解析項目。
