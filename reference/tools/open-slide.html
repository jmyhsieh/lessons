open-slide · 簡報製作

open-slide

把簡報當成 React 專案製作，適合需要 Git diff、元件、互動與 HTML／PDF 輸出的任務。

解決的問題

code-first 簡報

讓 Claude Code 在可追蹤的專案裡建立與修改投影片，而不是只在圖形介面手動排版。

何時用

需要 React、Git 或客製互動

交付接受 HTML／PDF，而且團隊願意維護 React、套件與 Git 歷史。

何時不用

PPTX 或一次性工作

必須交可編輯 PPTX、團隊不維護程式碼，或 Claude Design 已足以完成時。

會讀寫什麼

建立完整工作區

初始化會建立目錄、設定檔、AGENTS.md／CLAUDE.md、Skills 與相依套件。

權限與副作用

先核准新目錄與安裝命令。在隔離工作區初始化；編輯前先讀專案規則與需要的 Skill。公開部署是另一個需另行核准的動作。

最低完成證據

  • 有限、可說明的 Git diff。
  • 正式 build 成功並知道輸出位置。
  • 親自在瀏覽器檢查正式輸出；build 成功不等於版面正確。

交給 Claude Code

先唯讀檢查目前目錄與 open-slide 官方初始化方式。
提出隔離工作區名稱、會建立或下載的內容、驗證命令與停止線。
我核准前不要執行；建立後先讀 AGENTS.md、CLAUDE.md 與相關 Skill。
