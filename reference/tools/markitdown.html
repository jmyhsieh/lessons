MarkItDown

把有可靠文字層的 PDF、Word、Excel、PowerPoint 等文件轉成適合後續處理的 Markdown。

解決的問題

輕量文字轉換

抽取文件內容與基本結構，建立可搜尋、可引用、可再加工的 Markdown。

何時用

原檔已有文字層

一般 Office 文件與可選取文字的 PDF；先用最輕的轉換路線。

何時不用

掃描或版面複雜

輸出空白、亂碼、閱讀順序錯誤時，改評估 Docling，不要把基礎轉換器當本機 OCR。

會讀寫什麼

讀原檔、寫 Markdown

會讀指定文件並產生文字檔；選用額外 plugin 時，資料流與憑證需求可能不同。

權限與副作用

機密文件先確認處理邊界。使用基礎本機轉換；若 plugin 需要外部模型或 API，必須另外說明並核准。Claude Code 訂閱不是 API key。

最低完成證據

  • 記錄原檔、工具版本與實際命令。
  • 輸出標示為「待查核」，不能直接當權威內容。
  • 對照標題、段落、表格、數字與頁面，記下遺漏或順序錯誤。
