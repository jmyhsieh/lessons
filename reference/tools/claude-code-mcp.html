Claude Code MCP

透過 MCP server，讓 Claude Code 使用外部系統提供的工具、資源與資料來源。

解決的問題

跨出本機 repo

需要查詢 issue、文件、資料庫、瀏覽器或其他專用系統時，提供明確的整合介面。

何時用

外部系統才有權威資料

已有可信任的 MCP server，且任務確實需要它的工具或資料，而不是只讀本機檔案。

何時不用

本機工具已經足夠

讀檔、搜尋 repo 或跑現有命令不必先接 MCP；來源不明或權限過寬的 server 也不應連線。

會讀寫什麼

設定、憑證與外部狀態

連線方式可能需要 command、URL、環境變數或 OAuth；可見工具若含寫入能力，可能改變外部系統。

權限與副作用

只給任務所需的最小範圍。確認 server 來源、啟動命令、可見工具與憑證存放方式；先跑唯讀查詢，外部寫入另行核准。

最低完成證據

  • 記錄 server 來源、版本或端點、設定範圍與可見工具。
  • 用一個唯讀查詢取得可回查的來源資料。
  • 知道如何停用、移除與撤銷憑證。
