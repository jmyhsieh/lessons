Final handoff 速查表

把 latest run、parent chain、evidence 與未解風險整理成可接手交付包。

Final handoff 的驗收句：下一個 agent 或 reviewer 不看聊天紀錄，也能知道本輪決策、證據位置、未解風險與下一步。

Package sections

Section必填內容檢查問題
DecisionStatus 與一句理由。能不能判斷是否可收工？
Latest runrunId、inputId、reportPath。是否指向單一最新 run？
Parent chainparentRunId 與差異摘要。是否保留 rerun 歷史？
Evidence indexGate、report、stdout/stderr、截圖路徑。是否能打開 artifacts？
Open risksRisk、owner、next action。是否每項都有負責人？
Suggested skills下一輪 skill 或命令。是否具體到可執行？
Redactions敏感資訊檢查結果。是否移除 secret、token、PII？

完成定義

Done when:
- The package points to one latest run.
- Parent chain and rerun reason are visible.
- Evidence paths are canonical and verified.
- Every open risk has owner and next action.
- Suggested skills are specific.
- Sensitive data has been redacted.
