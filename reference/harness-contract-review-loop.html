Contract review loop 速查表

讓 repo contract 在下一輪 review 中被點名、被使用、被判斷。

驗收句：reviewer 不看聊天紀錄，也能知道哪條 contract 適用、它是否被遵守、下一步要 keep / revise / promote / retire。

Usage note 欄位

欄位用途常見錯誤
contract指向實際規範位置。只寫「依照規範」。
observedCompliance說明有沒有遵守。只寫 pass，沒有缺口說明。
reviewSignal指出它如何影響 review。只描述流程，沒有 signal。
nextAction決定 keep、revise、promote、retire。沒有後續決策。

Template

contractUsage:
  contract:
  appliedTo:
  observedCompliance:
  reviewSignal:
  nextAction:
  evidence:

放置位置

Review 入口適合情境
PR checklistreviewer 每次都要判斷。
Run reportrunner 或 harness 任務需要可追溯 evidence。
Handoff下一個 agent 或下一位同事要接手。
Reference note低頻流程，需要保留決策歷史。
