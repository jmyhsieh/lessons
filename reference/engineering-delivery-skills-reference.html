Review 契約

Review 必須固定候選版本與固定點；發現事項修正後建立新檢查點，兩軸全部重跑。欄位、失效規則與重跑範例見 Repo Review contract。

Wayfinder 返回邊界

Wayfinder 只為超過一個工作階段且決策路徑仍在模糊區裡的工作量圖／解決。地圖清楚後，把關聯決策帶回需求對齊、交付規格與工作票 DAG；它不形成獨立完成路徑，也不因一張前緣決策票關閉就宣稱 route 完成。

選擇規則

  • 能用確定性的 check 回答，就不要讓模型自評。
  • 需要可執行答案才用原型；回答後回規格。
  • 外部原始報告才走分流；難解缺陷先建立 feedback 迴路；架構 branch 只產出接縫探索摘要。
  • Wayfinder 只解規劃迷霧，輸出證據回交付流程。
  • 沒有 Code readiness 或權限邊界，就停在 route entry。
  • Skill 現行的契約與這份已審查的快照不一致時，先停止並重新校準 Source registry。
