Review contract

Review 必須固定 candidate 與 fixed point；finding 修正後建立新 checkpoint，兩軸全部重跑。欄位、失效規則與 rerun 範例見 Repo Review contract。

Wayfinder return boundary

Wayfinder 只為超過一個 session 且 decision path 仍在 fog 裡的 effort chart／resolve。Map 清楚後，把 linked decisions 帶回 request alignment、delivery spec 與 ticket DAG；它不形成獨立 completion path，也不因一張 frontier ticket 關閉就宣稱 route complete。

選擇規則

  • 能用 deterministic check 回答，就不要讓模型自評。
  • 需要 runnable answer 才用 prototype；回答後回 spec。
  • 外部 raw report 才走 triage；hard bug 先建立 feedback loop；architecture branch 只產出 seam discovery brief。
  • Wayfinder 只解 planning fog，輸出 evidence 回 delivery flow。
  • 沒有 Code readiness 或權限邊界，就停在 route entry。
  • Skill current contract 與這份 reviewed snapshot 不一致時，先停止並重新校準 Source registry。
