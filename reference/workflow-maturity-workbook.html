Workflow maturity 工作簿

這份 learner-owned workbook 只保存被選擇之 advanced route 的 artifact lineage：Workflow evidence dossier、Scenario rollout plan 與 Governance lifecycle policy。它不是新 route、Phase checklist、universal scorecard、automatic promotion gate 或第二套 source of truth；尚未選擇的區段保持 not selected，不用補齊。

使用規則

  1. 每個區段只放 artifact ID、owner、decision、limits 與原始證據連結；細節留在原 artifact。
  2. 完成 evaluation 不會自動進 rollout；完成 rollout design 也不代表實際 adoption或 production authorization。
  3. Deterministic checks 只檢查 identity、link、required fields 與 date，不能自動計算「成熟度」。
  4. 每次 package、scope、authority 或 evidence 改變，建立新 revision並保留舊 lineage。
No maturity score：不同 workflow 的風險、audience、judgment 與 evidence 不可壓成一個通用等級。不要用總分宣稱 ready、promote、deploy 或 govern；每個 route 都有自己的 entry、legal stop 與 accountable learner decision。
