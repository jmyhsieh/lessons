Advanced appendix：遇到缺口再開

A · Runner 與交付細節

  • Report / handoff：report 與 evidence 如何分工。
  • Runner 第一片：list、show、dry-run handler 與 fixtures。
  • Gate execution：change set、status precedence 與 gate-results。
  • Rerun policy：可重跑原因、parent lineage 與 stop condition。
  • Final handoff：latest run、open risks 與 canonical paths。
  • Closeout decision：ship、review、rerun、blocked、downgrade。

B · Rehearsal 與 workflow patch

  • Repo rehearsal：用低風險真實任務跑第一輪。
  • Workflow patch：一次只修一個 rehearsal finding。
  • Patch verification：以第二輪同類任務做 keep／revise／revert。

C · Repo contract 治理

  • Repo contract：把 verified patch 放到最小正確位置。
  • Contract review loop：在 review checkpoint 真正使用 contract。
  • Contract effectiveness：用少量 signals 看是否降低返工。
  • Template promotion：把重複缺欄位升級成 template。
  • Hook / gate promotion：低誤判、可機械判斷後才強制化。
  • Contract cleanup：合併、移動或退役過時規則。
