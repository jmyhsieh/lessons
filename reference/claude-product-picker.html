一句話判斷規則

需要思考、回答、草稿，內容自己貼得進去 → Claude
需要 AI 動手處理電腦裡的檔案與文件（非程式碼）→ Cowork
需要 AI 在 git repo 裡讀、寫、執行程式碼 → Claude Code

正式專案安全要點（Claude Code）

  • 預設權限模式會在改檔、跑指令前逐項詢問 — 正式 repo 請保持此模式。
  • 先開分支再讓它動手；用 PR review 把關，不直接推 main。
  • CLAUDE.md 放在 repo 根目錄，記錄專案規範，每次 session 自動讀取。
