速查表：先選成果環境，再選 Claude 工作表面

這張表用來做 route choice，不是產品能力排行榜。實際 availability 可能依方案、組織設定、client 與 rollout 改變；開始前以你看得到的產品 surface 為準。

Claude對話與附件 context回答、分析、草稿輸入來源與預期讀者已驗證的外部事實或自動完成的多檔案工作
Cowork授權的 task files；部分 surface 可處理本機資料夾整理後的文件與檔案read／write 範圍、敏感資料與交付 review無需檢查的完成品或 repo delivery
Claude Design視覺 brief、design context 與 prototype方向、原型、簡報、design intent受眾、feedback criteria 與 handoff boundaryusability、accessibility 或 production readiness 證明
Claude Codegit repo 與執行環境repo map、diff、checks、checkpointinstructions、permissions、safe scope 與 Code readiness未經 Review 的 production-ready change

一句話 selector

只需思考、回答或草稿，context 由你提供 → Claude
需要在授權檔案範圍完成多步驟知識工作 → Cowork
需要先探索視覺方向、原型或簡報 → Claude Design
需要在 repo 中讀、改、執行 checks 與 review diff → Claude Code
