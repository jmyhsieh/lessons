一句話判斷規則

需要思考、回答、草稿，context 由你用文字、附件或 connector 提供 → Claude
需要 AI 完成多步驟知識工作，或透過 Desktop 處理本機文件（非程式碼）→ Cowork
需要先探索視覺方向、做互動原型、反覆評論，再交接實作 → Claude Design
需要 AI 在 git repo 裡讀、寫、執行程式碼 → Claude Code

Claude Design 的停止線

  • Design system 抽取結果要由品牌或產品負責人檢查，不能自動視為正確。
  • Claude 的 accessibility review 是待驗證建議，不是 audit 結果。
  • Prototype 用來取得回饋；production readiness 仍看 repo diff、browser evidence、tests 與 human review。

完整交接流程見：Claude Design × Claude Code 速查表。

正式專案安全要點（Claude Code）

  • 正式 repo 先用 Desktop Manual 或 CLI default：工作目錄內讀檔與內建唯讀指令通常直接執行，編輯與其他指令會詢問。
  • 先開分支再讓它動手；用 PR review 把關，不直接推 main。
  • CLAUDE.md 放在 repo 根目錄，記錄專案規範，每次 session 自動讀取。
