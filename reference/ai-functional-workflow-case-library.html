AI 職能工作流案例總覽

把案例按「工作責任」整理，而不是按職稱整理。本頁只收 2026/04/01 起發布，且案例本身明確使用 Claude Code 的來源。

讀法：先找你現在負責的職能，再看該職能的下一個可驗收 artifact。不要照抄公司或工具名稱；要抄的是流程槽位、驗證方式與交接證據。未明確使用 Claude Code 的 Claude 生態案例不放進主表。

職能對照表

職能適用情境細部案例
產品職能 收斂需求、做可驗收原型、對齊 stakeholder 與上線條件。 產品細部案例
工程職能 改 repo、切小 diff、跑 tests / review / PR，或處理長任務 agent session。 工程細部案例
研究 / 資料職能 重現 paper / data、設 oracle tests、做 domain review 與 bias check。 研究 / 資料細部案例
營運 / IT / RevOps 職能 處理活動資料、CRM 匯入、incident / runbook 或內部工具流程。 營運 / IT / RevOps 細部案例
創業 / Founder 職能 從使用者洞察做產品切片、demo、回饋收集與下一輪假設。 創業 / Founder 細部案例
平台 / 治理職能 管理 access、成本、eval gates、政策、長任務執行與 incident review。 平台 / 治理細部案例
本次排除：Claude Managed Agents、finance agents、Claude Cowork、Figma Make、Walmart Code Puppy 等仍可作為延伸脈絡，但目前不是「2026/04 起發布且案例本身明確使用 Claude Code」的主案例。

如何選案例

你要收斂需求
從產品職能開始，看 artifact 是否能被使用者或 stakeholder 驗收。
你要改 repo
從工程職能開始，先定義 test、review、PR 與 rollback。
你要處理資料
從研究 / 資料職能開始，把可重跑、oracle tests 與 bias check 寫進流程。
你要導入團隊工具
從平台 / 治理職能開始，先定義權限、成本、替換性與審計。

延伸細節

本頁是嚴格篩選後的主入口。每個職能都有細部案例頁：產品、工程、研究 / 資料、營運 / IT / RevOps、創業 / Founder、平台 / 治理。
