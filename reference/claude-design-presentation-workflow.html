Claude Code × Claude Design 簡報

Claude Code 管理來源、故事與 Design MCP；真人管理內容核准、輸出檔與彩排。01–08 先完成一份簡報，真的要反覆使用或對外交付，再接 09–12。

入門完成線：你審查過 Claude Code 整理的三頁故事，實際打開輸出並講過一次；聽眾能說出重點與下一步，一個重要主張找得到原始資料。

三頁故事

頁回答的問題內容
1現在怎麼了？一個讓受眾知道為何要聽的完整句子
2資料告訴我們什麼？一個重要證據＋來源
3接下來要做什麼？一個選擇、決定或行動

給 Claude Code 的 prompt

先只根據我提供的三份資料，整理三頁 storyboard：
1. 現在怎麼了
2. 資料告訴我們什麼
3. 接下來要做什麼

不要發明數字或引言；每個重要主張標出來源。
等我核准 storyboard 後，再透過 Claude Design MCP 為［受眾］建立三頁簡報。

輸出前只查三件事

真人打開來源確認最重要的數字 · 真人打開目標格式並在實際距離閱讀 · 關鍵意思不只靠顏色。Claude Code 可以列檢查清單，不能假裝完成這些觀察。

格式選擇

PPTX：別人要繼續編輯。 PDF：固定版面閱讀或列印。 HTML：確實需要互動。

進階 09–12

課只做這件事留下什麼
09讓 Claude Code 草擬高影響主張與精確來源人工核准的 claim ledger
10讓 Claude Code 擷取反覆視覺決定，再用 Design MCP 重生一頁人工比對過的 deck system
11Claude Code 列 preflight；真人檢查 accessibility 與輸出檔交付前稽核紀錄
12把真實彩排觀察交回 Claude Code，只核准一個修正觀察紀錄＋受控版本

停止線

只需要一份可講的三頁簡報，完成第 08 課即可；需要 HTML／PDF、React 與 Git 工作流，再改查 open-slide 工具卡。不要讓模型生成的「聽眾回饋」取代真人彩排。
