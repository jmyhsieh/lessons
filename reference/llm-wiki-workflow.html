LLM Wiki × Claude Code 路線速查卡

前三課用一個 raw 連結開始；實際使用後，再走 schema、ingest、query、lint 與自動化。

入門完成線：Claude Code 建好最小版本 · 加入一份真實來源 · 回答一個能回查來源的問題。

直接貼給 Claude Code

請讀這份 LLM Wiki idea file：
https://gist.githubusercontent.com/karpathy/442a6bf555914893e9891c11519de94f/raw/ac46de1ad27f92b28ac95459c782c07f6b8c964a/llm-wiki.md

請在目前資料夾幫我建立最小可用版本。
先問我這個 Wiki 要整理的主題，再建立需要的最少檔案。
不要先安裝額外工具，也不要一次加入大量來源。

接下來只做三件事

課你要做的動作完成證據
01把 raw idea file 與需求交給 Claude Code資料夾中出現最小 Wiki
02加入第一份真實來源，抽查一個說法說法能回到原始資料
03問一個小問題，要求指出使用來源答案有來源或誠實說不足

進階 04–08：Wiki 開始成長後再學

課解決的真實需求完成證據
04 · schema讓 agent 下次仍遵守已驗證的規則現有指引只加入真實規則
05 · ingest讓一份新來源更新既有知識看過計畫、diff 與來源回查
06 · query把跨頁探索變成可重用結果有引用，並判斷是否寫回
07 · lint找出矛盾、過期、孤兒頁與缺口修一項並重跑同一檢查
08 · 自動化省下重複、可確定檢查的工作命令有成功與失敗輸出

前三課先由 Claude Code 處理

檔案結構、schema、ingest、query、lint、log 與自動化都不是開始前的必修。完成第 03 課、Wiki 有了真實資料與問題後，再用 04–08 一次解決一個維護需求。

只守住兩條線

要守住原因
原始資料保留，不讓 Wiki 取代來源模型整理可能誤讀，重要說法要能回查
資料不足時明說不知道避免把模型常識或猜測混成 Wiki 已知內容
