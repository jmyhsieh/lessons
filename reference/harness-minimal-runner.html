Minimal runner 速查表

把成熟的 issue / brief、gates、evidence、report/handoff 串成一條可重跑的單任務路徑。

先做 runner，不做平台。最小 runner 只讀一份 input、跑一個任務、產出一份 report。多任務、排程、資料庫與 UI 都是後續層。
