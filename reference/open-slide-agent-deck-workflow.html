Phase 7：Claude Code × open-slide

Claude Code 讀取 scaffold 產生的 CLAUDE.md 與 workspace skills；你核准命令、審查 diff 並親自看 browser。01–04 完成第一個三頁切片，遇到重用、稽核或部署需求再接 05–09。

留在 Claude Design，如果：
需要 PPTX 交接、想用 canvas 快速修改，或團隊不想維護 React／Git。
讓 Claude Code 使用 open-slide，如果：
交付接受 HTML／PDF，而且 Git diff、客製互動、React 元件或部署能力真的重要。

一句話做決定

「我選 Claude Design／open-slide，因為交付格式需要＿＿，團隊也願意／不願意維護 React 與 Git。」

入門 01–04

課只做這件事留下什麼
01請 Claude Code 唯讀比較 Claude Design 與 open-slide人工核准的選路理由
02核對目標與命令，再讓 Claude Code 建立隔離 workspacedev server browser evidence
03讓 Claude Code 讀 CLAUDE.md、使用 /create-slide人工審查過的三頁 diff
04請 Claude Code build／preview，真人打開正式輸出dist/＋檢查紀錄

讓 Claude Code 提議的最小命令

npx @open-slide/cli init phase7-open-slide --use-npm --locale zh-TW
cd phase7-open-slide
npm run dev
npm run build
npm run preview

學員不必背 React 或 open-slide API；先核對 target directory 與命令，再授權執行。建立後，Claude Code 應先讀 workspace 的 CLAUDE.md，再選用對應 skill。

Claude Code 工作迴圈

讀 CLAUDE.md 與 relevant skill
→ 說明這次只改什麼
→ 等人核准後執行
→ 顯示 diff 與 build output
→ 真人在 browser 檢查

進階 05–09

課解決的真實需求留下什麼
05Claude Code 先讀 CLAUDE.md 與 relevant skillscontract-aware bounded diff
06Claude Code 以 /create-theme 收斂重複規則theme＋一個重用 pattern
07Claude Code 列查核點，真人檢查來源與畫面來源＋accessibility evidence
08Claude Code 以 /apply-comments 處理具體回饋comment＋diff＋重新驗證
09Claude Code 準備 package；owner 決定是否部署deployment-ready package

停止線

必須交可編輯 PPTX 就回 Phase 5。第 04 課是獨立入門完成線；不需要重用、稽核或部署，就不必繼續第 05–09 課。Build 成功仍要打開目標輸出；Claude Code 不能代替 owner 授權公開部署。
