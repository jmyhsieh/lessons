Quick Reference · Phase 5

Phase 5 日常視覺交付物速查表

先選使用時刻，再選格式。主交付物只選一個；其他格式在主版本通過內容查核後再改作。

30 秒選路

你會在現場帶著聽眾走向決策？
選 Deck。需要故事 spine、delivery notes（可獨立成 sidecar）、時間控制與彩排。
讀者會自行閱讀、轉寄或核准？
選 One-pager。需要完整上下文、掃讀層級與獨立來源。
只要在單一版位推動一個動作？
選 Social asset。需要單一 hook、單一 CTA、權利與版位測試。
要測試流程、互動或任務完成率？
選 Prototype，回到 Phase 4。

格式比較

格式主要優勢最常失敗真實驗收
Deck講者控制節奏與共同決策把講稿全文塞進 slide限時彩排＋聽眾能重述決策
One-pager可獨立閱讀與轉寄缺少講者後上下文斷裂沒聽簡報的人可自行理解
Social asset快速觸及與單一 CTA一張圖承擔太多訊息目標尺寸三秒掃讀＋CTA 清楚
Prototype可觀察真實任務與互動把漂亮畫面當 usability 證據真實使用者完成指定任務

Deck 選定後，再選 authoring surface

Claude Design
需要 canvas 精修、非工程協作或 PPTX 交接；走 Phase 5 第 04–08 課主線。
open-slide
需要 React 客製、Git diff 或 static HTML／PDF；完成主線後走 第 09 課 vertical slice。

選定後填四欄

Audience：誰？已知什麼？
Moment：現場聽、自行讀、滑到內容或實際操作？
Next action：之後要決定、核准、分享、點擊或完成什麼？
Success：能觀察到什麼才算交付有效？

停止線

不要用 Claude Design 的能力清單替你決定格式。若受眾、使用時刻與下一個動作還寫不出來，先不要生成。
