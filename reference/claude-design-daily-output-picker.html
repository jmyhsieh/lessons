日常視覺交付物入門選擇卡

在 Claude Code 先問內容會怎麼被使用，再決定要讓 Design MCP 產生哪種格式。

Deck

你會在現場帶著聽眾，依順序說明並推動下一步。

One-pager

讀者會自己閱讀、轉寄或核准，沒有講者補充。

Social asset

只需要一個重點與一個行動，閱讀時間很短。

Prototype

你需要觀察使用者是否能完成一個操作，改走小畫面路線。

本課預設

三頁簡報路線會先請 Claude Code 定義一個真實 deck 任務、整理來源與 storyboard；核准後才透過 Design MCP 完成三頁簡報，最後再把同一份已核准內容改成 one-pager。

何時改查 open-slide 工具卡

只有交付接受 HTML／PDF，而且團隊真的需要 React、Git diff、客製互動或部署時，才讓 Claude Code 使用 open-slide。必須交 PPTX 或只想快速完成簡報，就繼續使用 Claude Design MCP。
