Contract effectiveness 速查表

用少量 evidence 判斷 repo contract 是否真的減少返工。

驗收句：一條 contract 的有效性，應能由同類任務中的 evidence path 支撐，而不是只靠「感覺有幫助」。

Signal selector

Signal有效 evidence可能決策
Clarification reduced同類任務不再追問同一欄。keep 或 promote。
Review fasterreview note 能直接指到 artifact。keep。
Handoff quality下一個 agent 可接手，不需重問背景。keep 或 template promotion。
Noise欄位常空白、常被改寫、常出現合理例外。revise 或 retire。
Effort cost同類任務是否反覆需要 xhigh/max 或多輪 rerun。revise input/gate，或降回 high。

Decision rules

觀察結果處理方式
三次同類任務都有改善。keep，或進入 template promotion。
改善只出現在單一任務。繼續觀察，不升級。
常被跳過或補例外。revise、move 或 retire。
需要 dashboard 才能看懂。先把 contract 切小。
連續依賴 max。不要視為成熟；回頭修 contract 或 gate。
max 沒改善 evidence。下次降回 high。
