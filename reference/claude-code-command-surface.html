Claude Code 操作必備 command 速查表

先記住工作流控制用 command，不需要背完整清單。

使用原則：commands 是 session 控制台。先用它控制風險、上下文、驗證與交付，再考慮大型自動化。

起手式

Command用途何時使用
/help列出可用 command。不確定環境支援哪些指令時。
/init產生 starter CLAUDE.md。第一次進 repo。
/memory編輯或查看 memory。團隊規範需要被每次 session 記住。
/permissions管理 allow、ask、deny 規則。正式 repo 設定安全邊界。

任務中控制

Command用途何時使用
/plan進入 plan mode。跨檔案、大改動、需求不清楚。
/model切換模型，也可在 picker 調 effort。任務風險或複雜度改變。
/effort調整推理程度。需要在速度、成本、深度之間取捨。
/context查看 context 使用狀態。長 session 開始變慢或變散。
/compact壓縮目前對話。要保留任務脈絡，但釋放 context。

交付前

Command用途何時使用
/diff看目前變更與每回合 diff。準備 review 或 commit 前。
/run啟動並檢查 app 行為。需要看真實 UI 或互動結果。
/code-review檢查目前 diff 的 bug 與清理點。交付前做一輪本地審查。
/review對 PR 做較深的 read-only review。需要審 PR，而不是只看本機 diff。
/security-review檢查安全風險。變更碰 auth、資料、權限、輸入處理。

換任務或復原

Command用途何時使用
/clear開始新對話，保留 project memory。換成不相關任務。
/resume回到之前 session。接續舊任務。
/rewind回到 checkpoint 或摘要部分對話。方向錯了，需要退回。
/goal設定完成條件，讓 Claude 跨回合持續工作。已有清楚 stop condition、gate 與 evidence。
