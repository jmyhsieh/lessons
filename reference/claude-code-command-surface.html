Claude Code 操作速查表：桌面版 UI 與 CLI 命令

先分清楚你在哪個介面：Desktop App 用畫面入口；CLI 才以斜線命令為主。

使用原則：Desktop App 不等於 CLI。應用程式先找畫面上的模型、權限、diff、preview、工作階段側邊欄。需要斜線 command 時，只用 prompt 方塊的 / 或 + → Slash commands 看目前可用項目；不要把 CLI 指令表直接套到應用程式。

Desktop App

看快捷鍵

打開應用程式快捷鍵清單。這是快捷鍵清單，不是斜線 command 清單。

看可用命令
/+ → Slash commands

清單裡出現的才代表目前應用程式可用。

開新工作階段

用側邊欄的新工作階段。每個工作階段有自己的專案資料夾、歷史紀錄、變更。

權限模式

用模式 selector。新手正式 repo 先用人工；工作目錄內讀檔與內建唯讀指令通常直接執行，編輯與其他指令會詢問。

模型 / 工作量

用模型下拉選單與工作量選單。高工作量是例外，不是預設。

看變更

用 diff 統計 / diff 窗格。交付前一定看。

Preview

用 Preview 窗格。前端、HTML、PDF、圖片都可用。

Terminal

用內建 terminal。只在本機的工作階段可用。

Side chat

用側邊對話。旁支問題不要污染主對話。

View mode

用檢視模式選單切換一般 / 詳細 / 摘要。

應用程式特別注意：/help 不作為應用程式的查詢入口；應用程式用 / 或 + → Slash commands。/diff、/model、/effort、/compact 只有出現在應用程式清單時才當快捷，否則用上表的 UI。

CLI（命令列）

查詢
/help

顯示 CLI 說明與可用命令。應用程式不用這個。

第一次進 repo
/init/memory

建立或調整 CLAUDE.md 與記憶。

權限與設定
/permissions/config/agents

管理權限規則、設定與子代理程式。這些常是終端機對話方塊類型，應用程式改走 UI 或設定檔。

任務中控制
/plan/model/effort

進入規劃模式，或調整模型與推理程度。

上下文管理
/context/compact/btw

查看脈絡、提早壓縮、或開旁支問題。

交付前檢查
/diff/code-review/review [PR]/security-review

查看變更、檢查正確性、做官方 PR 審查或安全審查。

換任務或復原
/clear/resume/rewind

清空目前對話、接續舊工作階段、或回到檢查點。

診斷
/doctor

診斷 Claude Code 安裝與設定問題。

CLI 特別注意：官方文件明確說 command 可用性會依平台、計畫、環境改變；實際仍以你在 CLI 輸入 / 或 /help 看到的清單為準。

CLI 啟動旗標：在工作階段外先界定執行

Slash commands 控制已開啟的工作階段；啟動旗標則在啟動前固定脈絡、工具、權限與輸出。兩者不要混用。以下只作任務導向探索，真正執行前仍以本機 claude --help 為權限。

隔離調查
--agent--agents

選擇或定義有界的代理程式；唯讀的權限仍由代理程式工具／權限明確限制。先練習：002-0008。

隔離改動
-w--worktree [name]

建立獨立工作目錄／branch；不隔離憑證、網路或外部的資源。先練習：002-0009。

一次性執行
-p--tools--allowedTools--output-format--max-budget-usd--no-session-persistence

固定無頭單次執行的工具、輸出、成本與持續性；非互動模式會跳過工作區信任對話框，只能從可信目錄執行。先練習：002-0010。

外部執行邊界
--permission-mode--setting-sources--strict-mcp-config

這些旗標只能表達部分執行期邊界；遠端觸發、權杖權限、機密資料、不受信任的輸入、網路、retry 與核准 stop 仍要由 CI 契約限制。先做桌上演練：002-0011。

共同 stop：本機說明沒有該旗標、現行的用戶端沒有對應介面、目錄不可信，或權限／副作用無法逐項說明時就停止。不要用文件中的完整目錄推定目前帳號與環境一定可用。
