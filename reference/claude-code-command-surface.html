Claude Code 操作速查表：Desktop UI 與 CLI commands

先分清楚你在哪個介面：桌面 App 先用可視化操作；slash commands 是可用時的快捷。

使用原則：桌面 App 先找畫面上的 model、permission、diff、preview、session sidebar。需要 slash command 時，在 prompt box 輸入 / 看目前可用清單；不要假設每個 CLI command 都能在 Desktop Code tab 使用。

桌面 App UI 優先

目的桌面 App 操作備註
看鍵盤快捷鍵App 快捷鍵清單。這是快捷鍵清單，不是 slash command 清單。
開新 sessionsidebar 的 New session。每個 session 有自己的 project folder、history、changes。
權限模式mode selector。新手正式 repo 先用 Ask permissions。
選模型model dropdown。任務變難時再調。
調 efforteffort menu。高 effort 是例外，不是預設。
看變更diff stats / diff pane。交付前一定看。
PreviewPreview pane。前端、HTML、PDF、圖片都可用。
Terminal內建 terminal。只在 local session 可用。
Side chatside chat。旁支問題不要污染主對話。
切換 view modeview mode 選單。Normal / Verbose / Summary。

App 可用 slash commands

Command用途使用方式
/瀏覽目前可用 slash commands、skills、plugins。在 prompt box 輸入。
/help查看目前環境支援的 commands。若清單有就可用。
/init產生 starter CLAUDE.md。若清單有就用；否則用自然語言請 Claude 建立。
/model、/effort切換模型與推理程度。桌面 App 新手先用 UI；command 可作快捷。
/compact提早壓縮對話、釋放 context。也可等系統自動 summarization。
/btw開 side chat。App 若有 side chat UI，也可直接使用。

Desktop 不適用

Command 類型代表例子桌面 App 路徑
Terminal-dialog commands/permissions、/config、/agents、/doctor改用 UI、settings files，或到 CLI 執行。
CLI session control/clear、/resume、/rewindApp 先用 sidebar、session history、diff 與 git。
