Claude Code 操作速查表：Desktop UI 與 CLI commands

先分清楚你在哪個介面：Desktop App 用畫面入口；CLI 才以 slash commands 為主。

使用原則：Desktop App 不等於 CLI。App 先找畫面上的 model、permission、diff、preview、session sidebar。需要 slash command 時，只用 prompt box 的 / 或 + → Slash commands 看目前可用項目；不要把 CLI 指令表直接套到 App。

Desktop App

看快捷鍵

打開 App 快捷鍵清單。這是快捷鍵清單，不是 slash command 清單。

看可用 commands
/+ → Slash commands

清單裡出現的才代表目前 App 可用。

開新 session

用 sidebar 的 New session。每個 session 有自己的 project folder、history、changes。

權限模式

用 mode selector。新手正式 repo 先用 Ask permissions。

模型 / effort

用 model dropdown 與 effort menu。高 effort 是例外，不是預設。

看變更

用 diff stats / diff pane。交付前一定看。

Preview

用 Preview pane。前端、HTML、PDF、圖片都可用。

Terminal

用內建 terminal。只在 local session 可用。

Side chat

用 side chat。旁支問題不要污染主對話。

View mode

用 view mode 選單切換 Normal / Verbose / Summary。

App 特別注意：/help 不作為 App 的查詢入口；App 用 / 或 + → Slash commands。/diff、/model、/effort、/compact 只有出現在 App 清單時才當快捷，否則用上表的 UI。

CLI

查詢
/help

顯示 CLI help 與可用 commands。App 不用這個。

第一次進 repo
/init/memory

建立或調整 CLAUDE.md 與 memory。

權限與設定
/permissions/config/agents

管理權限規則、設定與 subagents。這些常是 terminal-dialog 類型，App 改走 UI 或 settings files。

任務中控制
/plan/model/effort

進入規劃模式，或調整模型與推理程度。

上下文管理
/context/compact/btw

查看 context、提早壓縮、或開旁支問題。

交付前檢查
/diff/code-review/review/security-review

查看變更、檢查 correctness、做 PR 或安全審查。

換任務或復原
/clear/resume/rewind

清空目前對話、接續舊 session、或回到 checkpoint。

診斷
/doctor

診斷 Claude Code 安裝與設定問題。

CLI 特別注意：官方文件明確說 command availability 會依 platform、plan、environment 改變；實際仍以你在 CLI 輸入 / 或 /help 看到的清單為準。
