Claude Code 操作速查表：Desktop UI 與 CLI commands

先分清楚你在哪個介面：Desktop App 用畫面入口；CLI 才以 slash commands 為主。

使用原則：Desktop App 不等於 CLI。App 先找畫面上的 model、permission、diff、preview、session sidebar。需要 slash command 時，只用 prompt box 的 / 或 + → Slash commands 看目前可用項目；不要把 CLI 指令表直接套到 App。

Desktop App

看快捷鍵

打開 App 快捷鍵清單。這是快捷鍵清單，不是 slash command 清單。

看可用 commands
/+ → Slash commands

清單裡出現的才代表目前 App 可用。

開新 session

用 sidebar 的 New session。每個 session 有自己的 project folder、history、changes。

權限模式

用 mode selector。新手正式 repo 先用 Manual；工作目錄內讀檔與內建唯讀指令通常直接執行，編輯與其他指令會詢問。

模型 / effort

用 model dropdown 與 effort menu。高 effort 是例外，不是預設。

看變更

用 diff stats / diff pane。交付前一定看。

Preview

用 Preview pane。前端、HTML、PDF、圖片都可用。

Terminal

用內建 terminal。只在 local session 可用。

Side chat

用 side chat。旁支問題不要污染主對話。

View mode

用 view mode 選單切換 Normal / Verbose / Summary。

App 特別注意：/help 不作為 App 的查詢入口；App 用 / 或 + → Slash commands。/diff、/model、/effort、/compact 只有出現在 App 清單時才當快捷，否則用上表的 UI。

CLI（命令列）

查詢
/help

顯示 CLI help 與可用 commands。App 不用這個。

第一次進 repo
/init/memory

建立或調整 CLAUDE.md 與 memory。

權限與設定
/permissions/config/agents

管理權限規則、設定與 subagents。這些常是 terminal-dialog 類型，App 改走 UI 或 settings files。

任務中控制
/plan/model/effort

進入規劃模式，或調整模型與推理程度。

上下文管理
/context/compact/btw

查看 context、提早壓縮、或開旁支問題。

交付前檢查
/diff/code-review/review [PR]/security-review

查看變更、檢查 correctness、做官方 PR review 或安全審查。

換任務或復原
/clear/resume/rewind

清空目前對話、接續舊 session、或回到 checkpoint。

診斷
/doctor

診斷 Claude Code 安裝與設定問題。

CLI 特別注意：官方文件明確說 command availability 會依 platform、plan、environment 改變；實際仍以你在 CLI 輸入 / 或 /help 看到的清單為準。

CLI launch flags：在 session 外先界定 execution

Slash commands 控制已開啟的 session；launch flags 則在啟動前固定 context、tools、permissions 與輸出。兩者不要混用。以下只作 task-based discovery，真正執行前仍以本機 claude --help 為 authority。

隔離調查
--agent--agents

選擇或定義 bounded agent；read-only authority 仍由 agent tools／permissions 明確限制。先練習：002-0008。

隔離改動
-w--worktree [name]

建立獨立 working directory／branch；不隔離 credentials、network 或 external resources。先練習：002-0009。

一次性執行
-p--tools--allowedTools--output-format--max-budget-usd--no-session-persistence

固定 headless one-shot 的 tools、output、cost 與 persistence；non-interactive mode 會跳過 workspace trust dialog，只能從可信 directory 執行。先練習：002-0010。

外部執行邊界
--permission-mode--setting-sources--strict-mcp-config

這些 flags 只能表達部分 runtime boundary；remote trigger、token permissions、secrets、untrusted input、network、retry 與 approval stop 仍要由 CI contract 限制。先做 tabletop：002-0011。

共同 stop：本機 help 沒有該 flag、current client 沒有對應 surface、directory 不可信，或 authority／side effects 無法逐項說明時就停止。不要用文件中的完整 catalog 推定目前帳號與環境一定可用。
