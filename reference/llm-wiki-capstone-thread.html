用途：這是一張 learner-owned lineage worksheet，讓選擇同一 LLM Wiki 題目的學習者保留跨 route 的 artifact identities、judgment 與 feedback。它不是新 route、不是額外 source of truth，也不是 Phase 3、8、9 或 course completion checklist。

每一站都做 lineage check

  1. Identity：引用 exact source pack、wiki revision、run、contract 與 package digest；不要只寫「最新版」。
  2. Source of truth：Material claim 永遠回 raw source locator；wiki、thread、contract 與 package 都不能升格成證據來源。
  3. Authority：後一站不得繼承前一站未授予的 read、write、network、publish、push、deploy 或 remote-delete 權限。
  4. Evidence：把 artifact、learner judgment、reviewer feedback 與 route closeout 分開；Lesson practiced 不會自動變 Route artifact produced。
  5. Return：保存目前 route anchor、legal stop 與精確 return point；optional continuation 必須由新 mission 觸發。

停止條件：任一 identity 不可重建、raw provenance 斷裂、rights／authority 不明、failure 沒有 disposition、package 超出 proven contract，或 learner 只是為了「集滿 Phase」而繼續時，保存 thread 後停止，回對應 route 的缺口。Thread 不得被 instructor、agent 或 automation 當作批准、採用或完成權威。
