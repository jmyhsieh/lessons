Wayfinder 共用地圖速查表

巨大模糊工作量的選路、地圖 schema、工作票類型、前緣與工作階段 stop 規則。

內容校準自已審查的契約 9603c1c；契約漂移時先重新做 Source recertification。

一句話：Wayfinder 不是把巨大工作切成施工票，而是把看不清的路整理成決策工作票；路清楚後，再交給 /to-spec → /to-tickets → /implement。

選擇器

訊號判斷
已能寫完整規格與阻擋工作票不要用 wayfinder；直接進主線。
一個工作階段能把所有未知問清楚用 /grill-with-docs。
巨大、跨工作階段，連問題順序都仍在模糊區裡使用 wayfinder。

標準地圖結構

## Destination
一兩句：這張 map 要找出哪份 spec、哪個決策或哪條改變路徑。

## Notes
領域、固定偏好、每個 session 要查的 skills。

## Decisions so far
- [Ticket title](link) — 一句答案 gist

## Not yet specified
在 scope 內，但目前還無法精確問成 ticket 的 fog。

## Out of scope
超出 destination、永遠不會從 fog 升級的工作。

工作票類型

標籤模式完成訊號
wayfinder:researchAFK（離席執行）research/<name> branch 上有已引用的摘要；工作票留脈絡指標。
wayfinder:prototypeHITL（人在迴路）人類對 artifact 作反應，留下可引用答案。
wayfinder:grillingHITL（人在迴路）真正的決策者逐題回答，代理程式不代答。
wayfinder:taskAFK／HITL 模式阻擋決策的操作完成並留下事實。
研究例外：決策工作票建立並連接阻擋邊後，為每張研究工作票平行啟動 /research subagent。研究留在可丟棄的 research/<name> branch，工作票留脈絡指標；繪圖代理程式不手動逐張解票。

工作票、模糊區、範圍外

分類判斷題存放位置
工作票現在已能精確說出要回答的問題。地圖的子議題。
模糊區知道這塊在範圍內，但還無法精確問問題。尚未指定。
範圍外即使變清楚，也超出目的地。範圍外；不會升級。

繪製地圖

  1. 透過追問與網域建模固定目的地。
  2. 廣度優先掃描整片未知區，不急著深挖一題。
  3. 建立標記 wayfinder:map 的標準地圖。
  4. 只建立現在能精確問出的決策工作票。
  5. 工作票取得識別碼後，再第二輪連接阻擋邊。
  6. 為每張研究工作票平行啟動 /research subagent。
  7. 看得到前緣後停止；繪圖代理程式不手動解票。

依地圖推進

以下是普通前緣決策票的循序迴路；繪圖時已啟動的研究子代理程式是平行例外。

  1. 載入地圖低解析全貌。
  2. 選第一張未解的、未被阻擋、未被領取前緣決策票。
  3. 先指派給自己，再依工作票類型解題。
  4. 把完整答案留在解決留言，關閉工作票。
  5. 地圖只新增工作票名稱、連結與一句要旨。
  6. 建立新工作票、連接邊、升級模糊區或移出範圍。
  7. 停止；下一張普通工作票留給下一個工作階段。

不變量

  • 地圖是索引，不是答案倉庫。
  • 人類文字用工作票標題，不用裸議題 ID。
  • 被指派者是主張；先主張才開始。
  • 普通前緣工作階段最多解一張工作票；平行研究子代理程式是明確例外。
  • 預設產出決策，不產出目的地交付物。
離場：沒有未解的工作票、沒有可升級模糊區、路徑已清楚 → 回需求對齊，再由 /to-spec → /to-tickets 收斂關聯決策；本課程不把 Wayfinder 地圖當成直接施工授權。

回到 Engineering 交付流程

Wayfinder 的輸出是證據，不是另一條完成路徑。地圖尚未完成就由新工作階段繼續解一張前緣決策票；地圖完成後，先到需求對齊關聯決策，再固定交付規格、切工作票，最後才實作與 Review。
