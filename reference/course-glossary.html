工作介面與執行環境

課程用語意思
工作介面（surface）完成任務的產品或介面，例如 Claude、Cowork、Claude Design、Claude Code。
工作階段（session）一段有自己對話脈絡的工作對話；換工作階段前，要先把重要狀態寫進持久文件。
對話脈絡（context）模型目前能使用的對話、檔案與指令。內容多不代表內容乾淨。
規劃模式（plan mode）允許探索、提出計畫與風險，但不直接修改檔案的模式。
權限規則（permission rule）限制工具或命令能否執行的規則；它不能證明內容正確。
事件勾點（hook）在指定事件自動執行的確定性檢查或動作。
工作技能（Skill）可重用的代理工作說明與資源；使用前先讀適用條件與停止線。
MCP讓 Claude Code 透過受控工具連接外部系統或資料的協定。
子代理（subagent）負責邊界清楚子任務的獨立代理；結果仍要回到主要工作流程整合與驗證。
工作樹（worktree）同一個 Git 程式庫的另一份工作目錄，用來隔離分支與平行改動。

從需求到可驗證交付

課程用語意思
規格（spec）把已對齊的問題、範圍、需求、限制與驗收方式寫成可持續使用的文件。
工作項目（ticket）可由單一負責人認領，並具有完成條件的工作切片。
有限切片（bounded slice）範圍小到能在目前工作中檢查、驗證與說清楚的一段實作。
回饋迴圈（feedback loop）能穩定重現、觀察改動效果，並快速再次執行的診斷方式。
比較起點（fixed point）審查或比較的明確起點，例如 commit、tag 或 merge-base。
交接（handoff）讓下一個工作階段或接手者不用重讀整段對話，也能恢復狀態的持久文件。
產出（artifact）可被檢查與使用的成果，例如規格、程式碼、簡報、查核表或交接文件。
完成證據（exit evidence）能證明結果達到完成條件的產出、判斷說明與驗證證據；只勾完清單還不算。

Claude Code 工作技能

課程用語意思
流程可預期性（process predictability）Skill 讓 Claude Code 在不同執行中走相近、可審查的過程；不要求逐字相同。
使用者手動啟用（user-invoked）只有使用者輸入 /skill-name 才執行的 Skill；以 disable-model-invocation: true 控制。
Claude 自動啟用（model-invoked）Claude 可依 description 自動選用的 Skill；啟用是否正確與執行結果要分開測試。
按需讀取提示（context pointer）告訴 Claude Code 何時讀取另一份內容的短指示。
按需載入（progressive disclosure）把特定情況才需要的資料移出 SKILL.md，需要時才讀取。
引導詞（leading word）Claude 已熟悉、能用少量文字喚起一組做法的詞；要用實際行為判斷是否有效。
完成條件（completion criterion）每個步驟可檢查的完成標準，用來避免 Claude 太早收尾。
實際查找與驗證（legwork）為了達到完成條件而進行的讀檔、查找、驗證與整理。
單一維護來源同一個行為規則只放在 Skill 系統中的一個維護位置，避免互相矛盾。
歷史堆積／無效指令（sediment／no-op）前者是只加不刪累積的過期內容；後者是刪掉也不會改變 Claude Code 行為的句子。

設計與簡報交付

課程用語意思
設計意圖（design intent）畫面背後要保留的受眾、層級、互動與品牌判斷。
Claude Design MCP讓 Claude Code 連接 Claude Design 的官方工具；連線不代表已授權修改程式庫或公開內容。
設計交接（design handoff）把選定方向、設計意圖、使用者任務與有限範圍帶回程式庫。
設計系統校正（design system calibration）把生成結果與正式元件、設計 token 或品牌資產逐項比對。
狀態表（state matrix）記錄預設、載入中、空白與錯誤等狀態在不同畫面寬度的行為。
端到端切片（vertical slice）用少量頁面或功能走完一條工作流程，以驗證方向與交付邊界。
來源包（source pack）帶來源、狀態與負責人的真實內容集合，是生成視覺產物前的內容地基。
權威來源（source of truth）主張可回查的原始位置；模型重述或多份簡報互相引用不算來源。
故事主線（story spine）從聽眾現況、證據到下一個決策的敘事順序。
簡報（deck）由講者控制節奏、用來建立共同理解並推動決策的投影片組合。
主張查核表（claim ledger）把高影響主張逐一連到精確來源、查核狀態與限制條件。
共用簡報規則（deck system）經實際重用的字級、色彩、間距與版型規則。
彩排（rehearsal）在目標環境向代表性聽眾實際講一次，記錄問題與理解落差。
上線前收尾（production closeout）用測試、真實瀏覽器證據與已知限制，收斂準備進產品的有限切片。
程式化簡報（code-first deck）把投影片當成程式碼與靜態網站維護，使用 React、Git、建置與瀏覽器驗證。
工作區技能契約（workspace skill contract）open-slide 的 CLAUDE.md 與本地 Skills，說明程式庫規則與受控命令。
檢閱留言（inspector comment）在 open-slide 瀏覽器檢閱器對元素留下、可由 Claude Code 處理的具體回饋。
可部署交付包（deployment-ready package）已驗證輸出，並寫清楚負責人、權限、版本、發布方式與回復做法；不代表已公開。

Claude Code × Playwright

課程用語意思
關鍵路徑（critical path）風險高、價值明確，而且能用開始狀態、使用者動作與可觀察結果描述的瀏覽器路徑。
Playwright MCP讓 Claude Code 操作真實瀏覽器的 MCP server；適合即時查核，但不會自動留下持久測試。
即時瀏覽器查核（live browser check）Claude Code 當下走過一條路徑並重新讀取頁面狀態的觀察證據。
Playwright Test Agent由 Playwright 產生、供 Claude Code 使用的角色定義與 MCP 工具組合；輸出仍需人工審查。
規劃代理／產生代理／修復代理（planner／generator／healer）分別整理規格、依核准規格產生測試，以及診斷失敗測試的三個角色。
起始測試（seed test）已在程式庫真實通過的最小測試，讓代理沿用正確設定與應用程式起點。
元素定位（locator）Playwright 在每次操作時重新尋找元素的方式。
會等待頁面的斷言（web-first assertion）會重複查找並等待介面達到預期狀態的非同步斷言。
追蹤記錄（trace）可回看操作、DOM、網路與斷言的執行紀錄，用來判斷問題在產品、測試或環境。
測試組態（project）一組 Playwright Test 設定，可代表特定瀏覽器、裝置、環境或測試群組。
CI 關卡（CI gate）在合併或交付前自動執行測試，失敗時阻擋流程並提供受控證據。

LLM Wiki 與知識累積

課程用語意思
LLM Wiki由 Claude Code 協助建立與更新的持久 Markdown 知識庫；重要內容仍要能回到原始資料。
原始想法檔（raw idea file）直接交給 Claude Code、用來建立第一版 Wiki 的起始文件。
原始資料（raw source）支持 Wiki 的文件、筆記或網頁；保留原文，不讓模型覆寫。
待確認來源不同、資料不足或仍需人決定的內容；先誠實標記。

文件轉換與 OCR

課程用語意思
文字型文件內含可搜尋、可複製文字層的 PDF 或 Office 文件；通常先用 MarkItDown。
掃描文件頁面主要是影像、沒有可靠文字層的 PDF 或圖片；通常需要 OCR。
光學字元辨識（OCR）從頁面影像辨識文字的過程；數字、專有名詞、表格與閱讀順序仍需人工查核。
MarkItDownMicrosoft 的輕量文件轉 Markdown 工具；基礎套件不會自動替掃描 PDF 做本機 OCR。
Docling可在本機處理 OCR、版面、閱讀順序、表格與 Markdown 輸出的文件轉換工具。
強制 OCR（force OCR）用 OCR 結果取代既有文字層；只在掃描頁或文字層損壞時使用，不是預設選項。
轉換紀錄連結原檔、輸出、工具版本、實際命令、人工查核範圍與已知缺口的可追查資料。
核准清單（allowlist）批次轉換前明確列出的精確檔案集合，避免遞迴掃描未授權資料。
批次結果清單（manifest）逐檔記錄 success、failed、skipped、輸出位置與查核狀態的結果表。

Phase 6 進階詞

課程用語意思
資料規則（schema）讓 Claude Code 重複遵守 Wiki 結構與維護慣例的指引。
匯入（ingest）讀取一份新原始資料，整合進既有 Wiki，並維護索引與紀錄。
查詢（query）從索引定位相關頁面、附來源回答問題，必要時把結果寫回。
整合異同（reconcile）整理新舊說法，同時保留矛盾與不確定性。
Wiki 格式檢查（lint）檢查過期說法、孤兒頁、缺少連結與資料缺口。
自動化（automation）把重複、可用確定規則檢查、低破壞性的步驟做成可重跑命令。
證明包（proof pack）用來證明 Wiki 可重跑、可查核的一組進階證據。
