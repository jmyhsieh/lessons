工作表面與執行環境

詞彙本課程中的意思
surface完成任務的產品或介面，例如 Claude、Cowork、Claude Design、Claude Code；先依交付物選 surface。
session一段有自己 context 的工作對話；換 session 前要把重要狀態寫進 durable artifact。
context模型目前能使用的對話、檔案與指令脈絡；長不等於乾淨，也不能取代持久文件。
plan mode先探索、提出計畫與風險，不直接修改檔案的工作模式。
permission rule限制工具或命令可否執行的規則；不等於內容正確性驗證。
hook在特定事件自動執行的 deterministic 檢查或動作。
Skill可重用的代理工作說明與資源；要先讀適用條件與停止線。
MCP讓 agent 透過受控工具連接外部系統或資料的協定與整合方式。
subagent負責邊界清楚子任務的獨立 agent；輸出仍需由主工作流整合與驗證。
worktree同一 Git repository 的另一份工作目錄，用來隔離分支與並行改動。

從需求到可驗證交付

詞彙本課程中的意思
spec把已對齊的問題、範圍、需求、限制與驗收方式寫成可持續使用的文件。
ticket可由單一 owner 認領、具完成條件的工作切片。
bounded slice範圍小到能在目前工作中檢查、驗證與說清楚的一段實作。
feedback loop能穩定重現、觀察改動效果並快速再次執行的診斷迴圈。
fixed pointreview 或比較的明確起點，例如 commit、tag 或 merge-base。
handoff讓下一個 session 或接手者不用重讀整段對話，也能恢復狀態的持久交接。
artifact可被檢查與使用的產物，例如 spec、程式碼、簡報、ledger 或 handoff。
exit evidence證明學習或工作結果達到完成條件的產物、判斷說明與驗證證據；不是只勾完 checklist。

設計與日常視覺交付

詞彙本課程中的意思
design intent畫面背後要保留的受眾、層級、互動與品牌判斷，不只是像素外觀。
Claude Design MCP讓 Claude Code 透過官方 MCP 連接 Claude Design、產生或修改視覺成果的工具能力；連線不等於授權修改 repo、公開內容或代替真人回饋。
design handoff把選定方向、design intent、使用者任務與 bounded scope 從 Claude Design 帶回 Claude Code／repo，而不是只丟一張截圖。
design system calibration把生成結果與正式元件、token 或品牌資產逐項比對，修正同步後的誤讀與遺漏。
state matrix把 default、loading、empty、error 等狀態，對照不同裝置尺寸的行為規則。
vertical slice用少量頁面或功能走完整條工作流，以驗證方向與交付邊界。
source pack帶來源、狀態與 owner 的真實內容集合，是生成視覺產物前的內容地基。
source of truth主張可回查的權威原始位置；模型重述或多份簡報互相引用不算來源。
story spine從受眾現況、證據到下一個決策的敘事順序。
deck由講者控制節奏、用來建立共同理解並推動決策的投影片組合。
claim ledger把投影片中的高影響主張逐一連到精確來源位置、查核狀態與限制條件的紀錄。
deck system經實際重用的字級、色彩、間距與版型規則，用來讓多頁和多版本維持一致。
rehearsal在目標環境向代表性聽眾實際講一次，記錄迷失點、問題與決策理解。
production closeout用 tests、真實 browser evidence 與已知限制，收斂一個準備進產品的 bounded slice。
code-first deck把投影片當成程式碼與靜態網站維護，使用 React、Git、build 與 browser verification；不等於 PPTX 交接。
workspace skill contractopen-slide scaffold 留給 Claude Code 的 CLAUDE.md 與本地 skills，說明 repo 規則與 /create-slide、/create-theme、/apply-comments 等受控工作流。
inspector comment在 open-slide 瀏覽器 inspector 對元素留下的具體回饋，會成為可由 agent 處理的程式 marker。
deployment-ready package已驗證目標輸出，並寫清楚 owner、權限、版本、發布方式與 rollback 的交付包；不代表已經公開。

Claude Code × Playwright

詞彙本課程中的意思
critical path一條風險高、價值明確，且能用開始、使用者動作與可觀察結果描述的 browser 路徑。
Playwright MCP讓 Claude Code 以 MCP 工具操作真實 browser 的 server；適合 live check，但互動紀錄不會自動成為 committed test。
live browser checkAgent 在當下走過一條路徑並重新讀取頁面狀態的觀察證據；回答「現在如何」，不保證未來回歸會被攔下。
Playwright Test Agent由 Playwright 產生、供 Claude Code 使用的角色定義與 MCP 工具組合；產出仍需要人工審查。
planner／generator／healer分別產生可讀 spec、依核准 spec 產生 test，以及診斷並修復 failing test 的三個 agent 角色。
seed test已在 repo 真實通過的最小 test，讓 agents 沿用正確 config、fixtures、locator 與 app 起點。
locatorPlaywright 在每次操作時重新尋找元素的方式；優先使用 role、label、text 等使用者語意或明確 test contract。
web-first assertion會重複查找並等待 UI 達到預期狀態的 async assertion，例如 await expect(locator).toBeVisible()。
trace可回看 actions、DOM snapshots、network 與 assertions 的 execution artifact，用來區分 app、test 與 environment failure。
project一組 Playwright test configuration，可代表特定 browser、device、environment 或 test group；不是越多越好。
CI gate在合併或交付前自動執行 tests，失敗時阻擋流程並提供受控 evidence 的檢查點。

LLM Wiki 與知識累積

詞彙本課程中的意思
LLM Wiki由 AI agent 協助建立與更新的持久 Markdown 知識庫；可先把 raw idea file 直接交給 Claude Code，重要內容仍要能回到原始資料。
原始資料你選來支持 Wiki 的文件、筆記或網頁；保留原文，不讓 AI 覆寫。
待確認來源不同、資料不足或仍需人決定的內容；先誠實標記，不讓 AI 猜成答案。

進階詞（完成第 03 課後再學）

詞彙Phase 6 進階路線中的意思
raw source原始資料的正式稱呼。
schema讓 agent 重複遵守 Wiki 結構、慣例與工作流的指引文件，例如 CLAUDE.md。
ingest讀取一份新 raw source，整合進既有 Wiki，並維護需要的索引與紀錄。
query從索引定位相關 Wiki 頁面，附來源回答問題，必要時把可重用結果寫回。
reconcile整合新舊說法，保留矛盾與不確定性。
wiki lint檢查矛盾、過期說法、孤兒頁、缺少連結與資料缺口。
automation把重複、可用確定規則檢查、低破壞性的步驟做成可重跑命令。
proof pack進階專案用來證明 Wiki 可重跑、可查核的一組證據。
