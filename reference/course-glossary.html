課程詞彙表

本頁是耐久課程語意的單一標準負責人；持續變動的產品、command、模型與可用性主張仍以各自 Source anchor 為準。

使用成果：閱讀 route、課程、參考、Migration 或審查記錄時，能把同一個詞解讀成同一種狀態與證據邊界。若局部頁面與本頁衝突，先停止完整的完成主張，記錄衝突，再由課程負責人修正文案或更新共用的詞彙契約。
可觀察解讀測試：給另一位讀者一張紀錄：「已練習006-0007、候選版本 SHA 已固定、頁面遷移狀態=已撰寫，但尚未完成標準／Spec Review，也尚未取得切換授權。」對方應判斷：學習者有 Lesson practiced 與實作檢查點；課程歷史記為已撰寫；發布仍未發生；不得推論 Route artifact produced、Review 完成、Migration release 或完整課程完成。

路線、Phase 與課程角色

詞彙固定意思常見誤讀
任務路線由任務選出的目標導向課程序列；以真實交付物、必要的 Evidence、學習者判斷與 feedback 結束。Phase 1→12的通用的線性階梯
Route promiseroute 承諾保留的成果、artifact、判斷、feedback／驗證證據與安全邊界。固定課程數量或導覽順序
Phase相關內容的穩定的目錄分組；route 才決定進程。等級、必修關卡或完成狀態
Canonical course coordinate現行目錄中的 Phase、標籤與 Phase 內課程編號；它定位內容，不表示 route 順序或精通。學習者進度或可重用的空號
Entry／readiness進入一段 route 工作前必須帶入的任務、輸入、能力或證據；缺口導向最小補強。所有人都要重走的先決條件 checklist
Conditional只有現行的任務命中條件才選擇的支線。隱藏必修
Elective可依學習目標選擇、但不屬於目前 route 承諾的延伸。不做就不能收尾
Rejoin／return支線或補強完成後，帶著有界證據回到已指定的現行的 route 錨點。自動跳過主線完成契約
Legal stop權限、輸入、證據、安全或可恢復性不足時，保存已知事實與返回點後停止。失敗、放棄或默認核准
Continuation目前 artifact 收尾後，因新任務才選擇的下一段 route。原 route 尚未完成的尾巴
Exit evidence滿足 route 或有界的切片 stop 條件的 artifact、判斷、feedback 與驗證證據。看完頁面或勾完 checklist

練習、產物與證據

詞彙固定意思邊界
Lesson practiced學習者完成該課的操作與可觀察的 feedback。不自動成為 Route artifact produced。
Route artifact produced產物滿足所選任務路線的 artifact 與證據契約。不等於 Phase、Migration 或完整課程完成。
產物可被檢查、使用、交接或重跑的持久輸出，例如報告、規格、儲存庫差異、簡報、檔案或政策草稿。對話中的聲稱不是持久產物。
Evidence能支持具體主張的觀察、artifact 識別、確定性的結果、來源沿革、學習者判斷或 feedback 紀錄。工具成功、模型信心或螢幕看起來合理不夠。
Tangible win一課結束時學習者手上新增的有界的、可保存產物。不是抽象的「理解了」。
Observable feedback另一位人或確定性的介面能觀察到、可反駁的結果。不是代理程式對自己工作的評分。
Deterministic check相同已宣告的輸入與環境產生可重跑通過／失敗的 oracle；必須對錯誤狀態會失敗。不能判斷需求價值、風險接受或負責人核准。
Learner judgment學習者根據證據對取捨、限制與下一步做出的明示處置。不由模型、check 或審查者自動代替。
Evidence carryover準備度檢查後，承認既有 artifact、判斷或 feedback 可作為現行的 route 輸入。不自動既有沿用完成。
整體完成聲稱只在明定的整體完成契約全部有證據時才能做出的聲稱。單課、單一階段、單一路線產物或已發布目錄，都不足以單獨提出這項聲稱。

Review

詞彙固定意思有效證據
Review contract對有界的 repo 變更固定候選版本識別、原始意圖、專案標準、分離的發現事項、人工處置與修正後 checks 的共同契約。Repo Review contract
Standards Review獨立檢查候選版本是否遵守儲存庫內指示、慣例與適用標準。引用規則來源與精確的檔案／差異區塊的發現事項。
Spec Review獨立檢查候選版本是否滿足原始的議題、規格與驗收條件。逐條要求的證據或發現事項。
Immutable Review checkpoint可解析的固定點與精確的候選版本 commit 的 SHA；候選版本任一位元組改變，舊 Review 證據全部失效。新檢查點上完整重跑 checks、標準與 Spec Review。
Reviewer write boundary審查者唯讀的檢查／check／報告；撰寫者才變更、修正與 commit。分離報告與發現事項處置，不是審查者自修自批。

Source 與權限

詞彙固定意思不是
Source支持主張的可歸因資料；現行產品主張優先使用符合資格的第一方來源。模型重述或無法回查的摘要。
Source anchor最小、可獨立重新認證的主張群組或可執行操作程序。整頁共用一個模糊新鮮度標籤。
Source registry標準且機器可讀的 source-anchors.json，保存錨點中繼資料、版本、狀態與重新認證證據。課程頁尾或資源清單的副本。
Source of truth某種狀態／主張的單一權限，例如清單管頁面處置、登錄表管 Source 錨點。多份文件互相引用後共同變成權限。
Source recertification依符合資格的現行來源重新評估主張，並在已宣告環境重跑適用操作程序。只檢查連結還活著。

相容性、Migration 與發布

詞彙固定意思禁止推論
Stable public URL已發布網址永遠解析到現行的標準內容或明確退役通知；不改派給無關內容。舊 URL 可因重新編製索引任意消失。
Compatibility entry非標準的 Stable public URL，直接到最終的標準的目標，或在沒有後繼方案時解釋轉接／退役。不得形成重新導向鏈；不得算進目錄、課程數量、導覽或完成。
Deprecation notice原 URL 上的公開的退役紀錄，說明理由、生效日期、後繼方案與 Evidence carryover。無聲刪除或過期重複課程。
遷移基準十二階段遷移前，公開部署後凍結的 73 個 HTML 路徑。所有歷史 Git 路徑。
Content disposition保留、重寫、移動／改名、條件式、合併、參考轉換或退役的頁面層級決策。只因舊座標或主題相似就刪除。
planned清單已定義頁面契約，但現行的內容尚未被認定滿足已撰寫中繼資料／內容邊界。頁面不存在、驗證失敗或發布受阻的同義詞。
authored頁面已按清單契約撰寫，且應由已撰寫切片驗證器檢查中繼資料、連結、測驗與 Source 範圍。已 Review、已獲切換授權或已發布。
遷移發布標準目錄、基準網址、相容對照、導覽、退役通知與證據沿用一致的公開課程狀態。逐頁或分支預覽的部分發布。
Report-only驗證器可以揭露阻礙，但自身結束行為不會直接發布、批准或修改正式環境。阻礙可忽略，或報告已授權切換。

工作介面與一般交付詞彙

詞彙固定意思
工作表面完成任務的產品或介面；依交付物、權限、可用性與證據需求選擇，不假設所有人都有相同功能。
工作階段／脈絡工作階段是有獨立脈絡的工作對話；脈絡是目前可用的對話、檔案與指示。兩者都不能取代持久的 artifact。
權限規則限制工具、路徑或 command 是否可執行；不證明內容正確，也不授權未列外部副作用。
Skill／MCP／subagent／worktree分別是可重用代理程式指示、受控工具整合、有界的委派脈絡、Git 工作目錄隔離；它們改變執行拓撲，不自動增加權限或完成證據。
Spec／ticket／bounded slice規格固定意圖與驗收；工作票是單一負責人可認領的工作切片；有界的切片小到能檢查、驗證與清楚交接。
回饋迴路能穩定重現、觀察變更影響並再次執行的診斷迴圈。
Handoff／Return notebook讓下一個工作階段或接手者恢復任務、route 錨點、證據、判斷、法務 stop 與下一步動作的持久的紀錄。
