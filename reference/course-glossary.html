課程詞彙表

同一個詞在課程中的固定意思；不是完整產品文件。

使用方式：先用這頁確認課程語意；涉及目前產品功能、模型或介面時，再回官方文件與實際介面查核。

工作表面與執行環境

詞彙本課程中的意思
surface完成任務的產品或介面，例如 Claude、Cowork、Claude Design、Claude Code；先依交付物選 surface。
session一段有自己 context 的工作對話；換 session 前要把重要狀態寫進 durable artifact。
context模型目前能使用的對話、檔案與指令脈絡；長不等於乾淨，也不能取代持久文件。
plan mode先探索、提出計畫與風險，不直接修改檔案的工作模式。
permission rule限制工具或命令可否執行的規則；不等於內容正確性驗證。
hook在特定事件自動執行的 deterministic 檢查或動作。
Skill可重用的代理工作說明與資源；要先讀適用條件與停止線。
MCP讓 agent 透過受控工具連接外部系統或資料的協定與整合方式。
subagent負責邊界清楚子任務的獨立 agent；輸出仍需由主工作流整合與驗證。
worktree同一 Git repository 的另一份工作目錄，用來隔離分支與並行改動。

從需求到可驗證交付

詞彙本課程中的意思
spec把已對齊的問題、範圍、需求、限制與驗收方式寫成可持續使用的文件。
ticket可由單一 owner 認領、具完成條件的工作切片。
bounded slice範圍小到能在目前工作中檢查、驗證與說清楚的一段實作。
feedback loop能穩定重現、觀察改動效果並快速再次執行的診斷迴圈。
fixed pointreview 或比較的明確起點，例如 commit、tag 或 merge-base。
handoff讓下一個 session 或接手者不用重讀整段對話，也能恢復狀態的持久交接。
artifact可被檢查與使用的產物，例如 spec、程式碼、簡報、ledger 或 handoff。
exit evidence證明學習或工作結果達到完成條件的產物、判斷說明與驗證證據；不是只勾完 checklist。

設計與日常視覺交付

詞彙本課程中的意思
design intent畫面背後要保留的受眾、層級、互動與品牌判斷，不只是像素外觀。
vertical slice用少量頁面或功能走完整條工作流，以驗證方向與交付邊界。
source pack帶來源、狀態與 owner 的真實內容集合，是生成視覺產物前的內容地基。
source of truth主張可回查的權威原始位置；模型重述或多份簡報互相引用不算來源。
story spine從受眾現況、證據到下一個決策的敘事順序。
deck由講者控制節奏、用來建立共同理解並推動決策的投影片組合。
rehearsal在目標環境向代表性聽眾實際講一次，記錄迷失點、問題與決策理解。
