課程詞彙表

本頁是耐久課程語意的單一 canonical owner；moving product、command、model 與 availability claims 仍以各自 Source anchor 為準。

使用成果：閱讀 route、lesson、reference、migration 或 review 記錄時，能把同一個詞解讀成同一種狀態與 evidence boundary。若局部頁面與本頁衝突，先停止 full completion claim，記錄衝突，再由課程 owner 修正文案或更新 shared vocabulary contract。
可觀察解讀測試：給另一位讀者一張紀錄：「已練習 006-0007、candidate SHA 已固定、page migrationStatus=authored，但尚未完成 Standards／Spec Review，也尚未取得 cutover authorization。」對方應判斷：learner 有 Lesson practiced 與 implementation checkpoint；course history 記為 authored；publication 仍未發生；不得推論 Route artifact produced、Review complete、Migration release 或 full course completion。

Route、Phase 與 lesson role

詞彙固定意思常見誤讀
Task route由 mission 選出的 goal-directed lesson sequence；以真實 deliverable、required Evidence、learner judgment 與 feedback 結束。Phase 1→12 的 universal linear ladder
Route promiseroute 承諾保留的 outcome、artifact、judgment、feedback／verification evidence 與 safety boundary。固定 lesson count 或 navigation 順序
Phase相關內容的 stable catalog grouping；route 才決定 progression。等級、必修關卡或完成狀態
Canonical course coordinatecurrent catalog 中的 Phase、label 與 phase-local lesson number；它定位內容，不表示 route sequence 或 mastery。learner progress 或可重用的空號
Entry／readiness進入一段 route work 前必須帶入的 mission、input、capability 或 evidence；缺口導向最小 remediation。所有人都要重走的 prerequisite checklist
Conditional只有 active task 命中條件才選擇的支線。隱藏必修
Elective可依學習目標選擇、但不屬於目前 route promise 的延伸。不做就不能 closeout
Rejoin／return支線或 remediation 完成後，帶著 bounded evidence 回到已指定的 active route anchor。自動跳過主線 completion contract
Legal stopauthority、input、evidence、safety 或可恢復性不足時，保存已知 facts 與 return point 後停止。失敗、放棄或默認核准
Continuation目前 artifact closeout 後，因新 mission 才選擇的下一段 route。原 route 尚未完成的尾巴
Exit evidence滿足 route 或 bounded slice stop condition 的 artifact、judgment、feedback 與 verification evidence。看完頁面或勾完 checklist

Practice、artifact 與 Evidence

詞彙固定意思邊界
Lesson practicedlearner 完成該課的操作與 observable feedback。不自動成為 Route artifact produced。
Route artifact produced產物滿足所選 Task route 的 artifact 與 evidence contract。不等於 Phase、Migration 或 full course completion。
Artifact可被檢查、使用、交接或重跑的 durable output，例如 report、spec、repo diff、deck、dossier 或 policy draft。對話中的聲稱不是 durable artifact。
Evidence能支持具體 claim 的 observation、artifact identity、deterministic result、source lineage、learner judgment 或 feedback record。工具成功、模型信心或螢幕看起來合理不夠。
Tangible win一課結束時 learner 手上新增的 bounded、可保存產物。不是抽象的「理解了」。
Observable feedback另一位人或 deterministic interface 能觀察到、可反駁的結果。不是 agent 對自己工作的評分。
Deterministic check相同 declared inputs 與 environment 產生可重跑 pass／fail 的 oracle；必須對錯誤 state 會失敗。不能判斷需求價值、風險接受或 owner approval。
Learner judgmentlearner 根據 evidence 對取捨、限制與下一步做出的明示 disposition。不由模型、check 或 reviewer 自動代替。
Evidence carryoverreadiness check 後，承認既有 artifact、judgment 或 feedback 可作為 current route input。不自動 grandfather completion。
Full completion claim只在明定的整體 completion contract 全部有 evidence 時才能做出的聲稱。單課、單 Phase、單 route artifact 或 published catalog 都不足以單獨推出。

Review

詞彙固定意思有效 evidence
Review contract對 bounded repo change 固定 candidate identity、originating intent、project standards、separate findings、human dispositions 與 post-fix checks 的共同契約。Repo Review contract
Standards Review獨立檢查 candidate 是否遵守 repo-local instructions、conventions 與適用 standards。引用 rule source 與 exact file／hunk 的 findings。
Spec Review獨立檢查 candidate 是否滿足 originating issue、spec 與 acceptance criteria。逐條 requirement 的 evidence 或 finding。
Immutable Review checkpoint可解析的 fixed point 與 exact candidate commit SHA；candidate 任一 byte 改變，舊 Review evidence 全部失效。新 checkpoint 上完整重跑 checks、Standards 與 Spec Review。
Reviewer write boundaryreviewer read-only inspect／check／report；writer 才 mutation、fix 與 commit。分離 report 與 finding disposition，不是 reviewer 自修自批。

Source 與 authority

詞彙固定意思不是
Source支持 claim 的 attributable material；current product claims 優先使用 eligible first-party source。模型重述或無法回查的摘要。
Source anchor最小、可獨立 recertify 的 claim group 或 executable recipe。整頁共用一個模糊 freshness label。
Source registrycanonical machine-readable source-anchors.json，保存 anchor metadata、versions、status 與 recertification evidence。lesson footer 或資源清單的副本。
Source of truth某種 state／claim 的 single authority，例如 manifest 管 page disposition、registry 管 Source anchors。多份文件互相引用後共同變成 authority。
Source recertification依 eligible current source 重新評估 claim，並在 declared environment 重跑 applicable recipe。只檢查 link 還活著。

Compatibility、Migration 與 publication

詞彙固定意思禁止推論
Stable public URLpublished address 永遠解析到 current canonical content 或 explicit retirement notice；不改派給無關內容。舊 URL 可因 reindex 任意消失。
Compatibility entrynon-canonical Stable public URL，直接到 final canonical target，或在沒有 successor 時解釋 transition／retirement。不得形成 redirect chain；不得算進 catalog、lesson count、navigation 或 completion。
Deprecation notice原 URL 上的 public retirement record，說明 reason、effective date、successor 與 Evidence carryover。silent deletion 或 stale duplicate lesson。
Migration baseline十二 Phase migration 前 public deployment 的 frozen 73 HTML paths。所有歷史 Git path。
Content dispositionkeep、rewrite、move／rename、conditional、merge、reference conversion 或 retire 的 page-level decision。只因舊 coordinate 或 topic 相似就刪除。
plannedmanifest 已定義 page contract，但 current content 尚未被認定滿足 authored metadata／content boundary。頁面不存在、驗證失敗或 publication blocked 的同義詞。
authoredpage 已按 manifest contract author，且應由 authored-slice validators 檢查 metadata、links、quiz 與 Source scope。已 Review、已獲 cutover authorization 或已 publish。
Migration releasecanonical catalog、baseline URLs、Compatibility mappings、navigation、Deprecation notices 與 Evidence carryover 一致的 coherent public course state。逐頁或 branch Preview 的 partial publication。
Report-onlyvalidator 可以揭露 blocker，但自身 exit behavior 不會直接發布、批准或修改 production。blocker 可忽略，或報告已授權 cutover。

成熟度詞彙

詞彙固定意思邊界
Workflow maturity workbook保存 Workflow evidence dossier → Scenario rollout plan → Governance lifecycle policy artifact lineage 的 reusable learner reference。不是獨立 route、required capstone、source of truth 或 completion state。
Maturity score本課程沒有定義的 organizational ranking。不得由 workbook 欄位、Phase number、page count 或 agent judgment 計算。
Self-study artifact在 synthetic／local boundary 內建立、可 review 的練習產物。不是 production deployment、real adoption、legal／compliance approval 或 organization authority。

工作 surface 與一般交付詞彙

詞彙固定意思
工作表面完成任務的產品或介面；依 deliverable、authority、availability 與 evidence need 選擇，不假設所有人都有相同功能。
session／脈絡session 是有獨立 context 的工作對話；context 是目前可用的對話、檔案與 instructions。兩者都不能取代 durable artifact。
權限規則限制工具、path 或 command 是否可執行；不證明 content 正確，也不授權未列 external side effect。
Skill／MCP／subagent／worktree分別是 reusable agent instructions、受控 tool integration、bounded delegated context、Git working-directory isolation；它們改變 execution topology，不自動增加 authority 或 completion evidence。
Spec／ticket／bounded sliceSpec 固定 intent 與 acceptance；ticket 是單一 owner 可認領的 work slice；bounded slice 小到能 inspect、verify 與清楚 handoff。
Feedback loop能穩定重現、觀察 change effect 並再次執行的診斷迴圈。
Handoff／Return notebook讓下一個 session 或接手者恢復 mission、route anchor、evidence、judgment、legal stop 與 next action 的 durable record。
