Run history 速查表

用最小索引串起 input、agent evidence、gate results、report 與狀態。

Run history 的驗收句：reviewer 不看聊天紀錄，也能用 history show <run-id> 找到這次 run 的 input、evidence、gates、report 與未驗證項目。

Record schema

{
  "runId": "",
  "inputId": "",
  "status": "passed | failed | blocked | needs-review",
  "agentStatus": "",
  "gateStatus": "",
  "startedAt": "",
  "endedAt": "",
  "evidenceDir": "",
  "gateResultsPath": "",
  "reportPath": "",
  "costUSD": null
}

資料邊界

層級保存內容不要保存
Run history狀態、時間、ID、artifact path。完整 stdout/stderr、完整 transcript。
Evidencestdout、stderr、gate output、截圖。二次摘要當成唯一證據。
Session Store可 resume 的 transcript entries。自訂 report 判斷。
Telemetrytool、latency、token、cost、failure location。未核准的敏感內容。

最小命令

命令輸出失敗條件
history list --json近期 run 摘要。history 檔不存在且未初始化。
history show <run-id> --json單筆完整 record。找不到 run id。
history verify <run-id>artifact path 存在性。evidence/report/gate-results 遺失。

完成定義

Done when:
- Each completed runner attempt appends one run record.
- history list shows status, inputId, startedAt, and reportPath.
- history show returns the full record.
- history verify detects missing artifact paths.
- Cost is stored as an estimate, not authoritative billing.
