# Playwright 改為獨立 Phase 8

Status: superseded by LR-0011

使用者確認要把 Playwright 納入課程，並沿用 beginner-first 結構。後續教學固定為入門 01–04、進階 05–09：先選一條 critical browser path、建立 Playwright Test scaffold、完成一個可見 assertion，以及證明 action path 會紅會綠；遇到真實 flakiness、環境重複、診斷或 CI gate 需求時，才學 stable locators、webServer、fixture、trace、projects 與 CI。
