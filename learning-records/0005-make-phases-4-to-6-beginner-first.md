# Phase 4–6 改採 beginner-first

使用者指出 LLM Wiki 教學過早進入 production-grade 系統設計，並要求一併校準 Phase 4、5，因此同步修訂 [[MISSION.md]]。後續三個 Phase 應讓初學者先完成一個小而真實的成果：一個可操作畫面、三頁簡報或一頁兩來源 Wiki；design system sync、完整 accessibility audit、claim ledger、proof pack 與 code-first build 都只能在入門完成後再教。

Phase 6 的完成線後續再由 LR-0006 收斂為 idea-file-first；本紀錄對 Phase 4、5 的 beginner-first 決策仍維持有效。
