# Course-design learning records

`learning-records/` 是 append-only 的 course-design history。它記錄課程 owner 採納、取代或修正的設計決策，不是 learner progress、Source registry、publication evidence 或 completion authority。

4. [0004 — 採用 route-based 十二 Phase catalog](0004-adopt-route-based-twelve-phase-catalog.md)

## Maintenance rules

- 不覆寫既有 record 來隱藏歷史；新決策以新編號追加，並明記 supersedes／superseded by 關係。
- Learning record 只記 course-design decision 與理由，不宣稱 learner、organization 或 production state。
- Learner 續作使用 [`assets/templates/route-notebook.md`](../assets/templates/route-notebook.md)。
- Publication cutover 使用 [`docs/migration/cutover-report.md`](../docs/migration/cutover-report.md)，且必須引用模板之外的 immutable candidate identity。
