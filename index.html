Phase 3主線 01–12 · 選修 13–14

從需求到交付

先選對路線，再把需求打磨、固化、切片；巨大模糊 effort 可選 wayfinder，最後回到 implement 完成交付。

Phase 4 Claude Code × Claude Design入門 01–08 · 進階 09–13

從 Claude Code 進入視覺探索，再回到 repo

入門用 Design MCP 完成小畫面、選版與真人試用；進階再同步 design system、審查規則、handoff 與 browser evidence。

Phase 5 Claude Code × Claude Design 簡報入門 01–08 · 進階 09–12

讓 Claude Code 管理內容與 Design MCP

入門由 Claude Code 整理來源與三頁故事、真人查核輸出；進階再審查 claim ledger、deck system 與受控彩排。

Phase 6 Claude Code × LLM Wiki入門 01–03 · 進階 04–08

LLM Wiki：從來源到持久知識

前三課用 raw idea file 快速開始；進階再練 schema、ingest、query、lint 與低風險自動化。

Phase 7 Claude Code × open-slide入門 01–04 · 進階 05–09

讓 Claude Code 使用 workspace skills 做簡報

入門核准 scaffold、審查三頁 diff 並親自開啟；進階再讀 contract、使用專用 skills、稽核與準備部署。

Phase 8 Claude Code × Playwright入門 01–04 · 進階 05–09

讓 Claude Code 查核 browser，再留下可信 tests

入門先分清 MCP live check 與 durable test，觀看真實 browser 並審查第一份紅綠證據；進階再用 planner、generator、healer 與 CI 放大已核准路徑。
