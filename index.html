從 0 開始，用 Claude 做出可驗證交付

從真實程式庫開始，練習需求釐清、程式差異審查、測試、權限與交接，把 Claude Code 的產出變成可查核的交付成果。

進入課目表 →

第一次使用先走 Phase 1；已能安全操作 Claude Code，可從 Phase 3 開始。Phase 4–9 各自先完成入門線：小介面、三頁簡報、迷你知識庫、程式化簡報、瀏覽器測試與工作技能。碰到真實需求，再接同一階段的進階課。

Phase 101–12

安全開始

選對工具、開啟工作階段、唯讀探索、設定權限，再完成第一次安全的小改動。

Phase 2 工具箱依需求選讀

控制進階能力

遇到重用、隔離、外部連線或自動化需求時，再選工作技能、子代理、MCP、hooks、worktree 或 CI。

Phase 3主線 01–12 · 選修 13–14

從需求到交付

先選路線，再把需求問清楚、寫成規格、切成工作項目，最後交給 Claude Code 實作並驗證。

Phase 4 Claude Code × Claude Design入門 01–08 · 進階 09–13

從 Claude Code 做視覺探索，再回到程式庫

入門完成小畫面、選版與真人試用；進階再同步設計系統，補齊規則、交接與瀏覽器證據。

Phase 5 Claude Code × Claude Design 簡報入門 01–08 · 進階 09–12

讓 Claude Code 管理簡報內容

入門整理來源、完成三頁故事並由真人查核；進階再建立主張查核表、共用版型與受控彩排。

Phase 6 Claude Code × LLM Wiki入門 01–03 · 進階 04–08

LLM Wiki：從來源到持久知識

前三課直接使用原始想法檔；進階再學資料規則、匯入、查詢、格式檢查與低風險自動化。

Phase 7 Claude Code × open-slide入門 01–04 · 進階 05–09

讓 Claude Code 使用工作區技能做簡報

入門核准初始專案、審查三頁程式差異並親自開啟；進階再讀工作契約、稽核內容並準備部署。

Phase 8 Claude Code × Playwright入門 01–04 · 進階 05–09

讓 Claude Code 查核瀏覽器，再留下可信測試

入門分清即時查核與持久測試，觀看真實瀏覽器並審查第一次失敗到通過的證據；進階再用三種測試代理與 CI 擴大已核准路徑。

Phase 9 Claude Code × 工作技能入門 01–04 · 進階 05–09

讓 Claude Code 把重複流程寫成可預期的 Skill

入門先做出一個專案 Skill 並決定啟用方式；進階再學按需載入、行為引導、精簡整理與新對話測試。
