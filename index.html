從 0 開始，用 Claude Code 做出可交付成果

這套課不是介紹 AI 名詞，而是帶你一步步練習：選對 Claude 工具、在 repo 裡安全開始、把結果驗證清楚，最後把重複任務整理成團隊能重跑的工作流。

不知道從哪開始？先點「進入課目表」，從第 1 課照順序走；已經會 Claude Code 的人，可以直接跳到 Phase 2 或 Phase 3。
會選工具 知道什麼任務該用 Claude Chat、Cowork、Claude Code 或 skill。
會安全開始 先讀 repo、先規劃、再小步修改，避免一開始就改壞專案。
會交付結果 用測試、review、evidence 與 handoff 說清楚做了什麼。

Phase 1 — 先會用

從安裝、唯讀探索、權限、model/effort 到第一次安全改程式碼。

01–22

Phase 2 — 做真任務

把模糊需求問清楚，寫成 PRD/issues，用 TDD、review、diagnose 推進。

01–11

Phase 3 — 變成可重跑

把重複任務寫清楚，加入驗收關卡、證據、報告與執行紀錄。

01–16

Phase 4 — 放進團隊規範

把穩定做法放回 review、模板、hook/gate，並定期整理。

01–05
