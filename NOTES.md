# Teaching Notes

- 教學從 active mission 與 `common-foundation` 開始；Phase 只負責 catalog grouping，不能當作所有自學者共用的線性主線。
- 每課只承諾一個 tangible win；依 manifest 的 route entry、readiness、edge、stop 與 remediation 教學，不另維護平行 syllabus。
- 課堂 checklist 只表示步驟已操作；完成判定還要看 artifact、learner judgment、feedback 與 route 要求的 verification evidence。
- Product availability、命令、版本、export format 與 UI path 不寫成 durable teaching claim；教材只引用 stable Source anchor ID，moving details 回到 `source-anchors.json` recertify。
- Browser exploration、trace、agent summary 與模型 review 都只是 feedback；只有 promoted deterministic check、固定 review candidate 與 learner disposition 能形成相應 route evidence。
- Extensions 依 mission 需要選用；完成一條 route 不會自動授權下一條 route，也不代表真實組織採用、production authorization、legal approval 或 compliance approval。
- 本 repo 依 `AGENTS.md` 維持 standalone HTML 與 embedded CSS；新增頁面比照相鄰教材，視覺一致性由全站 audit 驗證，不另引入 shared stylesheet。
